# はたけパズル 改善会議のまとめ（2026年10月20日〜27日・33回）

## ひとことで

「ブロックパズル × 家庭菜園」の試作版（3段階・1日で作ったもの）を、1日5回の改善会議で1週間かけて作り込みました。
最後は「パズルを遊びながら、35種の野菜の育て方を覚えられる」ゲームになりました。

## ユーザーが決めた方針（会議でいちばん重く扱ったもの）

| 時期 | ユーザーの言葉 | 会議での反映 |
|---|---|---|
| 1日目 | 季節はその季節の野菜を収穫し終えたら次へ | ゲームオーバーで進む作りから、基本の野菜5種をそろえたら進む作りへ |
| 1日目 | 野菜を季節ごとに10種くらい、難しさも上げていい → ちょっと難し過ぎる | 35種に。難しさは真ん中に戻し、以後は上げない |
| 1日目 | 季節が変わるごとに通知 | 季節のお祝い・新しい季節のお知らせ・季節の賞状 |
| 2日目 | ブロックの中に水と肥料のマーク（オマケではなく） | 💧・🍂 マークが水と肥料の唯一の出どころに |
| 2日目 | 野菜の育て方をしっかり学べるように | 以後の最優先。育て方カード・クイズ・失敗しないコツ・ことばの説明・読みがな |
| 2日目 | 10種のうち5種はミッションでアンロック | チャレンジ野菜（20種）とミッション8種類 |

## 数字で見る

- 会議：33回（10/25 の午後の3回は作業環境の再起動で止まり、そのうち1回分を翌朝に開いた）
- 会議ごとの案：10案 × 33回。毎回レギュラー3人（UI/UX・ゲームデザイン・技術）＋ゲスト1〜2人（主婦・60代・子ども・初めて遊ぶ人・家庭菜園の先生・校正者・QA・色覚の専門家・サウンド担当 など）
- 野菜：35種（各季節10種。基本5種＋チャレンジ5種）。どの野菜にも 育て方カード・失敗しないコツ・食べ方・なかま
- ことばの説明：47語。読みがな：274か所
- テスト：38本（`tests/run-all.sh`。文字の大きさ3段の画面点検を含め40回流れる）
- ファイル：js 11本・データ2本・css 1本。外部ライブラリなし

## 何が変わったか（おおまかな流れ）

1. **土台（1〜3回目）**：季節の進み方、35種、季節のお知らせ、手元のとりかえ、💧🍂マーク
2. **学びの柱（4〜15回目）**：育て方カード、チャレンジ野菜、今日のひとこと、ことばの説明、おさらいクイズ、読みがな、プランターの目安、はじめの案内、食べ方35種、失敗しないコツ35種、連作のひとこと、今月とれる野菜
3. **ごほうびと続けやすさ（16〜21回目）**：季節の賞状と見返し、遊び方4ページ、季節の献立、音の設定、ゲームオーバー画面の整理。旬の文とカレンダーの食い違い18種などの不具合直し
4. **安心と見やすさ（22〜28回目）**：保存データの予備、ドラッグの中断、横向き、大事なお知らせを消さない、よくある質問、音のバランス、大きめ文字と320px幅の点検、押しやすい大きさ、なかまのクイズ、文字「とても大きい」
5. **仕上げ（29〜33回目）**：初めての人の通し点検、ことばの校正、図鑑コンプリート、はじめてそろえた日、おかえりのひとこと、お知らせが窓に透けない、色だけにたよらない表示、保存できないときの対策、先生による内容の最終確認、テストをリポジトリに、README

## 会議で学んだこと

- **ゲストの目線がいちばん効いた**：子どもが読めない言葉、60代の「大きめでもまだ小さい」、色覚の専門家の「カレンダーの2色が同じ明るさ」、先生の「しょうがは暑さが好き」など、レギュラーだけでは出なかった。
- **機械の点検と人の点検は別もの**：月の食い違いや読みがなの崩れは機械で拾えたが、育て方の中身のまちがい（8件）は先生にしか見つけられなかった。
- **点検の回は不具合が見つかる**：横向きのはみ出し、手元のブロックがタブに隠れる（320px幅）、遊べないまま出なかった目標、上書きされていた賞状の日付などは、新しい機能の回ではなく点検の回で見つかった。

## 次の版の候補（見送った案）

1. 💡ヒントボタン：置けなくなりそうなときだけ。回数は見せない
2. 本物の畑でも育てた記録（チェックリスト）。学びとのつなぎ方を考え直す
3. 野菜の絵：仮の絵（丸に1文字）の野菜を、少しずつ本物らしい絵に
4. コツのクイズ：「やりがちな失敗」をまちがいの選択肢にする問題
5. 季節の色：2つの季節にまたがる野菜の色の決め方
6. はじめて収穫した日の記録と、図鑑をそろえるまでの日数
7. おさらいクイズの問題数（3問／5問）を選べるように
8. 暗い配色（夜でもまぶしくない色）。色が直接書かれている所が多いので、色の名前をまとめてから
9. 使われていない CSS の掃除（2クラス・約10行）
10. 読み上げ機能への対応（ブロックの置き場はドラッグだけなので大工事）

難しさを上げる案（雑草のマスなど）は、方針により候補から外しています。
