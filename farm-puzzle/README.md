# はたけパズル（2026年10月版）

ブロックパズルを遊びながら、家庭菜園の育て方を覚えられるブラウザゲームです。
家事の合間に、スマホで5分ずつ遊ぶことを考えて作りました。

## 遊ぶ人へ

- **スマホやパソコンのブラウザで開くだけ**。登録・お金・広告はありません
- **途中でやめても大丈夫**。閉じても、盤面も畑も続きから遊べます
- **野菜は枯れません**。何日あけても畑はそのまま。3日以上あけると「おかえりなさい」が出ます
- **文字は大きくでき、音は消せます**（右上の「？」から。音ははじめオフ）
- **データが消えたように見えたら**：下の「保存データ」を見てください

### 遊び方

1. **パズル**：下のブロックを盤面へ運んで置き、縦か横の一列がそろうと消えます。
   ブロックのマスには 💧（水：青い丸いふち）と 🍂（肥料：茶色の角ばったふち）のマークがあり、
   マークのあるマスを消すと、その数だけ水と肥料がたまります
2. **はたけ**：種まき → 水やり → 追肥（肥料をあげること）→ パズルで列を消すと育つ → 収穫。
   収穫するとコインが入り、区画を増やせます
3. **図鑑**：収穫した野菜が載ります。旬・ミニ知識・食べ方・なかま、育て方カードが読めます

- **季節の進み方**：今の季節の「基本の野菜」5種をぜんぶ収穫すると、次の季節へ進みます（ゲームオーバーでは進みません）。
  季節をそろえると賞状がもらえ、図鑑の季節バッジからいつでも見返せます
- **チャレンジ野菜**：各季節に5種ずつ。ミッション（決まった野菜を収穫する・コンボを出す・クイズに正解する など）をクリアすると種が手に入ります
- **図鑑コンプリート**：35種ぜんぶ収穫すると、図鑑の賞状（📖バッジ）がもらえます
- **こまったとき**：「↩ 一手もどす」と「🔄 とりかえ」が1プレイに1回ずつ使えます（一手もどすは、畑で作業すると使えなくなります）

### このゲームで覚えられること

- **植える時期・とれる時期**：育て方カードの栽培カレンダー（植える月は下に線、とれる月は上に線）、図鑑の「今月まける」「今月とれる」
- **作業の順番とコツ**：種まき・水やり・追肥・収穫の、それぞれのコツ。作業をするたびにお知らせで読めます。35種それぞれに「失敗しないコツ」もあります
- **なかまと連作**：同じなかま（ナス・ウリ・アブラナ・マメ など）を同じ場所で続けて育てると病気が出やすい「連作」。収穫したときに「次はちがうなかまを」と教えてくれます
- **病気・虫、プランターで育つか**：育て方カードに書いてあります
- **むずかしい言葉**：読みがな（設定で消せます）と「ことばの説明」（47語）
- **おさらいクイズ**（図鑑から）：植える月・とれる月・病気や虫・プランター向きか・なかま の問題が出ます

### 設定（右上の「？」）

| 項目 | 内容 |
|---|---|
| 遊び方をもう一度見る | 4ページの説明 |
| 音 | オフ → 小さめ → ふつう（右上の 🔇/🔊 でもオン・オフ） |
| 読みがな | オン・オフ |
| 文字 | ふつう → 大きめ → とても大きい（横向きのときは大きめまで） |
| 振動 | オン・オフ（iPhone は振動しません） |
| よくある質問 | 水や肥料のため方、季節の進み方 |

### 保存データ

遊んだ記録はブラウザ（localStorage）に保存されます。同じ端末・同じブラウザなら続きから遊べます。

- プライベートモードや空き容量がないときは保存できません。そのときは1回だけ「今の進み具合が残せないかもしれません」と出ます
- 保存データが読めなくなったときは、ひとつ前の保存（予備）から自動で再開します

| キー | 中身 |
|---|---|
| `hatake-puzzle-save` | 本体 |
| `hatake-puzzle-save-bak` | ひとつ前の保存（予備） |
| `hatake-puzzle-save-broken` | 読めなかったデータの控え（消さずに残す） |

はじめからやり直したいときは、ブラウザの開発者ツールのコンソールで次を実行します。

```js
['hatake-puzzle-save', 'hatake-puzzle-save-bak', 'hatake-puzzle-save-broken'].forEach((k) => localStorage.removeItem(k)); location.reload();
```

## 作る人へ

HTML / CSS / JavaScript だけで動きます（外部ライブラリなし・ビルド不要）。

### 起動のしかた

JSON ファイルを読み込むため、`index.html` をダブルクリックでは開けません。かんたんなサーバーを起動してください。

```sh
cd farm-puzzle
python3 -m http.server 8765
```

- PC：http://localhost:8765/
- スマホ：PC と同じ Wi-Fi で `http://<PCのIPアドレス>:8765/`（GitHub Pages などに置けば URL を開くだけで遊べます）

### 方針（ユーザーが決めたこと）

- いちばん大事なのは「野菜の育て方をしっかり学べる」こと
- 難しさは真ん中。これ以上上げない
- 💧・🍂 のマークが水と肥料の出どころ
- 季節は、その季節の基本の野菜を収穫し終えたら進む。季節が変わるときはお知らせする
- 野菜は35種（各季節10種、そのうち5種はミッションで解放するチャレンジ野菜）

### ファイル構成

```
farm-puzzle/
├─ index.html          画面の骨組み（パズル・はたけ・図鑑の3画面とタブ）
├─ css/style.css       見た目（色は先頭の :root。文字の大きさ・横向き・小さい画面の調整もここ）
├─ data/
│  ├─ vegetables.json  季節・ゲームバランス（rules）・野菜35種・ことばの説明（glossary）
│  └─ messages.json    画面に出る文章（{name} などに値が入る。{語|よみ} は読みがな）
├─ js/
│  ├─ util.js          共通の小道具（文言と読みがな・ダイアログ・お知らせ・野菜の絵）
│  ├─ storage.js       保存（予備・読めなかったデータの控え・古い形のデータの読みかえ）
│  ├─ sound.js         効果音（その場で音を作る）と振動
│  ├─ guide.js         遊び方（4ページ）
│  ├─ howto.js         育て方カード（栽培カレンダー・コツ・なかま・ことばの説明）
│  ├─ quiz.js          おさらいクイズ
│  ├─ missions.js      チャレンジ野菜のミッション
│  ├─ puzzle.js        パズル（盤面・ドラッグ・列消し・一手もどす・とりかえ・ゲームオーバー）
│  ├─ farm.js          畑（資源・作業・収穫・区画・季節・次の目標・今日のひとこと）
│  ├─ zukan.js         図鑑（絞りこみ・季節のバッジ・賞状）
│  └─ main.js          起動と、各部分のつなぎ役（季節のお祝い・設定・ゲームオーバー画面）
├─ tests/              テスト（下を参照）
└─ docs/kaizen/        改善会議の記録（33回分）と まとめ.md
```

### 処理の流れ

```
main.js が JSON を読み込む → 保存データを読む（storage.js）→ 図鑑・畑・パズル・ミッションを準備
パズルで列を消す     → Farm.gainFromLines()：消した 💧・🍂 の数だけ水と肥料（上限 50・30）。育ち中の野菜も育つ
畑で収穫             → コイン・図鑑に登録 → 基本の野菜5種がそろえば季節が進む（farm.js の checkSeason）
収穫のあとの順番     → 図鑑に載りました → 図鑑コンプリート → 季節の賞状 → 次の季節（main.js の onHarvest）
変化があるたびに     → 保存（main.js の persist）・上のバーを更新
```

### データの直し方

野菜は `data/vegetables.json` の `vegetables` にあります（id は保存データで使うので後から変えない）。

| 項目 | 意味 |
|---|---|
| `id` / `name` / `icon` | ID・名前・絵（絵文字、`mark:キ:#色`、`css:名前`、`img:パス`） |
| `water` / `fertilizer` / `grow` / `price` | 水やり・追肥に要る量、実るまでに消す列の数、コイン |
| `seasons` / `seasonText` | 旬の季節（spring / summer / autumn / winter）と旬の文（カレンダーの月と合わせる） |
| `family` / `familyKa` / `rotationYears` / `perennial` | なかま、科の名前（ちがうときだけ）、連作で何年あけるか、何年もとれる野菜 |
| `guide` | 育てやすさ・日当たり・植える時期・`plantMonths`・`harvestMonths`・病気や虫・いちばんのコツ・`planter` |
| `steps` | 作業ごとのコツ（sow / water / fertilize / harvest） |
| `tips` / `mistake` / `eat` | ミニ知識、失敗しないコツ、おいしい食べ方 |
| `unlock` | チャレンジ野菜のミッション（種類は `js/missions.js` の先頭） |

ゲームバランスは同じファイルの `rules`（マーク1つの水・肥料、コンボの上乗せ、旬のコイン倍率 1.5、上限、区画の値段など）、
ブロックの形や出やすさは `js/puzzle.js` の `SHAPES` と `RULES` で変えられます。
文章を直したら `node tests/t49.js` で読みがなの印と月の食い違いを確かめてください。

### テストのしかた

Playwright と Chromium が入っている環境で、`farm-puzzle` フォルダから：

```sh
bash tests/run-all.sh
```

- localhost:8765 でゲームを配り（動いていなければ起動）、`tests/t*.js` を順に流します。最後に失敗の数を出します
- `t38.js` は画面のはみ出し点検で、文字の大きさ3段 × 320px・375px・横向き × 7画面を見ます
- `t49.js` はデータの点検（ブラウザ不要）
- ほかは、パズル・畑・図鑑・クイズ・季節・賞状・保存（予備・失敗）・初めての人の流れ などを、スマホ幅と PC 幅で確かめます
- 画面の写真は `$SP`（指定がなければ一時フォルダ）に保存されます
