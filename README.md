# 米粉の焼き菓子 pOna — ホームページ

Instagram [@komekopona](https://www.instagram.com/komekopona/)（米粉の焼き菓子 pOna）の
ホームページです。[Sunday Bake Shop](https://sundaybakeshop.jp/) の実際のサイト構成を
参考にしています。

## 参考にした点

Sunday Bake Shop のサイトは、ナビゲーションを持たない1枚ものです。以下をそのまま踏襲しました。

- **ナビゲーションバーを置かない。** 上から順に読ませて終わる
- **全画面のヒーロー** に店名を極太ゴシックで右寄せ・複数行、下に `⌄` のスクロール記号
- ヒーローの直後に **全幅の地図** → **中央揃えの住所** → **「営業日やお休みについては @◯◯ をご確認ください。」**
- **差し色のベタ塗りブロック**に、白のアイコン付きリンク一覧と手描きの落書きイラスト
- 最後に白地で Copyright
- 全体を通して **極太ゴシック＋広い字間（0.16em）＋中央揃え**、文章は最小限

差し色だけ、参考サイトの鮮やかな緑ではなく pOna のロゴの茶色 `#7d5231` にしています。
落書きイラストは、いただいたハリネズミの手描きイラスト（`assets/img/doodle-hedgehog.png`）です。
茶色の地に載せるため、紙の背景を透過させてインクを白に置き換えてあります。
明るい地に置きたい場合のために、元の茶色のまま透過させた
`doodle-hedgehog-brown.png` も同じフォルダに入れてあります。

## 構成

```
index.html              1ページ完結
assets/css/style.css    スタイル
assets/js/main.js       スクロール記号の表示制御のみ
assets/img/hero-1〜5    ヒーローのスライドショーの写真
assets/img/doodle-*     フッターのハリネズミ（白抜き／茶色の2種）
```

セクション順： `ヒーロー → 地図 → 住所 → 営業日 → メニュー → リンク → Copyright`

「メニュー」だけは参考サイトに無いブロックです。pOna は焼き菓子以外にソフトクリームや
生米パンもあるため、同じ字組み（中央揃え・太字・広い字間）で追加しました。不要なら
`<section class="block menu">` ごと削除できます。

## 差し替えが必要なところ

- **ヒーローの写真** — Instagram の投稿からいただいた5枚ですが、投稿一覧のスクリーンショット
  経由なので **元は 480〜640px しかありません**。全画面に引き伸ばしているぶん、大きな画面では
  眠く見えます。撮影データがあれば、同じファイル名で `assets/img/` に置き換えてください
  （長辺 1600〜2000px、JPEG 品質 80 前後が目安）。順番を変えるだけなら `index.html` の
  `.hero-media` の中の `<img>` を並べ替えます。枚数を増減する場合は
  `style.css` の `.hero-slide:nth-child(n)` の `animation-delay` と、
  `@keyframes slideshow` の割合（1枚あたり 20% = 6秒）も合わせて直してください。
- **地図** — `maps.google.com` の埋め込みを住所で指定しています。正確な位置に合わせたい場合は、
  Google マップで店舗を開いて「共有 → 地図を埋め込む」で出る `<iframe>` の src に差し替えてください。
- **メニューの内容と価格** — Instagram から書き起こしたものです。最新のものに。
- **お問い合わせ先** — 参考サイトにはメールのリンクがあります。メールアドレスが分かれば
  `.links` のリストに同じ形式で1行足せます。

## ヒーローのスライドショー

参考サイトが全画面の動画なので、それにあたるものとして写真5枚のクロスフェードにしています。

- 1枚 6 秒 × 5 枚 = 30 秒でひと回り。切り替えは 0.6 秒のクロスフェード
- 表示中はゆっくり 1.04 倍 → 1.12 倍に寄る（映像に近い間合いにするため）
- CSS アニメーションだけで動かしていて、JavaScript は使っていません
- 動きを減らす設定（`prefers-reduced-motion`）の環境では、1枚目を出したまま止まります
- 写真の上に文字を置くので、右下ほど濃くなる覆いを重ねています（`.hero::after`）。
  もっと明るい写真に替えて文字が読みにくくなったら、この濃さを上げてください

## つくりの方針

- **フォント** — Zen Kaku Gothic New（Google Fonts）の 500 / 700 / 900 のみ
- **配色** — 白地、写真が読み込まれるまでの地に生成り `#f4ece0`、差し色はロゴの茶 `#7d5231`
- **アクセシビリティ** — スキップリンク、フォーカス表示、`prefers-reduced-motion` 対応、
  地図の `<iframe>` に `title` を設定
- **依存なし** — フレームワーク・ビルドツールは使っていません

## おまけ：爆走！つがおのビバベジ便！（ミニゲーム）

`keitora/index.html` をブラウザで開くと遊べる、チャリ走風のランゲームです。
トマトを山積みにした軽トラが自動で田んぼ道を走り、タップ（またはスペースキー）でジャンプします。長押しすると高く跳び、
空中でもう一度押すと2段ジャンプ（着地まで1回）。500 m を過ぎると、ときどき2段ジャンプでないと越えにくい広い泥の斜面が出ます。
棚田のように道が段になって上の田んぼへ登っていく（段は登るだけで下りはない）。草の土手（1回のジャンプで登れる）と、
350 m を過ぎると出てくる石垣（2段ジャンプでないと登れない）がある。段の壁にぶつかるとゲームオーバー。
登るたびに画面が動いて、軽トラはいつもの位置に戻る。
田植え〜青田の時期は、手前の田んぼでアイガモの親子が泳いでいる（アイガモ農法）。
黄金の稲穂〜夕焼けの時期は稲が高く伸びて穂が垂れる。手前の田んぼではコンバインが稲を刈り進み、刈ったあとは切り株になる。
奥の田んぼは2層になっていて、コンバイン、2段のはさ掛け、稲束を掛ける人・かついで運ぶ人でにぎわう。
BGM は `keitora/bgm.mp3`（「VIVA‼︎つがお組長」）をループで流す。読み込めないときは手作りの8小節ループに切り替わる。
右上の音符ボタンで BGM だけ止められる。

**トマトが落ちる条件**: 水たまりで必ず2個／ボコボコ道で跳ねるたびに45%で1個／
着地の衝撃が強いほど高い確率で1個（石垣から飛び降りるような強い衝撃なら2個）

**スコア**: 配達スコア（1 m 進むごとに積んでいるトマトの数だけ加点）で勝負する。
着地がドスンと荒い・水たまり・ボコボコ道でトマトが落ちる。500 m ごとのトマト畑で満杯に積み直せる。

走る距離に合わせて、田植え → 青田 → 黄金の稲穂 → 夕焼け → 夜（ヘッドライト点灯）と景色が移り変わる（2,000 m で一巡）。

**障害物**

- **泥の斜面**: 落ちると斜面を滑り落ちて転がり、ゲームオーバー
- **イノシシ**: 右から「!」の警告のあとに突っ込んでくる。ぶつかると軽トラがボコボコになってゲームオーバー
- **水たまり**: 滑って大きく減速し、少しの間ジャンプできない
- **ボコボコ道**: 減速する。3 回乗り上げるとタイヤがパンクしてゲームオーバー（跳び越えれば数えない）

記録（配達スコア・最長距離）はブラウザに保存されます。一時停止は右上のボタンか P / Esc キー。
スマホは横向き推奨で、縦向きのときはゲームの下にジャンプ用のパッドが出ます。

**みんなのランキング**: タイトルとゲームオーバー画面の「ランキング」ボタンで上位10人を表示する。
ニックネームを入れると自己ベストの配達スコアが1人1件で載る（自分の記録より良いときだけ上書き）。
記録の保存先は Googleスプレッドシート（`keitora/ranking/Code.gs` を Apps Script のウェブアプリとして公開し、
その URL を `index.html` の `RANK_URL` に入れる。手順は `keitora/ranking/README.md`）。
`RANK_URL` が空のときは claude.ai のアーティファクトの共有 db を使い、どちらも使えなければボタンごと隠れる。

**ライバルの旗**: 走っている道に、ランキングで今の地点のすぐ先まで走った1人の名前入りの青い旗が立つ。抜くと「○○さんを抜いた!」。

**結果を送る**: ゲームオーバー画面の緑のボタンで、スコア・称号・順位・URL 入りの画像を作り、スマホの共有から LINE などに送れる
（共有が使えない所では画像を表示して保存・URL コピー）。名前がまだの人は結果画面でそのままランキングに載せられる。
LINE などでリンクを送ると `og.png` の紹介画像が出る。

**HD-2D（3D の世界にドット絵のキャラクター）**: 地形は Three.js（`keitora/vendor/three.min.js`、MIT）で作った本物の 3D。
あぜ道・段の土手と石垣・泥の穴（あぜが切れて斜面と水）・水たまり・ボコボコ道・田んぼの水面・稲（季節で高さと色が変わる）・電柱と電線・
山並み・遠くの平地を、ジオラマを斜め上から見下ろすカメラで描く。太陽（夜は月）の光で影が落ち、夜はヘッドライトが道を照らし、蛍が光る。
軽トラ・牛・イノシシ・カラス・旗・吹き出しは、今の 2D の絵を粗い解像度の「層」に描いて、道の真ん中に立てた板として置く（影も落ちる）。
カモ・はさ掛け・コンバイン・農家の人・トマト畑の小屋もドット絵の板。後処理で、カメラからの本当の距離を使ってピントの外をぼかし（被写界深度）、
明るい所を光らせ、色味と周辺減光を整える。距離やスコアの表示は別の canvas でぼかさない。ゲームの仕組み（座標・当たり判定）は 2D のまま。
一時停止メニューの「HD-2D」ボタンでオン・オフ（端末に保存）。WebGL が使えない端末では今までの 2D の絵、重い端末（1 コマ平均 28 ms 超）では自動で休止する。

**危なさの色と印**: 落ちたら・当たったら終わりの物は赤に白い「×」（泥の穴の手前の「× 穴」の看板と紅白の杭・ロープ、
段差と石垣の予告、イノシシの予告）。遅くなるだけの物は黄色に黒い「！」（水たまり・悪路・牛の看板）。

**夜の街灯**: 夜は電柱から道へ伸ばした裸電球が灯り、道に光の輪が落ちる（本物の光源は使わず、光って見える玉と板で軽く）。

**荷台の揺れ**: 着地やボコボコ道で、荷台の積み荷がばねのように揺れ、上の段ほど跳ねて落ちそうになる。

**やられた直後のスロー**: やられた瞬間から約 1 秒だけ動きがゆっくりになる。タップ（Space）で飛ばして早く結果へ。

**トマト畑の積み込み**: 500 m ごとのトマト畑では、小屋の先で農家さんが手を振り、足りない分の積み荷を1個ずつ荷台へ放り込む（届いた分だけ増える）。

**1000 m ごとの山場**: 1000 m ごとに1回、イノシシの親子（親1・子2）が一定の間隔で続けて走ってくる。1頭ずつ跳べば必ず越えられる。警告は最初の1回だけ。

**着地の土煙・速さの風**: 着地すると土煙がふわっと広がる（粒が多いときは出さない）。速くなるほど道の上を薄い風の筋が流れる。

**表示の整理と重さ**: 走り中の一言は同時に2つまで（パンクなど危ない知らせは残す）。季節は画面中央の文字の帯ではなく、変わり目の道ばたの縦長ののぼり旗で見せる。
重い端末では HD-2D を止める前に段階的に軽くする（ぼかしをやめる→影を粗く→遠くの稲を消す→低い解像度で描く→それでも重ければ休む。段は端末に保存）。

**結果画面・ベスト更新**: 結果画面の見出しは、やられ方ごとの一言（「泥んこダイブ!」「イノシシ一家に通せんぼ!」など）から毎回選ぶ。自己ベストを超えた瞬間に紙吹雪。

**背景のコンバイン**: 約 100 m に 1 台だけ、それぞれ自分のペースで田んぼを行ったり来たりする。

**牛**: 300 m を過ぎると、ときどき黒い F1 の牛（耳に黄色い耳標）が道の上で足踏みしている。跳び越えれば OK。
ぶつかっても終わらず、今の速さの 3 割まで減速し、牛は「モ〜」と1回鳴いて首をかしげ、奥へ下がる。

**カラス**: 400 m を過ぎると、ときどき右上から荷台めがけて降りてくる（道に影が出る）。着く瞬間に跳んでいれば追い払える。
地面にいると積み荷を1個持っていかれる（終わりにはならない）。「カァ」は1回だけ。

**落ちている積み荷**: 障害物のあいだの平らな所に、ときどき積み荷が1個落ちている。上を通ると1個積み戻せる（音なし）。

**運転手のリアクション**: ジャンプで帽子が浮く、積み荷を落とすと帽子を押さえる、イノシシをかわす・ライバルを抜く・
カラスを追い払うとガッツポーズ、ベスト更新・積み直しで手を振る、ぶつかると帽子が飛ぶ。

**夜の蛍と天の川**: 夜の時間帯は、空に天の川、田んぼの上に蛍が光る。

**ペースの影**: 自己ベスト（最長距離）を出した走りの「同じ時間にどこまで進んでいたか」を、うっすらした軽トラ（ベストの自分）で並走させる。
速さは距離で決まるので、水たまりやボコボコ道で減速すると置いていかれる。自分と重なるときや旗の近くでは消える。

**練習道**: まだ 150 m を走れていない人は、最初の 200 m で障害物の間隔が広く、泥の穴が狭く、イノシシと段差が出ない。

**積み荷**: タイトルの「積み荷」ボタンで荷台の見た目を選べる（点数は同じ）。自己ベストが 300 m で野菜いろいろ、
800 m で牧草ロール、1,500 m で子牛と牧草（黒い F1 の子牛、耳に黄色い耳標）。

**公開サイト（GitHub Pages）**: リポジトリの Settings → Pages で、Source を「Deploy from a branch」、
ブランチを `claude/kei-truck-runner-game-ngc2ni`・フォルダを `/ (root)` にすると、
`https://ngcmwbj-art.github.io/-/keitora/` で誰でもログインなしで遊べる。
スマホで開いて「ホーム画面に追加」すると、アイコンから全画面で起動できる（`manifest.webmanifest`・`sw.js`。
一度開いておけば電波がなくても遊べる。ランキングだけはつながったときに更新される）。

URL の末尾に `#debug` を付けると、自動運転の試運転用フック（`window.__kt`）が有効になります。
