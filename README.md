# 米粉の焼き菓子 pOna — ホームページ

Instagram [@komekopona](https://www.instagram.com/komekopona/)（米粉の焼き菓子 pOna）の
ホームページです。[Sunday Bake Shop](https://sundaybakeshop.jp/) の実際のサイト構成を
参考にしています。

## 参考にした点

Sunday Bake Shop のサイトは、ナビゲーションを持たない1枚ものです。以下をそのまま踏襲しました。

- **ナビゲーションバーを置かない。** 上から順に読ませて終わる
- **全画面のヒーロー** に店名を極太ゴシックで右寄せ・複数行、下に `⌄` のスクロール記号
- ヒーローの直後に **全幅の地図** → **中央揃えの住所** → **「営業日やお休みについては @◯◯ をご確認ください。」**
- **差し色のベタ塗りブロック**に、白のアイコン付きリンク一覧と手描きの落書きイラスト
- 最後に白地で Copyright
- 全体を通して **極太ゴシック＋広い字間（0.16em）＋中央揃え**、文章は最小限

差し色だけ、参考サイトの鮮やかな緑ではなく pOna のロゴの茶色 `#7d5231` にしています。
落書きイラストは、いただいたハリネズミの手描きイラスト（`assets/img/doodle-hedgehog.png`）です。
茶色の地に載せるため、紙の背景を透過させてインクを白に置き換えてあります。
明るい地に置きたい場合のために、元の茶色のまま透過させた
`doodle-hedgehog-brown.png` も同じフォルダに入れてあります。

## 構成

```
index.html              1ページ完結
assets/css/style.css    スタイル
assets/js/main.js       スクロール記号の表示制御のみ
assets/img/hero-1〜5    ヒーローのスライドショーの写真
assets/img/doodle-*     フッターのハリネズミ（白抜き／茶色の2種）
```

セクション順： `ヒーロー → 地図 → 住所 → 営業日 → メニュー → リンク → Copyright`

「メニュー」だけは参考サイトに無いブロックです。pOna は焼き菓子以外にソフトクリームや
生米パンもあるため、同じ字組み（中央揃え・太字・広い字間）で追加しました。不要なら
`<section class="block menu">` ごと削除できます。

## 見かた

ビルド不要の静的サイトです。`index.html` をブラウザで開くだけで確認できます。

```sh
python3 -m http.server 8000

```

GitHub Pages に置く場合は、Settings → Pages でこのブランチの `/`（root）を公開先に指定してください。

## 差し替えが必要なところ

- **ヒーローの写真** — Instagram の投稿からいただいた5枚ですが、投稿一覧のスクリーンショット
  経由なので **元は 480〜640px しかありません**。全画面に引き伸ばしているぶん、大きな画面では
  眠く見えます。撮影データがあれば、同じファイル名で `assets/img/` に置き換えてください
  （長辺 1600〜2000px、JPEG 品質 80 前後が目安）。順番を変えるだけなら `index.html` の
  `.hero-media` の中の `<img>` を並べ替えます。枚数を増減する場合は
  `style.css` の `.hero-slide:nth-child(n)` の `animation-delay` と、
  `@keyframes slideshow` の割合（1枚あたり 20% = 6秒）も合わせて直してください。
- **地図** — `maps.google.com` の埋め込みを住所で指定しています。正確な位置に合わせたい場合は、
  Google マップで店舗を開いて「共有 → 地図を埋め込む」で出る `<iframe>` の src に差し替えてください。
- **メニューの内容と価格** — Instagram から書き起こしたものです。最新のものに。
- **お問い合わせ先** — 参考サイトにはメールのリンクがあります。メールアドレスが分かれば
  `.links` のリストに同じ形式で1行足せます。

## ヒーローのスライドショー

参考サイトが全画面の動画なので、それにあたるものとして写真5枚のクロスフェードにしています。

- 1枚 6 秒 × 5 枚 = 30 秒でひと回り。切り替えは 0.6 秒のクロスフェード
- 表示中はゆっくり 1.04 倍 → 1.12 倍に寄る（映像に近い間合いにするため）
- CSS アニメーションだけで動かしていて、JavaScript は使っていません
- 動きを減らす設定（`prefers-reduced-motion`）の環境では、1枚目を出したまま止まります
- 写真の上に文字を置くので、右下ほど濃くなる覆いを重ねています（`.hero::after`）。
  もっと明るい写真に替えて文字が読みにくくなったら、この濃さを上げてください

## つくりの方針

- **フォント** — Zen Kaku Gothic New（Google Fonts）の 500 / 700 / 900 のみ
- **配色** — 白地、写真が読み込まれるまでの地に生成り `#f4ece0`、差し色はロゴの茶 `#7d5231`
- **アクセシビリティ** — スキップリンク、フォーカス表示、`prefers-reduced-motion` 対応、
  地図の `<iframe>` に `title` を設定
- **依存なし** — フレームワーク・ビルドツールは使っていません

## 写真の扱い

ヒーローの5枚は @komekopona の投稿写真です。お店の写真をお店のサイトに使う前提で入れています。
第三者が撮った写真が混ざっていないかだけ、公開前にご確認ください。

## おまけ：軽トラ走!（ミニゲーム）

`keitora/index.html` をブラウザで開くと遊べる、チャリ走風のランゲームです。
トマトを山積みにした軽トラが自動で田んぼ道を走り、タップ（またはスペースキー）でジャンプします。長押しすると高く跳び、
空中でもう一度押すと2段ジャンプ（着地まで1回）。500 m を過ぎると、ときどき2段ジャンプでないと越えにくい広い泥の斜面が出ます。
棚田のように道が段になって上の田んぼへ登る所があり、草の土手（1回のジャンプで登れる）と、
350 m を過ぎると出てくる石垣（2段ジャンプでないと登れない）がある。段の壁にぶつかるとゲームオーバー。
田植え〜青田の時期は、手前の田んぼでアイガモの親子が泳いでいる（アイガモ農法）。

**モード**

- **エンドレス**: 配達スコア（1 m 進むごとに積んでいるトマトの数だけ加点）で勝負。
  着地がドスンと荒い・水たまり・ボコボコ道でトマトが落ちる。500 m ごとのトマト畑で満杯に積み直せる
- **タイムアタック**: 毎回同じコースの 1,000 m を何秒で走れるか。減速するとタイムが落ちる。
  自己ベストの走りが半透明の「ゴースト」として一緒に走り、ベストとのタイム差も表示される

走る距離に合わせて、田植え → 青田 → 黄金の稲穂 → 夕焼け → 夜（ヘッドライト点灯）と景色が移り変わる（2,000 m で一巡）。

**障害物**

- **泥の斜面**: 落ちると斜面を滑り落ちて転がり、ゲームオーバー
- **イノシシ**: 右から「!」の警告のあとに突っ込んでくる。ぶつかると軽トラがボコボコになってゲームオーバー
- **水たまり**: 滑って大きく減速し、少しの間ジャンプできない
- **ボコボコ道**: 減速する。3 回乗り上げるとタイヤがパンクしてゲームオーバー（跳び越えれば数えない）

記録（最長距離・最速タイム）はブラウザに保存されます。一時停止は右上のボタンか P / Esc キー。
スマホは横向き推奨で、縦向きのときはゲームの下にジャンプ用のパッドが出ます。

URL の末尾に `#debug` を付けると、自動運転の試運転用フック（`window.__kt`）が有効になります。
