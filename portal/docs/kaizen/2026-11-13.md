# 改善会議 2026-11-13（お米のおまけゲームでリピーターを増やす）

議題：お米を買ってくれた人にゲームセット（7本）を贈る企画で、再購入につなげる仕組み。
メンバー：UI/UX担当・ゲームデザイン担当・技術担当＋ゲスト（ターゲット層代表＝お米を買う家庭の親、辛口レビュアー）。全員 Fable 5.2。

## 10案
1. 袋ごとの合言葉で続きが開く（しゅんの次の章・防農作戦の季節ボス）
2. ゲーム内スタンプカード（5個で値引き券・限定キャラ）
3. 今月の田んぼ・牛舎だより（本物の写真と一言を季節ごとに）
4. 新米シーズン限定ステージ
5. おまけカード集め（全8種）
6. 炊き方・レシピがごほうびで開く
7. 定期便の人だけの特典（先行公開・名前掲載）
8. 家族で競う月間ランキング
9. 「そろそろ新しいお米」のお知らせ
10. グソっ君の特別なごはん

## ベスト5
1. 案3 田んぼ・牛舎だより（季節4回・最終更新日を出す）
2. 案1 合言葉で続きが開く（QRで1か所・季節ごとに全員共通・できている中身だけ）
3. 案9 お米のお知らせ（1回だけ・閉じられる・親向けの場所）
4. 案10 グソっ君の特別なごはん（案1の仕組みに相乗り）
4. 案6 レシピ（最初から全部読める。ゲームでは農家の裏話だけ開く）

## 見送り
- 案2 スタンプ：記録が端末で消える・値引き券を偽造できる → 値引きは紙の券で
- 案4 限定ステージ：期間限定は不満のもと → 案1の季節の中身の1つに
- 案5 カード8種：印刷・袋詰めが重い、そろわない不満
- 案7 定期便特典：名前の管理が重い。定期便ができてから
- 案8 ランキング：サーバーなしでは不正と参加確認ができない

## 全員から出た条件
- 合言葉は手で打たせない（QR。予備はひらがな4文字）。入口はポータルに1か所
- 記録が消えても、合言葉を入れ直せば戻る
- 買わないと遊べないのは「続き」と「おまけ」だけ。最初の体験は全部ただ
- 子どもの画面に「買って」を何度も出さない
- 始める前に「やめ方」と「効いたかの物差し」（注文ページの印、半年で判断）を決める
