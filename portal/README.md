# ゲーム一覧ポータル

自作のブラウザゲームを、動くプレビューつきのカードで並べるページを**自動で作る仕組み**です。
`games.json`（題材データ）を書き換えて命令を流すと、検証 → プレビュー録画 → ページ生成 → レビュー → QC まで回ります。

- できあがり：[`dist/index.html`](dist/index.html)（単体で開ける）、[`dist/embed.html`](dist/embed.html)（既存のページに貼る部分）
- 棚卸しの記録：[`INVENTORY.md`](INVENTORY.md)
- 手順書（Claude 用）：[`../.claude/skills/game-portal/SKILL.md`](../.claude/skills/game-portal/SKILL.md)。次からは「ゲームを1本追加して」で回ります

## 流れ

```sh
cd portal
node scripts/validate.mjs              # 3. 検証：必須項目・20字・URLの実在・重複。NG なら止まる
node scripts/prepare.mjs               #    ゲームを git の各ブランチから .work/ に取り出してビルド
node scripts/capture.mjs [id] --verify # 4. プレビュー録画（2回撮って同じ映像になるかも確認）
node scripts/build.mjs                 # 5. 一覧ページを dist/ に作る（検証 NG なら作らない）
node scripts/review.mjs                # 6. PC・タブレット・スマホ幅のスクリーンショット（review/）とはみ出し検査
node scripts/qc.mjs                    # 7. QC：リンク・再生（PC/スマホ/MP4）・JSONと表示の一致・重さ・絞り込み
```

## プレビューの撮り方（再現できる録画）

- ゲームを Playwright（自動操作するブラウザ）で実際に起動する。ゲームのファイルは書き換えない
- **時計を止めて1コマずつ進める**：ブラウザの時刻・タイマー・描画（requestAnimationFrame）を偽の時計に置き換え、
  1コマ＝80ms ずつ進めて撮る。CSS のアニメーションも同じだけ進める
- **乱数を固定**：`Math.random` を決まった種の乱数に置き換え、`h.ready()` の時点で最初に戻す
- 入力（クリック・キー・ドラッグ）は `recipes/<id>.mjs` に書いた順に、決まったコマで入れる
- こうして撮ると、**同じ手順なら毎回同じ映像になる**（`--verify` で確認）
- 撮れないゲームは、静止画をゆっくり動かす映像（パララックス風）で自動的に代わりを作る
- 出力は 640×400・12.5fps・5〜8秒の WebM（VP9）と MP4（H.264）、1本 1MB 以下。最初の静止画がポスターになる

## ページの動き

- カードは画面に入ったものから、**ばねの物理計算**で作った動き（CSS の `linear()`）で出てくる。
  枠が先に持ち上がり、少し遅れて映像、さらに遅れて文字が1行ずつ（枠と中身のタイミングをずらす）
- 動画は画面に近づいたときに初めて読み込み、離れたら止める。最初の表示では動画を読まない
- 「動きを減らす」設定の端末では、アニメーションと自動再生をしない（▶ で再生できる）
- ジャンルの絞り込み、ゲーム名・タグでの検索（ひらがな・カタカナどちらでも）
- 「開発中」はバッジを出し、遊ぶボタンを押せなくする
- カードに「遊ぶ時間・むずかしさ・こんなときに」を1行で出す。絞り込みはジャンルではなく気分（さくっと・じっくり・子どもと・のんびり）
- 動画の中に一言の字幕（`caption`）。「あそぶ」は全ゲーム同じ色で、「別の画面で開きます」と添える
- ゲームごとの直接リンク（`#game-<id>`）と、貼ったとき用の小さなページ（`dist/g/<id>.html`）・絵（`dist/og.jpg`）
- 一番下に、作り手の紹介と「最近の更新」（ゲームのソースの最後の変更日を git から自動で取る）

## 既存のサイトに組み込む

`dist/` の `portal.css`・`portal.js`・`previews/` を置き、`embed.html` の中身をページに貼ります。
スタイルは `.gp-portal` の内側だけに効くようにしてあります。
