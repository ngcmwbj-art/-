# みんなのランキングの作り方（Googleスプレッドシート）

ゲームの記録を Googleスプレッドシートにためて、だれでも（ログインなしで）ランキングに載れるようにします。
かかるのは 5 分ほどで、お金はかかりません。

## 1. スプレッドシートを作る

1. <https://sheets.new> を開いて、新しいスプレッドシートを作る（名前は「ビバベジ便ランキング」など自由に）
2. 上のメニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `function myFunction() {…}` を全部消して、このフォルダの `Code.gs` の中身を丸ごと貼り付ける
4. 上の保存ボタン（フロッピーの絵）を押す

## 2. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 「種類の選択」の歯車から **ウェブアプリ** を選ぶ
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「アクセスを承認」と出たら、自分の Google アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら **詳細 → （安全ではないページ）に移動** → **許可**
     （自分で作ったプログラムなので大丈夫です）
5. 出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピーする

## 3. ゲームに URL を入れる

コピーした URL を Claude に渡せば、ゲームに設定して公開し直します。
自分で入れる場合は、`keitora/index.html` の `const RANK_URL = '';` の `''` の中に URL を貼り付けます。

## 困ったとき

- **いたずらの記録を消したい**：スプレッドシートの `ranking` シートで、その行を右クリック → 行を削除
- **名前を直したい**：`名前` の列を書き換えるだけでランキングに反映されます
- **`key` の列**：その人の端末だけが自分の記録を書き換えられるようにする合言葉です。消したり見せたりしないでください
- **Code.gs を直したとき**：デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ（URL は変わりません）

送られてくる点数は、距離から見てありえない値なら受け付けません（1 m あたりトマト 17 個分まで）。
ただし完全なずる防止ではないので、身内で楽しむ前提のしくみです。
