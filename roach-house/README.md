# ゴキブリ大作戦 パプリカハウス

ゴキブリになってパプリカハウスに忍びこみ、出荷前の収穫コンテナをかじってダメにする 3D アクションです。
相手は農場主。殺虫剤とホイホイ（粘着わな）をかわしながら、食べて・産んで・仲間をふやして勝負します。

人間にばれないよう近づいて「吸う（食べる）」潜入型のゲーム性を土台にした、オリジナルのゲームです。

## 遊びかた

- 目標の数のコンテナをかじりつくせば勝ち（やさしい 6 箱／ふつう 8 箱／むずかしい 10 箱）
- トラックの出発時刻になるか、出荷が進みすぎて目標に届かなくなったら負け
- **がっつきゲージ**：食べるボタンは長く押すほど早く食べられるが、赤までいくと「バリッ」と音が出て農場主に気づかれる
- **農場主の視界**：地面の扇形。畝の葉の下・台の下でじっとしていれば見つかりにくい。歩きながら時々よそ見もする
- **産卵**：栄養が満タンで卵を産める。少したつと 3 匹の仲間になる（最大 9 匹）。目立つ所の卵は踏まれる
- **仲間への指示**：探索（自分でエサを探して食べる）／囮（農場主の前をうろついて気を引く）／集合（後ろについてくる）
- **突撃**：農場主の足もとで使うと顔に飛びつき、5 秒ほどパニックにできる。運んでいたコンテナも落とす。そのぶん怒りが上がり、わなが増える
- 自分がやられても、仲間がいれば 1 匹に乗りかわって続けられる

| 操作 | PC | スマホ・タブレット |
| --- | --- | --- |
| 移動 | WASD / 矢印 | 左下をなぞる |
| ダッシュ | Shift | スティックを端まで倒す |
| 視点 | マウスドラッグ / Q・E | 右側をなぞる |
| 食べる・登る・脱出 | Space（長押し・連打） | 「食べる」ボタン |
| 突撃 | F | 「突撃」 |
| 産卵 | R | 「産卵」 |
| 指示 | 1・2・3 | 右の「探索・囮・集合」 |
| 一時停止 | Esc / P | 「II」 |

## ファイル

```
index.html          ページ本体（ES モジュールで js/ を読む）
css/style.css       画面のデザイン
js/main.js          起動・カメラ・HUD・地図・ヒント
js/game.js          ゲームの中身（ゴキブリ・仲間・農場主・わな・殺虫剤・勝ち負け）
js/world.js         ハウスの間取りと見た目
js/models.js        キャラクターと小物の 3D モデル（基本形状だけで作成）
js/pathfind.js      農場主の道さがし（A*）
js/input.js         キーボード・マウス・タッチ
js/audio.js         効果音（WebAudio で合成。音声ファイルなし）
vendor/             three.js r170（MIT License）
tools/build-artifact.cjs  1 ファイル版 dist/artifact.html を作る
tests/              自動テスト（Playwright）
docs/kaizen/        改善会議の記録
```

## 動かしかた

ビルド不要です。フォルダで簡易サーバーを立てて開きます。

```sh
cd roach-house
python3 -m http.server 8765
# → http://localhost:8765/
```

## テスト

```sh
bash tests/run-all.sh
```

- `mechanics.cjs`：食べる・がっつき・産卵・3 種の指示・突撃・ホイホイ・登る/落ちる・乗りかわり・勝ち負け・道さがし（21 項目）
- `input.cjs`：本物のタッチ操作（スティック・視点・ボタン）、キーボード、一時停止（15 項目）
- `sim.cjs`：ボットが全難易度を最後まで遊び、例外・NaN・場外がないか、勝ち負けの釣り合いを確認
- `shots.cjs`：PC・スマホ縦・スマホ横のスクリーンショット
- `artifact.cjs`：1 ファイル版が動くか

## 調整の目安（自動プレイの結果）

地図を知りつくして隠れ方も上手なボットで、ふつうは残り 25〜185 秒で勝ち、むずかしいは時々負けます。
人が遊ぶと移動や視点操作のぶん遅くなるので、ふつうで「ぎりぎり勝てる」くらいを狙っています。
数値は `js/game.js` の `DIFFS` と、食べる速さ（`updatePlayer`）、農場主の速さ（`farmerSpeed`）で変えられます。
