# note の書き方

## 文体
- 普通の日本語で、具体的に書く。です・ます調（依頼主の確認が取れるまでの仮）。
- 不要な比喩や大げさな宣伝文句を使わない。
- 数字・出典・引用は確かめた物だけ使う。他人の文を長く引用しない。
- 牛・田んぼ・野菜の話は、依頼主（F1 肥育の農家）の経験と言葉を優先し、推測で補わない。

## 想定読者
- 要確認（例：ゲームを遊ぶ人、農業に興味のある人、個人でものを作る人 など。依頼主に決めてもらう）。

## 構成の型
1. タイトル（案を3つ）
2. 導入：だれに、何が分かる記事か（3〜4行）
3. 見出しごとの本文（見出しは 3〜5 個）
4. まとめ
5. ハッシュタグ案（5 個前後）
6. 見出し画像の案（必要なら生成の指示文）

## 有料部分
- 扱い：要確認（有料にするか、どこから有料か、価格。税込・税別もあわせて依頼主に確認する）。
