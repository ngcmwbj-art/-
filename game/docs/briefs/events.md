【あなたの担当: シナリオ実装（全NPC会話、調べる、ふしぎ、イベント、カットシーン、ゲーム全体の流れ）】
担当ディレクトリ: src/events/**, src/data/text/**（src/events/index.ts から登録）。他チームのAPIを使う。どうしても足りない機能は自分のディレクトリにアダプタを書くか、小さな追加が必要なら該当ファイルに最小限の追加をしてよい（既存の動作を壊さないこと、報告に書くこと）
主な参照: docs/design/10_narrative.md（最重要：全台詞、フラグ、イベントの台本）, 00_concept.md（7章 ビートシート、3.4 段階システム・17:00の瞬間 ★、9章 カネナリくん加入、10章 ボス、11章 ふしぎ、12章 エンディングと引き ★）, 30_level_art.md（配置座標）, 20_systems_battle.md, 40_audio.md（13章 イベントのキューシート）, 01_index.md（通しプレイの手順）
既に実装済み: src/world（scriptAPI: registerScript 等）, src/ui（say/choose/ask、メニュー、ショップ、セーブ、HUD、タイトル）, src/battle（startBattle、データ）, src/art/chars（キャラ、エモート）, src/audio（BGM/SE/環境音）, マップ（町、家、店、モール）。まずこれらのAPIと既存の配置データを読むこと。

実装するもの:
1. ニューゲームの開始（タイトルの「はじめる」→ 16:52 自室で目を覚ます）から、エンディング（夜の町→家→窓、写真館、星見台のチラ見せ、カネナリくんが初めて声を出す）、そしてタイトルへ戻るまでの全フロー
2. 全NPCの会話（段階0/1/2/夜の差分、2回目以降の差分、フラグ差分）、全ての調べる物、ふしぎ（12か所、みましたハンコで押す）、みました帳への記録
3. 全イベント（evt_*）：母のおつかい（500円、「ソースは別」）、3つの違和感、肉屋「揚げたては…」、ひのや、17:00の瞬間 ★（チャイムが4音目で途切れ、NPC全員が空を見上げて3秒止まる、画面の縦方向正弦波0.8秒、BGMが半音下がって止まる、時計停止、色温度遷移）、ハト係長のチュートリアル戦闘とレベルアップ、おばあからハンコケース（みました・ペケ）＋フィールドチュートリアル、路地の開放、カネナリくんのイベント戦闘と加入（はなまる）、防災無線「迷子のお知らせ」→段階2（影が北東、チェーンが外れる）、おじぎ自販機（中ボス）、モールのイベント（噴水、ガチャ、のらカート、回転焼き機の鍵イベント「迷子センターの鍵」「やりなおし」）、2Fベンチのセーブ、ボス オムカエマチ（戦闘は battle チーム実装、前後のカットシーンはあなた）、エンディング
4. 導線：プレイヤーが迷わないように、NPCが自然に次の行き先をヒントする。進行不能（詰み）が起きないことを確認（お金、鍵、フラグ）
5. 通しプレイの自動テスト: tools/playthrough.mjs（Playwright）を作成し、デバッグコマンドとキー入力で、ニューゲームからエンディングまで通しで進められることを確認する（戦闘は __game.cmd.win() 等で短縮してよいが、少なくとも1回は実際にコマンド入力で戦う）。各ビートでスクリーンショットを /tmp/claude-0/shots/playthrough/ に保存
6. デバッグ: __game.cmd.jump('<beat>')（各ビートの状態へフラグ・位置・パーティをそろえて飛ぶ）
品質: 設計書の台詞を正確に。テンポ（会話の間、カメラ、エモート、SE）を作り込み、演出の気持ちよさを市販RPG水準に。全ビートを実際にプレイしてスクリーンショットで確認すること。
