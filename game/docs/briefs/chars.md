【あなたの担当: キャラクターアート（フィールドスプライト全般、顔グラ、エモート、敵シンボル、もとにもどった物）】
担当ディレクトリ: src/art/chars/**（index.ts の registerChar / registerPortrait / emotes.ts の registerEmote の契約は維持。中身の追加は自由）
主な参照: docs/design/00_concept.md（3.6 光と色、4章 キャラクター、8章 敵の見た目、6.7 もとにもどった物）, docs/design/30_level_art.md（キャラのドット絵仕様、パレット）, 10_narrative.md（全NPCの見た目の一行説明とID）, 20_systems_battle.md（敵）, 01_index.md

実装するもの:
1. フィールドスプライト（16×24 基本、特別なキャラは設計どおりのサイズ）：4方向×歩行サイクル（4フレーム以上、walk[dir][0]が立ち）＋待機（呼吸・まばたき）。主人公シュン（寝ぐせのアホ毛、大きすぎる緑Tシャツの魚プリント、紺の短パン、赤いビーサン、青い紐の鍵、背中の虫とりアミ等 設計どおり）、カネナリくん（真鍮色の鐘の頭、点目と頬、夕焼け色のもこもこ、たすき、背中の少し開いたファスナー。歩くと鐘がわずかに揺れる）、母、ひのやのおばあ、肉屋、まめ吉、ランドリーの青年、鶴見巡査、踏切の女子高生、郵便屋、砂場の女の子、影だけの人、その他10_narrative.mdに出てくる全NPC（IDは設計書のnpc_*）、動物（ネコ複数柄、ハト、スズメ（電線用の小さいもの）、カラス等 設計に出るもの）。必要な特別ポーズ（extra: 'surprised','look_up','sit','sleep','hurt' など、シナリオで使うもの。17:00の瞬間に全員が空を見上げる 'look_up' は全NPC・動物に必須）
2. 敵のフィールドシンボル：全7体（ハト係長、セミファイナル、コーン・ボーカル、ワスレガサ、おじぎ自販機、ソウジロウ、モミスギ）を registerChar(<enemy_id>) で。6.11のシンボルの動き用のフレーム（つつく、跳ねる、回転灯、手招き等）を extra に
3. もとにもどった物：registerChar('restored_<enemy_id>')（つつくハト、まっすぐ立ったコーン、塀に立てかけた傘、木にとまるセミ、充電台に戻った掃除機、「お試し中止」札のマッサージチェア、おじぎ自販機は設計を確認）
4. 顔グラ（戦闘のステータス枠用 32×32）：registerPortrait('minato', mood) と registerPortrait('kanenari', mood)。mood = 'normal','hurt','tsukkomi','happy','surprised','ko' 全部。カネナリくんは「しゃべれない」のでフリップを持つ顔等の工夫。会話用にも使えるよう主要NPC（母、おばあ、肉屋）の顔も作ると良い（任意）
5. エモート（emotes.ts）：exclaim, question, dots, note, sweat, anger, heart, zzz, light の全種をアニメ付き（ポップして出る）で registerEmote
6. カネナリくんのフリップ（会話用の手書きボード）の絵：export function flipBoard(): HTMLCanvasElement 等、UIチームが使えるように
7. 確認用ギャラリー：registerScene('chars', ...) で全キャラを4方向・歩行アニメ・待機・extraを一覧表示し、背景に夕方の地面色を敷く（見え方の確認用）。?scene=chars
品質：光源は左（西）の夕日。左上ハイライト、左縁に #F2894B 系1pxリムライト、セレクティブアウトライン（外周 #2A2440 基本、内側は塗りより1〜2段暗い同系色）。純黒禁止。16×24でも一目で誰かわかるシルエットと配色。歩行はボブ（上下1px）と腕振りまで。市販の高品質ドット絵RPG（例: 近年のSteamのインディーRPG）のキャラと並べて見劣りしないこと。ギャラリーを3倍・6倍拡大で撮って厳しく見ること。
