【あなたの担当: UI一式（ウィンドウの見た目、会話、メニュー、タイトル、HUD、ショップ、セーブ、設定、ゲームオーバー）】
担当ディレクトリ: src/ui/**（ui/dialog.ts の say/choose/ask と ui/window.ts の drawWindow/UI は、シグネチャを維持したまま中身を作り直してよい。関数の追加は自由）
主な参照: docs/design/00_concept.md（14章 UIの方針 ★、7章 ビートシートのタイトル、15章 禁止リスト）, docs/design/30_level_art.md（10章 UIのビジュアル方針「夏休みのノート」、11章 タイトル画面のデザイン）, 10_narrative.md（メニュー・システムメッセージの文言、ショップ、セーブ、みました帳の項目）, 20_systems_battle.md（アイテム・能力・成長・通知表の表示項目）, 40_audio.md（UIのSE ID、タイトル曲）, 01_index.md
既に実装済みの他チームの成果（読んで使う）: src/world（フィールド、スクリプトAPI）, src/battle と src/data/battle（アイテム/能力/メンバーのデータ、フィールドでのアイテム使用関数）, src/art/chars（portrait(), flipBoard 等）, src/audio（sfx, playBgm 等）

実装するもの:
1. ウィンドウの見た目を「夏休みのノート」へ（方眼ノートの地、枠、角丸、影、マスキングテープの名札、朱色の小さなハンコのカーソル＝決定で1px沈む）。drawWindow を置き換えるとフィールドの会話・選択肢がすべて新デザインになる。戦闘側が自前でウィンドウを描いている場合は見た目が揃っているか確認し、差があれば報告に書く
2. 会話ウィンドウの仕上げ：名札（マスキングテープ）、声（voiceId）によるブリップ、{w}{shake}{wave}{c}の表現、送りマーク、早送り、カネナリくんの「フリップ」会話（手書きボードが出る専用表示。src/art/chars の flipBoard 等を利用）、ミナトの心の声（10_narrative の書式に従う）、ask() の多ページ対応の修正、テキスト速度設定の反映
3. フィールドメニュー（キー: menu（C/Tab）と cancel(X) の両方で開く）：もちもの（使う/わたす/すてる、説明文）、ハンコ（ハンコケース8枠、フィールドで使えるハンコの使用）、つよさ（通知表の形式）、みました帳（「ふしぎ」「あいて」「ツッコミ」の3頁、既読/未読）、せってい（BGM/SE音量、文字の速さ、ツッコミ判定 ふつう/ひろい）。全項目を実装し、未実装の項目は置かない。カーソル移動/決定/キャンセルのSE、開閉アニメーション
4. HUD：右上の時計プレート（16:52→16:55→16:58、17:00で停止・コロンの点滅停止、段階2で秒針が戻る演出、夜は進む）、左下のハンコアイコン（ふしぎの知らせ）、場所名の表示（マップに入った時に短く）、アイテム入手の通知
5. タイトル画面（registerScene('title', …)。11章のデザイン：止まった夕焼けの町を背景に、ロゴがハンコでペタンと押される、チャイムの動機が4音目で止まる、「はじめる」「つづきから」（セーブが無ければ無効表示））。はじめる→ワールドのニューゲーム開始（src/world の API を確認。シナリオチームがオープニングイベントを後で差し込めるよう、ニューゲーム時に呼ばれるフック registerNewGameHook 等を ui 側か world 側の既存APIで用意）
6. ショップUI（ひのや等。品物、値段、所持金、買う/売る必要なら設計書どおり、ツケの仕組みが設計にあれば対応）とセーブUI（お地蔵さん・モール2Fのベンチから呼ばれる。save()/load()）をシナリオチームがスクリプトから呼べる関数として公開（例: yield* openShop('shop_hinoya'), yield* saveMenu()）
7. ゲームオーバー画面（registerScene('gameover')、設計書どおりの復帰）と、エンディング後の「つづく」画面が設計にあればその画面部品
8. 全画面のトランジション（場所移動のフェード等）で見た目の統一感
9. デバッグ: __game.cmd.menu(), __game.cmd.title(), __game.cmd.shop(id) など
品質: 市販インディーRPGのUIと並べて見劣りしないこと。文字の読みやすさ（行間・余白・コントラスト）、情報の整理、アニメーション（開閉、カーソル、選択時の反応）の気持ちよさ。MOTHER2の黒地白枠ウィンドウに似せない。全画面を3倍で撮って厳しく確認すること。
