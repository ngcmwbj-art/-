【あなたの担当: 屋内マップとモール（ダンジョン）のレベルデザインと環境アート】
担当ディレクトリ: src/data/maps/**（map_town と map_home_* 以外の新規マップ）, src/art/props/**（屋内・モール用の新規ファイルのみ。既存ファイルはワールドチームが修正中なので編集しない）, src/art/tiles/**（屋内・モール用の追加）。【注意】ワールドチームがレビュー指摘の修正を並行して行っているので、src/world/** の既存ファイルは編集しないこと。屋内表現のための機能（照明、固定カメラ、演出など）はまず既存のAPI（room_shell / roomShell() など）で実現し、どうしても足りない場合だけ src/world/ に新規ファイルとして追加する（既存ファイルへの1〜2行のフック追加が必要なら報告に明記し、最小限にする）
主な参照: docs/design/30_level_art.md（4章 屋内マップ、5章 ショッピングプラザ・ユウナリ、6章 バリエーション計画、7章 アートディレクション）, docs/design/00_concept.md（3.3 屋内マップ、11章 ふしぎ、6.11 エンカウント）, 10_narrative.md（屋内のNPC・調べるテキスト）, 20_systems_battle.md（モールの敵配置）, 01_index.md
既に実装済み: src/world（マップ形式・レンダラ・エンティティ・スクリプトAPI）、map_town、ミナトの家。まず src/world と src/data/maps の既存マップの書き方を読み、同じ形式で作ること。

実装するもの:
1. 屋内マップ: map_maruyama（肉のマルヤマ：ショーケース、揚げ場の油の鍋が静かに光る）, map_hinoya（駄菓子の棚、くじ、文房具の小棚）, map_laundry（乾燥機6台、3番が回り続ける）, map_koban（机、地図、落とし物の掲示板）。設計書のレイアウト・出入口・NPC・調べる物をすべて配置。店ごとに生活感と固有の小物を作り込む
2. モール: map_mall_hall(M1), map_mall_food(M2), map_mall_health(M3), map_mall_2f(M4), map_mall_maigo(M5)。黄ばんだ蛍光灯（ちらつき）、天窓から差す夕日の斜めの光、忘れ物の山、枯れた噴水（底に10円玉）、ガチャコーナー、フロア案内板、止まった時計、回転焼き機（勝手に回る）、テーブルといす、忘れ物カウンター、マッサージチェアの列、ぶら下がり健康器、止まったエスカレーター（上れる）、休憩ベンチ（セーブ/回復）、シャッターの店、迷子センター（小さなカウンター、放送マイク、忘れ物の山）。動線（M1→M2（鍵）→M1→M3→M4→M5）と鍵イベントの場所、敵シンボル（ソウジロウ、モミスギ）の配置と動き
3. 各マップの接続（door_*）を設計書どおりに。町の door_town_* からの行き来が全部つながること（flag_ojigi_beaten 等の条件も）
4. 屋内のライティング（蛍光灯の光だまり、天窓の光の筋、油の鍋の光、自販機の光など）とアンビエンス（蛍光灯のハム等は audio の playAmbience を使う）
5. デバッグ: 既存の warp で全マップへ飛べることを確認
品質: 市販の16bit風インディーRPGの屋内・ダンジョンと並べて見劣りしないこと。同じタイルの連続を避け、1画面に調べられる物5つ以上・動く物3つ以上・固有の小物1つ以上。全マップをスクリーンショットで厳しく確認すること（各マップ複数か所、3倍）。
