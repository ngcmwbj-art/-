## 0. この本の使い方

### 0.1 座標と記号

- 座標は**タイル単位**（1タイル＝16×16px）。原点はマップの左上。x は右、y は下に増える。`(x,y)` と書く。
- 範囲は `x0–x1, y0–y1`（両端を含む）。
- NPC と敵シンボルの座標は**足もとのタイル**。
- 小物の座標は**衝突範囲の左上のタイル**。見た目は上へはみ出してよい（電柱、木、時計塔など）。
- 壁の高い所にある物（看板、時計、窓、ポスター）の座標は**見た目の位置**。調べる判定は、その真下の**壁の一番下の行**のタイルに置き、その下の歩けるタイルから北を向いて調べる。
- 描画の前後は**足もとの y**（ピクセル）で並べる。背の高い物も、足もとの y で判定する。
- 向きの表記：`N`（上）`S`（下）`E`（右）`W`（左）。
- 「画面」は 24×13.5 タイル（384×216px）。

### 0.2 コンセプトからの変更点（レベル側で決めたもの）

| 変更 | 内容 | 理由 |
|---|---|---|
| 外マップのサイズ | **64×44**（コンセプトの初版は 64×40。00_concept も 64×44 に更新済み）。y40–43 の4行を足した | 南の端に**用水路の対岸と田んぼの眺め**を置くため。y0–39 の座標はコンセプト・シナリオの目安と同じ範囲のまま使える |

### 3.3 区域ごとの設計意図

**A ひぐらし坂（x0–22, y16–34）**
- 自宅（x0–7, y25–31）は南西。玄関 (4,30) を出ると門 (4,31)、その前が**川べり通り**。
- 坂（ひぐらし坂）は x14–18 の南北の道。上（北）がひぐらしの木と路地、下（南）が川べり通り。y26–27 で1タイル西へ折れる**クランク**になっていて、曲がり角にカーブミラー (17,27)。
- 坂の上（x16–23, y21–25）は**辻の広場**。西へ「上の道」（y21–22）、北へ路地、東へアーケードの入口、南へ坂。ここが町の交差点になる。
- 自宅と水まきの家の裏には細い**裏庭の帯**（y24）があり、家と家の間の側道（x8）からだけ入れる（寄り道、3.12）。
- 空き地（x0–6, y16–20）は中学生の修行場。トラロープで囲い、入口は (4–5,20)。

**B 夕鳴銀座（x23–57, y16–34）**
- **北の列**（x24–55, y16–21）はアーケードに正面を向けた看板建築。西から 肉のマルヤマ（x24–29）／駄菓子ひのや（x30–34）／豆腐まめ吉（x35–38）／時計店チクタク堂（x39–42）／駐車場へのゲート通路（x43–45）／喫茶 夕顔（x46–50）／山吹酒店（x51–55）。
- **アーケード**（x23–55, y22–25）は床に夕日の縞が落ちる。南の縁（y25）に柱、ベンチ、掲示板、ポストが並ぶ。
- **南の列**（x24–55, y26–31）は川べり通りに正面を向ける。西から コインランドリー ふわり（x24–28）／猫の抜け道（x29）／夕鳴写真館（x30–34）／シャッター1（x35–38）／シャッター2（x39–42）／中通り（x43–45）／シャッター3（x46–49）／交番（x50–53）／交番の横（x54–55）。

**C 夕鳴公園（x0–31, y0–15）**
- 南の入口（x18–20, y15）は路地の出口。入口の左右に禁止の看板 (17,14) と案内板 (21,14)。
- 中央の**時計塔広場**（x12–19, y3–10、石畳）。時計塔 (15–16, 6–7)。カネナリくんはこの石畳の上を周回する。
- 北西にトイレ、ブランコ、藤棚のベンチ、カバの遊具。北東に鉄棒、防災スピーカー柱。東に砂場。
- 東の生け垣のすき間（x31, y9–11）が駐車場への近道。段階2までチェーン。

**D 駐車場・モール前（x32–57, y0–15）**
- モール（ショッピングプラザ・ユウナリ）の正面（x34–57, y0–5）。入口の自動ドア (50,5)。

**踏切（x56–63, y19–27）**
- アーケードの東の端から道が踏切（x58–62, y22–24）へ続く。線路は南北（x60）。遮断機は下りたまま。
- 線路は用水路の上を鉄橋（x59–61, y36–37）で渡る。

**用水路と対岸（x0–57, y32–43）**

### 3.7 電柱・電線・街灯

- **電柱**（`prop_utility_pole`）：足もと 6×6px の衝突。高さ 64px（4タイル）。上から「腕金と碍子（3本の電線）」「変圧器（柱によって有無）」「低い電線とケーブル（2本）」「巻き付け看板（柱によって内容が違う）」「住所表示板（青 #2F4A8A に白文字の帯）」「足場ボルト」。
- **電線**：隣り合う電柱の同じ高さの点を、たるみ（中央で 6〜10px 下がる放物線）でつなぐ。1pxの #2A2440（太いケーブルは 2px の #3A2B5C）。**前景レイヤー**（キャラより上）。家へ引き込む線（電柱から屋根の角へ）も各家に1本ずつ引く。
- 電線のつなぎ方：
  - 上の道：(3,23)→(13,23)（**5本**。fushigi_03 の五線譜。ここだけ低い電線を5本にする）→ (21,15)（路地の上を斜めに渡る）
  - 坂：(13,23)→(18,28)→(22,35)
  - 川べり通り：(6,35)→(22,35)→(34,35)→(46,35)→(56,21)（交番の横を斜めに上がって踏切へ）
  - 駐車場の照明灯は電線なし。
- **街灯**：段階0〜2は昼の光で消えている（ガラスに空が映る）。段階2はランダムに明滅（点く時間 80〜300ms、間隔 2〜6秒）。夜は点灯し、足もとに半径 40px の光の円（#FFE7A3、スクリーン合成 α35%）。
  - 街灯の場所：川べり通りの電柱の4本と坂の電柱に「防犯灯」を付ける。アーケードは柱の提灯が灯る。公園は時計塔広場の四隅に公園灯（見た目のみ、衝突なし：(12,3)(19,3)(12,10)(19,10)）。

### 3.10 見下ろしの約束事

- 看板、のぼり、標識、表札、ポスター、アーチの板は**すべて画面（南）向きに描く**。道の向きに合わせて横向きにしない。
- 建物はすべて南に正面を向ける。北向きの正面は作らない（0.2）。
- アーケードの屋根そのものは描かない（視界をふさぐため）。屋根は床の縞、柱、提灯、アーチ、薄い前景（7.6）で感じさせる。
- 空は見えない。空の色は、水面の映り込み、光と影の色、画面の左から差す夕日のにじみ（7.3）で見せる。

## 6. 「同じ素材の繰り返し」に見せないためのバリエーション計画

### 6.1 原則

1. **変種の選び方**：地面は1種類につき基本の変種を3〜4枚持つ。変種の番号は `hash2(x, y) % n` で決め、左2枚（または上2枚）と同じ番号になったら次の番号にずらす。これで同じ絵が3枚以上一直線に並ばない。
2. **デカールを2層重ねる**：
   - ランダム層：`hash2(x+97, y+13)` が確率 p を超えたタイルに置く（ひび、汚れ、小石）。
   - かたまり層：`valueNoise(x/5, y/5)` がしきい値を超えた所にまとめて置く（落ち葉、苔、砂ぼこり、水じみ）。自然な「むら」になる。
3. **手置きのデカール**：マンホール、道路の文字、水たまり、横断歩道のかすれは座標を決めて置く（6.3）。
4. **境界はオートタイル**：草・土・砂・水・生け垣・歩道の縁石は、8近傍（47枚ブロブ方式）でつなぐ。境界は直線にせず、2px のでこぼこと小石・草の飛び出しを入れる。
5. **家・店・塀は1軒ずつ別の素材**（6.2）。同じ素材を使うときは色か汚れの位置を変える。
6. **合格の基準**：どの画面のスクリーンショットでも、同じ絵のタイルが一直線に6枚以上並んで見えないこと。同じ小物が同じ向きで3つ以上並ばないこと（柱や電柱は、看板・巻き付け広告・汚れで描き分ける）。

### 7.2 色の決まり

- **色相をずらした段階（ランプ）**：影は紫へ（#5B4A7A 方向）、光は黄橙へ（#F7C27A 方向）ずらす。影を灰色にしない。
- 1つの素材は**4段まで**（光・地・影・最暗）。5段目が要るときはディザで作らず、形を分ける。
- 彩度は、画面の奥（北、上）と影で1段落とす。行き先と手前のキャラに彩度を集める。
- 純黒 #000000 は使わない。最暗は #0B0B14（虚）、実用の最暗は #2A2440。
- 純白 #FFFFFF は使わない。いちばん明るいのは #FFF6D8。例外は、半透明・水・ガラスの反射のハイライト1〜2pxだけ（ワスレガサの膜、コーンの縞の光沢、しずく、逆さ雨の先頭、自販機のガラス。20_systems_battle 11章・17章）。戦闘の白フラッシュは #FFF6D8（20 16.0）。

### 7.3 段階ごとのカラーグレーディング

2. **左からの夕日のにじみ**（`screen`）：画面の左端から幅45%まで、横のグラデーション（左端の α → 0）。

### 7.4 光源と影

**光源**：西の低い夕日。画面の**左、少し上**から当たる。
- 面の明るさ：左向きの面（西）＞ 上面 ＞ 画面向きの面（南）＞ 右向きの面（東）。
- 建物の南の壁は斜めから光が当たるので、壁の左 1/3 を1段明るく（2px のディザでぼかす）。
- 壁から出っぱった物（看板、室外機、ひさし、雨どい、表札）は、**壁の上に右へ短い影**（2〜6px、#3A2B5C α30%）を落とす。夕方らしさの決め手なので、建物の正面に必ず入れる。
- ひさしと屋根の下には 2px の影の帯（#3A2B5C α40%）。

**長い影（地面に落ちる影）**
- すべてのキャラと、高さ 12px 以上の小物が持つ。スプライトの不透明なピクセルを影の色で塗ったシルエットを、足もとを基準に傾けて描く。
- 足もとの点を (bx, by)、スプライトの足もとからの高さを h px とすると、影のピクセルは `(bx + u + L·dx·h, by + L·dy·h)` に置く（u は横の位置）。Canvas では `setTransform(1, 0, -L*dx, -L*dy, bx, by)` を足もと原点で描いたシルエットにかける。スムージングは切る。
- 向き `(dx, dy)`：
  - 段階0・1：`(1.0, 0.25)`（東南東。光が左の少し上から来るので、影は右へ長く、少し下がる。人の影は高さ 24px なら右へ約 34px、下へ約 8px の寝たシルエットになる）。
  - 段階2：物からモールの入口 (50,4) へ向かう角度 θ を、東〜北（0°〜90°）の範囲に丸め、`(cosθ, −0.65·sinθ)`。**どの影も、その場所からモールを指す**。回るときは 1.2秒で補間する（`fx_shadow_swing`）。
  - 例外：`npc_shadow_man` の影は向きを変えない（本人が影なので）。
- 長さ L：段階0 は 1.3 から 10秒ごとに +0.02、最大 1.5。段階1 は 1.4 で固定。段階2 は 1.2。
- 影は物より先に（地面の上に）描く。水面の上の影は α を 0.6倍にする。
- **足もとの丸い影**：すべてのキャラと小物に、幅＝スプライトの幅の70%、高さ4px の楕円（#2A2440 α40%）。全段階。
- **建物の影**：建物は長い影を描かない。代わりに建物の東どなりの地面に 12px 幅の影の帯（#3A2B5C α30%、奥ほど細く）を置く。
- **木の影**：樹冠の影は東へ伸ばし、中に木漏れ日の点（#FFE7A3 α20%、4〜6px の丸、ゆっくりまたたく。段階1は止まる）を抜く。
- **夜**：太陽の影を消す。街灯の光の円（半径 40px、#FFE7A3、screen α35%）と、窓の明かりの四角（#F6D98A、α30%）を地面に落とす。

### 7.9 ドットの描き方

- ピクセルのかたまりは 2px 以上。1px のばらばらのノイズでテクスチャを作らない（タイルがざらつくだけになる）。
- ピロー・シェーディング（外周から内側へ同心円に暗くする塗り）は禁止。光は必ず左上から。
- ディザは2つの場合だけ：①大きな面のグラデーション（空、水面、モールの壁）②もこもこした素材の縁（カネナリくんの胴）。チェッカー以外の模様ディザは使わない。
- アンチエイリアスは曲線の段差にだけ、中間色1色で。
- 質感は「かたまりの形」で出す：アスファルトは粒、瓦は行の段、トタンは縦の波、ブロック塀は目地、木は葉の房（3〜5px の丸いかたまり）。
- 読みやすさの3段階テスト：どの物も「光・地・影」の3つの明るさで形がわかること。グレースケールにして確かめる。
- キャラと背景の分離：背景は明るさの幅を狭く（中間〜やや暗）、キャラは明るさの幅を広く（最暗の輪郭と明るい肌）。キャラが背景に埋もれたら、背景の方を1段落とす。
- 文字を絵に描くとき（看板、ポスター）は、読めなくてよい所は「字らしい線」で済ませ、読ませたい所だけ手描きドットの字にする。

## 10. UIのビジュアル方針「夏休みのノート」

### 10.1 意匠の核

- すべての窓は**方眼ノートの切れ端**。部品は、マスキングテープ（名札）、朱のハンコ（カーソル、決定、判定）、蛍光ペンの線（選択中の行）、付箋（通知・チュートリアル）、通知表（つよさ・レベルアップ）、がま口（お金）。
- 子どもの持ち物だけで UI を作る。未来的な枠、金属の枠、宝石のカーソルは使わない。
- **使わないもの（00_concept 16章）**：黒地に白枠の窓、太いクラシックな枠、市松模様の背景、ドラム式に回る HP。

### 10.3 窓の描き方（`drawWindow`）

1. 影：外の矩形を (+2,+2) にずらして #5B4A7A α50%。
2. 枠：#2A2440 の 2px。四隅は 1px 丸める（角の1ピクセルを抜く）。
3. 紙：#FBF3DC。
4. 方眼：内側の左上を起点に 8px おきに 1px の #E8D9B5。
5. 余白線：会話とメッセージの窓だけ、左から 16px に縦 1px の #E0567A α50%。
6. 大きい窓（高さ 80px 以上）は右下の角を 4px めくる（#E8D9B5 の三角と 1px の影）。
- 開くとき：下から 6px 上がりながら 120ms でフェードイン。閉じるとき 90ms。
- 文字は窓の中では輪郭なし（#2A2440）。画面の上に直接出す文字（場所の名前、ふきだし以外の浮き文字）は #FBF3DC に 1px の #2A2440 の輪郭。
