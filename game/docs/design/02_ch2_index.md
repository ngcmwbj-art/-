## 1. 全体の要約

### 1.1 作品（第2章）

- **章題**：第2章『星見台のトマト』。第1章のエンディングの直後（8月31日 19:30、踏切）から始まり、夕鳴町 19:31 に帰ってきて終わる。
- **ログライン**：夏休み、最後の夜。踏切で止まった明かりのない電車に乗ると、着いたのは山の上の小さな村・星見台だった。人口12人の村は、朝の5時1分前で止まっている。朝が来ないので、トマトは赤くならず、牛のエサの時間も来ない。村でたった1つ赤くなったのは、夕鳴町の長い夕焼けをためこんで、ぼんやり光る「はなまるトマト」。しゅんはそれを虫とりアミに入れて提灯にし、カネナリくんと夜の村を照らして回る。山の上の防災無線は、村を出ていった人たちの名前を、今夜も呼び続けている。
- **プレイ時間**：初見・寄り道ありで約10分（タイトルに戻るまで約12分。エンディングのあとのツガオの場面 約1分25秒を含む）、必須だけで約7分〜7分30秒（見積もり。ツガオの場面は別。8章）。任意のサブイベント2つ（牛舎のおてつだい 約1分20秒、野菜の配達 約1分50秒）は、この時間の外。
- **第3章へのつなぎ**：村では、転回場の軽トラで寝ている「ツガオ便」の運び屋ツガオさんと、仕事仲間のヒロスケさん・ポコシャさん（とめんどりのぴーちゃん）を、気のいい人たちとして見せる（50 3.14〜3.16）。「つづく」のあとに、闇の組織「まだまだ団」の団長ツガオが、夕鳴町と星見台の報告を受ける場面（50 10.16 カット7）。作業帽・軽トラの鍵・黄色いコンテナ・口癖で、あの軽トラのツガオさんだとわかる（どんでん返し）。オムカエマチとヨビモドシの想いは本物のままで、ツガオはそこに黒い判「まだ」を押して時間を止めていた。次は「海ぞいの 町」。
- **3本柱の広げ方**：①「みました」＝見てもらえなくなった**村と畑**を認める。最後はカネナリくんのPR（見てもらう仕事）で夜の村を照らして見せる ②ボケとツッコミ＝村のモノは「働きすぎ」「待ちすぎ」「すねすぎ」のボケ。新しいハンコ「おつかれさま」で働きすぎを休ませる ③止まった夜の村が**よなか→ともしび→よびごえ→あさ**と変わる。第1章が「こわれていく」なら、第2章は「ともっていく」。
- **トーン**：笑い7：切なさ3。恐怖演出なし。暗がりは「こわい」ではなく「見えない」だけ。泣かせるのはエンディングの日の出の30秒だけ。農家・高齢者・過疎・方言をばかにする笑いは禁止（50 2.1）。

### 1.2 世界のルール（第2章で足すもの）

- 星見台は **4:59** で止まっている（朝5時の防災無線の「朝のチャイム」の1分前）。HUD の時計はコロンが点滅しない。
- **止まっている町で過ごした時間は、ほかの町では数えない**。星見台でひと晩すごしても、夕鳴町では1分（19:30 → 19:31）。しゅんの「すぐ もどる」がそのまま本当になる。
- 朝が来ない理由：防災無線は毎晩「おやすみ放送」で1日をしめていた（分校のまつ先生が30年読んだ）。この夏のお盆に出ていった人がだれも帰ってこず、その晩から出ていった人の名前を**出席をとるように**呼びはじめた。へんじがないので点呼が終わらず、「おやすみなさい」まで行きつかない。この想いがボス「**ヨビモドシ**」。
- **ヨビモドシとオムカエマチは対**：オムカエマチは「名前を呼ばれるのを待っていた」忘れ物たち。ヨビモドシは「名前を呼び続けている」スピーカー。ヨビモドシの欠点は、村に残っている12人を一度も呼んでいない（見ていない）こと。
- **はなまるトマト**：夕鳴町の夕焼けの色が山を越えてこぼれ、3号ハウスのトマトが1つだけそれをためこんだ。持っていると暗がりが見える。最後に夜空へ届けると、夕焼けが朝焼けになって朝が来る。
- **またたかない星**（第1章のエンディングで止まった星）は明けの明星（金星）。朝が来ると空にとける。
- **ツガオとまだまだ団**（50 1.2）：ツガオは人やモノの「まだ」（まだ来ない、まだ朝じゃない）に黒い判「まだ」を押して、その時間を終わらせず、「休みの貯金」としてためている。しゅんの朱のハンコは、その上から押されて時間をほどいた。見た目は組長のような風貌、性格は冷静、口癖は「つがおちゃん 寝る〜♪」、手下はタイムレコーダーの形の機械「ダコク」（事務所の机の上の記録係。報告するのはダコクだけ）。**表の顔**はツガオ便の運び屋で、ふもとの町から40年、星見台に通っている。仕事仲間のヒロスケさん（44。社交的で人なつこい。口癖「焼き芋 食うか？」）とポコシャさん（40。とてもシャイ。口癖「さすが 師匠！」が思わず大きな声で出て照れる。めんどりのぴーちゃん）は、まだまだ団の外で動く参謀（第2章ではにおわせるだけ。第3章で明かす）。3人とも**村の12人に数えない**（ふもとから通う。さんかどと同じ）。星見台の黒い判は、お盆の晩に、観望会の望遠鏡を運んで丘へ行けるツガオが柱に押した（50 1.2）。
