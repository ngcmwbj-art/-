## 2. 第1章の流れ（変わる所）

## 3. 第1章の決着（練り直し）
**ボス**：オムカエマチは、迷子センターで迎えを待ちつづける迷子。「おむかえ、まだ かな」。5時のチャイムが4音目で止まり、町の時間が止まっている。

**グソっ君との重なり**：グソっ君も、どこから来たのか分からず、だれも迎えに来なかった。
- オムカエマチの技「よいこは おうちへ かえりましょう」で、グソっ君は帰りかける。
- でも「……帰る 家、分からへんかったわ」と、すぐ戻ってくる。今のまま残すが、今より重くなる。

**決着の流れ（案）**：
1. 最終局面。いくらハンコを押しても、オムカエマチは「おむかえ、まだ かな」をくり返す。
2. グソっ君が、戦いの構えをといて前に出る。海で敵なしだった強さを、使わない。
3. しゃがんで手を出す（保育園のお迎えのように）。
   - グソっ君「……迎えに 来たで。」
   - 「わいもな、だれも 迎えに 来ぇへんかってん。せやから、分かるねん」
   - 「いっしょに 帰ろ」
4. オムカエマチがその手をにぎる。そのとき、遠くの時計塔のチャイムが、止まっていた4音目を鳴らす。
   - 今のボスの鐘の音と、曲がハ長調に戻る変わり方は、「チャイムの4音目」として使う。
5. 時間が動き、ハンコ「おかえりなさい」が浮かぶ。しゅんが押す。
   - グソっ君「……ええ ハンコやな。わいも いつか、押して もらえるやろか」。第3章でツガオと向きあう伏線だが、ばれない。

**ねらい**：
- だれも倒さない決着のまま、グソっ君の「海で敵なし」の強さを「手を出す」やさしさに変える。
- 「迎えに行く」は、おばあの「だれも、迎えに 行って ないんだ」への答えになる。
