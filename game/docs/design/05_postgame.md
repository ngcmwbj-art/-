## 1. ひとことで

**ツガオ便の1日が、クリア後の時計になる。**
ツガオ便は毎日、夜明け前に星見台で野菜を積み（第2章）、朝5時すぎに夕鳴町の焼きそばのたかしへ届け（第3章 S33）、昼に海ぞいの町の港へ着き（第3章）、夕方に夕鳴町へ帰ってくる（第3章 S32、第1章の交番のそばで昼寝）。この道すじは、本編ですでに描いた物だけでできている。

- しゅんが軽トラに乗るたびに、時計が1つ進み、つぎの町に着く。**着いた町は、その時刻の光で**、**その時刻にしか起きない遊び**が動く。
- 結果として、夕方の夕鳴町では第1章の寄り道、夜明け前の星見台では第2章の寄り道、昼の海ぞいの町では第3章の寄り道ができる。どれも「その時間だから」動いている（章を遊び直しているのではない）。
- グソっ君はたかしの店で働いている。話しかけると「いっしょに 行く」で隊列にもどる。章の寄り道の多くは「グソっ君が いっしょ」が条件なので、合流が寄り道の入口になる。
- みました帳に「やり残し」のページ。全部そろうと、**シークレットエンディング**（8章。おすすめ案A「40年ぶりの 休み」）。

```
ツガオ便に乗る（＝時計が1つ進む）
  夜明け前 4:40 星見台 → 朝 5:10 夕鳴町 → 昼 12:10 海ぞいの町 → 夕方 16:58 夕鳴町 → （夜のうちに走って）夜明け前 星見台 …

夕鳴町の家のふとん（時計が進む。町はそのまま）
  朝 → 昼寝 → 夕方
  夕方 → 寝る → 翌朝
```

  - `yr_c1_kotei`「夕方。坂の なんばるわんの 家。／グソっ君と いっしょに。」
  - `yr_c2_taihi`「夜明け前。堆肥舎の 張り紙。／灯りと、グソっ君と。」
  - `yr_c3_moguri`「昼。港の 階段から 海へ。／グソっ君が 潜る。」
- ふしぎは各章の行の下に「ふしぎ ①12・②10・③10」の数（n/12 など）だけ出し、くわしくは各章のみました帳で見る。
- いちばん下に合計「やり残し あと n」。0 になったら「ぜんぶ はなまる！」（8.3 の入口）。

### 7.2 文

- 行の名前は 2章の「中身」から作る（U が字数を合わせる。1行に入らない物は E が短い名前を書く）。
- ヒントは1行目＝時間帯と場所、2行目＝だれと。2行まで。第3章の真相（グソっ君の生まれ）にふれない。
- 文は `data/text/yarinokoshi.ts`（E）。行の ID・章・時間帯・済んだかの関数・ヒントの表。

### 8.2 案A「40年ぶりの 休み」（リードのおすすめ）

- **何が起きるか**：
  1. ツガオがやり残しのページ（はなまるでいっぱい）を見て、「……ほんなら、わしも 1日 休むか。」40年で休んだのは1日だけ（8月30日。グソっ君を公園に置いた日。60 S30）。**2回目の休みは、自分で 選んだ 休み**。
  2. その日のツガオ便は、ヒロスケが運転し、しゅんとグソっ君が荷台で手伝う。1日の4つの止まる所を、カットで回る（約各15秒。どれも今ある町と光で撮る：夜明け前の星見台でマサルがキャベツ、朝の夕鳴町でたかしに卸す、昼の港でナミエの店へ、エゴがタイムカードに『休』の欄を作る）。

  4. グソっ君が起こす：「……迎えに 来たで、おっちゃん。」（第1章のオムカエマチの「迎えに 来たで」と同じ言葉。04 の3章）。置いていかれた場所で、今度はグソっ君が迎えに来る。
  5. 5時のチャイムが8音鳴る。グソっ君が、たかしの店の焼きそばを1パック渡す：「冷めても うまいけど、／……出来たてや。」（S30 のツガオ「冷めても うまいけえ」の返事）。ツガオ「……うまいのう。」
  6. しゅんが、ツガオのタイムカードの『休』の欄に、はなまるを押す（ハンコの絵は第3章の「みんなの はなまる」の小さい版）。

- **長さ**：約2分30秒（カット4つ 約1分、公園 約1分30秒）。

## 11. 依頼主に聞くこと

本当に決めてもらう必要がある物だけ。ほかは（仮）のまま進められる。

1. **時計の進み方**：「ツガオ便に乗るたびに、朝→昼→夕方→夜明け前と進み、その時間にツガオ便が止まる町に着く」（ツガオ便の1日＝クリア後の1日）でよいか。最小の形では、夕鳴町は朝と夕方、海ぞいの町は昼、星見台は夜明け前だけ行ける。**全部の町を全部の時間帯で歩けるようにするのは手間が大きい**（3.4。1つの町の1つの時間帯で M〜L）。
2. **止まった時間の台詞**：クリア後の夕方の夕鳴町・夜明け前の星見台で、町の人が第1章・第2章のときの「時間が止まっている」話をそのままするか、クリア後用に書き直すか（4.4。書き直すなら＋2〜5日）。
3. **シークレットエンディングの中身**：おすすめは案A「40年ぶりの 休み」（ツガオが自分で選んで1日休み、夕方の公園でグソっ君が「迎えに 来たで」）。そのとき、グソっ君がツガオに出来たての焼きそばを渡す場面は、「焼きそばが3回つながる」の決まりの中で入れてよいか（入れないなら、焼きそばを渡さずに終える形にできる）。

（仮のまま進める物：夜明け前の星見台の灯りはペロが貸す、やり残しのページの場所と形、数える物の範囲〈あいて・隠し物は数えない〉、タイトルとセーブのカードの差分）
