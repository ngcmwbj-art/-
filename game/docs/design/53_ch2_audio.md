## 1. 音の方向性（第2章）

### 1.1 合言葉

**「朝のチャイムの1分前。静かな夜を、夕焼け色の灯りが歌いながら歩く」**

- 第1章は「夕方5時の町内放送が、ほんの少しだけ調子っぱずれ」。第2章は**静けさが主役**。音楽は第1章より音が少なく、村の音（虫、用水路、換気扇、電気柵、遠い放送）が半分を受けもつ。
- **灯りは歌う**。はなまるトマトは夕鳴町の夕焼けをためこんだ実なので、その声は**夕鳴町のチャイムの「問いかけ」**（1.3）。トマトを取った瞬間から、フィールドの曲にあたたかい三角波の「提灯の旋律」が入る（段階1）。
- **呼び声は遠くから**。山の上の防災無線は、谷の向こうの斜面から返ってくる長いこだま（3.3「山の型」）で聞こえる。こわくしない。さびしく、少しこっけい（出席をとる声が夜通し続く）。
- **朝は、問いかけへの答え**。星見台の朝のチャイム（1.4）は、夕鳴町の問いかけを逆からたどって、主音に帰る。第2章でいちばん最後に、いちばん落ちついた音が鳴る。
- 笑い7：切なさ3は第1章と同じ。泣かせてよいのは**エンディングの日の出の30秒だけ**（朝のチャイム → トマトが昇る → 日の出 → 「……おはよう。」 → 鐘）。

### 1.2 3本柱の広げ方

| 柱（40 1.2） | 第1章 | 第2章 |
|---|---|---|
| ①チップ＋モダン | 矩形波・三角波・FM＋パッド、リバーブ、テープの揺れ | 同じ楽器を使う。新しい楽器は**2つだけ**：トマトの灯りの声 `ins_lantern`、分校の足踏みオルガン `ins_reed_organ`（3.1） |
| ②「ちょっとおかしい」和声とリズム | ヨナ抜き、1ループに1〜2の借用和音、1曲に1種類の拍子のずれ（物語の理由つき） | 同じ規則。星見台の夜は**ヘ長調のリディア**（4度が半音高い B♮）。借用和音は「朝の予感」の B♭ と、♭VI の D♭。拍子のずれは段階2の「コロンが点滅しかけて止まる」1拍（5.1） |
| ③チャイム動機が全体を貫く | 夕鳴町の五時チャイム（問いかけ4音＋封印された答え4音） | 夕鳴町の問いかけ（トマトの声）＋防災無線の放送チャイム＋**星見台の朝のチャイム**（1.3、1.4） |

### 1.3 動機の地図 ★

第2章の曲とSEは、次の6つの音形だけで骨組みを作る。どれも短く、口ずさめる。

| 動機 | 音（実音） | 意味 | 出てくる所 | 規則 |
|---|---|---|---|---|
| **M1 夕鳴町の問いかけ** | ヘ長調で C5 D5 F5 A5（+2 +3 +4。第1章の G4 A4 C5 E5 と同じ形） | 夕鳴町の夕焼け＝**トマトの声** | `bgm_hoshi_night` の提灯の旋律 A1、ボス曲の提灯の対旋律 A1・A5・B7、`bgm_hoshi_morning` の A1、`se_h_light_spread`（頭の2音）、`se_h_tomato_rise` | **答え（−2 −3 +3）は第2章でも封印**（40 1.3 の自動検査をそのまま第2章の曲にかける） |
| **M2 星見台のリディア** | A5 B5 C6（3 ♯4 5） | 星見台の夜の色 | `bgm_hoshi_night` の導入 HI1〜HI2（第1章 `bgm_night` N5 の「続編の予告」の回収）、提灯の旋律 A2 | 朝の曲では B♮ が B♭ に落ちつく（夜がほどける） |
| **M3 放送のはじまり** | D5 F♯5 A5 D6（`se_pa_chime`、第1章と同じ）／短調で D5 F5 A5 D6 | 点呼がはじまる | `se_pa_chime`、ボス曲の導入 YI4 と A1 | ― |
| **M4 おやすみ放送のしめ** | D6 A5 F♯5 D5（`se_pa_chime_end`）／短調で D6 A5 F5 ―（4つ目なし） | 点呼が終わらない | ボス曲 A2（F5 で止まる）、点呼の層（6.3。名札1つにつき1音。4つ目の D5 は鳴らない）、ボス曲 C7（ヘ長調で F5 C5 A4 ― ） | **4つ目の音は、最終局面の `se_pa_chime_end`（長調・音程が合う）まで鳴らさない** ★（16.1 の自動検査） |
| **M5 呼び声** | 下がる短3度（ソ→ミ）。「ナ・ナ・ミー」は `G5:2 G5:2 E5:4` | 名前を呼ぶ | `bgm_hoshi_night` 段階2の `yobigoe`、`se_h_onamae`、ボイス `yobimodoshi` と `broadcast` の名前の行（9.2） | ― |
| **M6 星見台の朝のチャイム** | A5 F5 D5 C5 D5 F5（1.4） | 夜が終わる | `se_h_morning_chime`（5:00）、`bgm_hoshi_morning` の MI1〜MI2 と A1〜A3 | **エンディングまで封印** ★（16.1 の自動検査） |

- 夕鳴町の問いかけ（M1）は5度の音 C で始まり、3度の A で宙に浮いて止まる。朝のチャイム（M6）はその A から始まって問いかけを逆にたどり（A F D C）、問いかけの最初の3音（C D F）で主音 F に着地する。**同じ音でできた、問いと答え**。第1章の封印された答え（D C A C）とは別の形なので、夕鳴町の答えは夕鳴町のものとして残る。

### 1.4 星見台の朝のチャイム ★（M6）

**音列**（ヘ長調。ヨナ抜きの音だけ）

```
A5  F5  D5  C5 ｜ D5  F5（最後をのばす）
3   1   6   5  ｜ 6   1
```

| 項目 | 値 |
|---|---|
| 楽器・経路 | `ins_chime`（第1章の防災スピーカーのチャイムと同じ音）を `bus_pa` の**山の型**（3.3）に通す。星見台の防災無線は古い型なので、LP を 3.2kHz に下げて少し丸い |
| 間隔 | 1音 0.55秒（夕鳴町の 0.45秒より少しゆっくり＝朝の空気）。各音 hold 0.30秒 |
| 最後の F5 | hold 2.5秒、R 900ms。こだまが3回返る |
| 音程 | **音程は正しい**（−35セントなどのずれをかけない。朝は調子っぱずれではない） |
| 鳴る所 | エンディングのカット1の 5:00 の1回だけ（12.14）。`bgm_hoshi_morning` の MI1〜MI2 がオーケストラで1回くり返す |

**規則**

| 規則 | 内容 |
|---|---|
| 封印 | この6音の音程の形（−4 −3 −2 +2 +3）は、エンディングまでどの曲にもSEにも出さない。`bgm_hoshi_morning` だけ例外 |
| 集めない ★ | 町のチャイムは**町の1つの鐘**で、集めて並べるものではない（00 16章「◯◯のばしょ」型のメロディ収集の禁止）。タイトル、メニュー、みました帳、エンディングで、夕鳴町と星見台のチャイムを並べて聞かせる演出はしない。第3章以降も同じ（17章 #1） |
| 実在の曲 | 実在の時報、学校のチャイム（ウェストミンスターの鐘）、防災無線の実在の曲（「夕焼け小焼け」「家路」「エーデルワイス」「ふるさと」「七つの子」「赤とんぼ」「野ばら」など）、ラジオ体操の曲、駅の発車メロディに似せない。ウェストミンスターの4音の形（どれも音階の2度を含む）とは、2度を1回も使わないことで分けた |
| 5時どうし | 夕鳴町は17:00、星見台は5:00。どちらも「5時のチャイム」。音は夕方が宙づり、朝が着地 |

### 1.6 描写の正確さ（農村・牛舎・獣害の音）★

依頼主は F1 の肥育農家。**音も「わかってるな」と思える正確さで作る**。下の表の「確かな事実」だけを音にし、知らないことは音にしない。

| 分野 | 音にしてよい事実 | 音にしないこと（理由） |
|---|---|---|
| 牛舎（F1 の肥育） | 大きな換気扇が夏じゅう回っている低いうなり。反すうはあごの動きが1秒に1回くらいで、ひと口を40〜60回ほど噛んで、少し間をおいて次を戻す。鼻息。牛が鼻で押して飲む給水器（ウォーターカップ）の水の音。おがくずの上で寝たり立ったりする音。牛房の柵（鉄パイプ）に体がふれる音。朝の給餌の前後に鳴くことがある。給餌車の車輪 | **首の鎖**（牛房に数頭ずつ放して飼っているので、つなぎ飼いの鎖の音はない）。**カウベル**（放牧の牛の鈴で、牛舎で飼う肥育牛には付けない。第1章の中ボスの `ins_fm_cowbell` は第2章では鳴らさない。5.5）。苦しそうな声、おびえた声。**出荷**を思わせる音（トラック、積みこみ）。牛を笑いの種にする「モー」 |
| 出荷の話（ゲンさん h1_2） | ― | **音楽で感傷をつけない**。台詞のあいだ BGM を変えない、ジングルもSEも足さない。淡々と |
| 電気柵 | 電源装置が約1秒おきにパルスを出すときの小さな「カチッ」。草が線にふれている所で、パルスと同時に小さく「チッ」と漏電の音 | 人がしびれる「ビリビリ」の効果音をフィールドで鳴らさない（さわれない。さわってはいけない）。戦闘の感電は小さく（8.4） |
| イノシシ | 鼻を鳴らす「ブフッ」、低い「ブー」、土を鼻で掘る音、泥浴び（ヌタうち）の水音、ひづめ | わな、猟、悲鳴。撃破は「山へ帰る」（鼻息が遠ざかる） |

## 2. 記法（40 の2章に足すもの）

40 の2章（mml、ベースの型、ドラムの型、和音の構成音）をそのまま使う。第2章で足すのは次だけ。

| 書き方 | 意味 |
|---|---|
| `@song … part=<名前>` のブロックに、**その小節だけ**書く | そのパートは書いた小節だけで鳴る（第1章の `chimeQuote` と同じ）。`yobigoe`（5.1）など |
| `h≥1` `h=2` | 音楽パラメータ `h_stage` の条件（6.1）。編成の表の列見出しで使う |
| `light=1` | 音楽パラメータ `h_light` の条件（6.2） |
| `det=-35` | SE のレシピの音程のずれ（セント）。既存の `recipe.ts` が読める（40 9.0 の表には載っていなかった） |
| `am=12→30/250/.8` | トレモロの速さを 250ms で 12Hz→30Hz、深さ 0.8（既存の `recipe.ts` の書式） |

- すべての mml ブロックは執筆時に検算した（小節の長さ、封印した音形。16.1）。

> 40 の5章と同じ順（旋律 → 和音の構成音 → ベース → ドラム → 編成 → ループ）。旋律の小節ラベルは曲の中で一意。

### 5.1 `bgm_hoshi_night`（星見台の夜）

- **テンポ** 96／**拍子** 4/4／**キー** ヘ長調のリディア（B♮）／スウィングなし
- **狙い**：朝の1分前で止まった山の村。よく眠れる夜。第1章 `bgm_night` の星のオルゴールが、そのまま星見台の空になる。**段階でパートが足されていく**：段階0はオルゴールと低いパッドだけ（さびしくない静けさ）、段階1はトマトの灯りの歌（夕鳴町の問いかけ）が入って村を歩き、段階2は山の上の呼び声がこだまで重なる。
- 和音はリディアの I – II（Fmaj7(♯11) – G/F）で浮かび、B で「朝の予感」の B♭（B♭maj7(♯11)、Gm9）を2か所だけ借りる。C の ♭VI（D♭maj7(♯11)）が第1章の A♭maj7 と同じ「ほんのり寂しい」の色。

- **狙い**：朝が来た村。泣かせる30秒の後半を受けて、すぐに明るい「朝の段取り」へ。トマトの灯りの歌（問いかけ）が、朝のチャイムの答え（A F D C D F）をつけて、1つの旋律として歌い切る。
- **構成**：夜明け MD1〜MD2（`h_stage` が 3 になるまでくり返す）→ 導入 MI1〜MI2（1回）→ A（8）→ B（8）→ A へ

**夜明け（トマトが昇って、日が出て、「……おはよう。」のあいだ）**

```mml
@song bgm_hoshi_morning part=dawn ins=ins_musicbox meter=4/4
MD1 Bbmaj9/C       | -:8 D6:8 |
MD2 C9sus4         | C6:8 -:8 |
```

- パッド（`ins_pad`、A 2秒、v 0.03、LP 900→1800Hz を2小節かけて開く）が C のペダルの上で B♭maj9 → C9sus4 をゆっくり往復する。ドラムなし、ベースは `ins_sub` の C2 だけ。
- **C のペダルの上にいるので、カネナリくんの鐘（C の長三度の鐘。40 9.6）が鳴っても、いつ鳴ってもぶつからない**。鐘のあとに `h_stage` が 3 になり、次の小節で MI1 へ進む。

**導入（朝のチャイムを、村の楽器でもう一度）**

```mml
@song bgm_hoshi_morning part=chime ins=ins_fm_vibes meter=4/4
MI1 Dm7/C          | A5:4 F5:4 D5:4 C5:4 |
MI2 F6/9           | D5:4 F5:12 |
```

**旋律**

```mml
@song bgm_hoshi_morning part=lead ins=ins_lantern meter=4/4
A1  Fmaj7          | C5:4 D5:4 F5:4 A5:4 |
A2  Dm7            | F5:4 D5:4 C5:4 D5:4 |
A3  Bbmaj7         | F5:12 -:4 |
A4  Gm7            | G5:6 A5:2 Bb5:4 A5:4 |
A5  Fmaj7/A        | C6:8 A5:4 F5:4 |
A6  Bbmaj7         | D6:6 C6:2 Bb5:4 A5:4 |
A7  Gm9            | G5:4 A5:4 Bb5:4 D6:4 |
A8  C9sus4・C7     | C6:8 Bb5:4 G5:4 |
```

- A1 の問いかけ（C D F A）に、A2〜A3 で朝のチャイムの答え（F D C D ｜ F）が続く。A1 の最後の A5 から数えると、A F D C D F＝**朝のチャイムそのもの**。夕鳴町の問いと星見台の答えが、1つの息で歌われる。
- A4 の B♭5 → A5：夜の曲の B5（B♮）が、朝には B♭ になって落ちつく。


## 6. 音楽パラメータ（第2章）

`setMusicParam(name, value)`（40 7章）に足す。値が変わったときだけ処理する。

### 6.1 `h_stage`（−1／0／1／2／3）

| 値 | 意味 | 効く所 |
|---|---|---|
| −1 | 星見台の外（第1章、プロローグ、エンディングのカット4以降）。**既定値** | ― |
| 0 | よなか | `bgm_hoshi_night` のパート（5.1）、`bgm_battle` `bgm_midboss` の夜の版（≥0 のとき）、`amb_h_*` の段階の違い（7章）、放送の間隔（7.4） |
| 1 | ともしび | 同上。0→1 で `bgm_hoshi_night` が次の小節で A1 へ飛ぶ |
| 2 | よびごえ | 同上 |
| 3 | あさ | `bgm_hoshi_morning` の夜明けの出口（5.4） |

- ワールドは、`flag_ch2_stage` が変わったとき、**ロードしたとき**、星見台のマップに入ったときに呼ぶ。プロローグの `map_town` と、エンディングのカット4に入るときは −1。
- 第1章の `stage` は第2章のあいだ 3 のまま（50 5.2）。`stage` と `h_stage` は別々に持つ（`dog` の声が半音下がる規則や、`se_pa_chime` の −35セントは `stage` を見ているので、第2章では働かない。放送のずれは7.4で別に決める）。
- 環境音は `stageListeners` と同じ仕組みで `h_stage` を受けとる（`hStageListeners` を足す）。

### 6.2 `h_light`（0／1）

- `bgm_boss_yobimodoshi` だけに効く（5.3 の表）。戦闘側がトマトをかかげた瞬間（51 14.2 の 700ms）に 1、暗くなるとき（51 14.3）に 0 を送る。
- 1 になったら**次の拍の頭**で切り替える（小節を待たない。灯りの手応えをすぐ返す）。0 に戻るときは次の小節の頭。
- 戦闘が終わったら 0 に戻す（`playBgm` で別の曲になったとき、オーディオ側が自動で戻す）。

### 6.3 `tenko`（0〜4）

- `bgm_boss_yobimodoshi` の点呼の層（5.3）。戦闘側は名札が点く・消えるたびに、その時点の数を送る（点く：+1 のたび、夜ふかしのあと 0、やりなおしで −1）。
- 変わったら**次の拍の頭**から新しい数で鳴らす。4 は「夜ふかしの一撃」の合図で、層は鳴らさない。

### 6.4 `h_rest`（0／1）

- `bgm_midboss` の夜の版だけに効く（5.5）。戦闘側は「おつかれさま」でテツヤが休憩に入ったとき 1、休憩あけ（51 14.11）で 0。**次の拍の頭**で切り替える。戦闘が終わったら自動で 0。

### 6.5 `variant`（`bgm_hoshi_night` の形）

- 5.2。`playBgm('bgm_hoshi_night', { variant })`。同じ曲が鳴っていれば、形だけ 0.6秒で移る。

### 9.3 カネナリくんの「……おはよう。」

40 10.2 の「……おいしい。」と同じ作り（`kanenari_voice`、`{spd=0.4}`、1文字＝1ブリップ、「……」は鳴らさない、母音の色のついたハミング）。**1文字目の「お」の次の文字で、どちらの言葉かを決める**（「い」なら「おいしい」、「は」なら「おはよう」）。

| 文字 | お | は | よ | う |
|---|---|---|---|---|
| 高さ（D3 から） | 0（D3） | +5（G3） | +5（G3。少し弱く、v×0.85） | +5→+3（長さ 320ms。G3 から F3 へゆっくり下がって止まる） |

## 13. API（足すもの）

40 14章の関数はそのまま。他チームは次の関数だけを足して呼ぶ。

```ts
// ---- 音楽パラメータ（6章） ----
export function setMusicParam(
  name: 'stage' | 'kire' | 'boss_phase' | 'muffle' | 'detune' | 'h_stage' | 'h_light' | 'tenko' | 'h_rest',
  value: number,
): void;

// ---- bgm_hoshi_night の形（5.2） ----
// playBgm('bgm_hoshi_night', { variant: 'outdoor' | 'house' | 'barn' | 'school' | 'hill' })
// 同じ曲が鳴っていれば、形だけ 0.6 秒で移る（曲は止まらない）

// ---- 防災無線（3.3、7.3） ----
export function setPaMode(mode: 'town' | 'yama'): void;
export function setPaDistance(d: number, indoor?: boolean): void; // d: 0（真下）〜1（村の南の端）

// ---- 星見台の朝のチャイム（1.4） ----
export function playMorningChime(opts?: {
  gap?: number;        // 既定 0.55 秒
  lastHold?: number;   // 既定 2.5 秒
  onNote?: (i: number) => void; // i = 0..5（エンディングの明るさの同期）
}): Promise<void>;     // 最後の音が消えたら解決

// ---- 空間（3.4） ----
// setSpace('yama' | 'barn') を足す（SpaceId に 2 つ追加）

// ---- 環境音のイベント名（7章） ----
// ambientEvent('amb_h_fence', 'pulse', pan)            1.0 秒ごと（ワールドの時計）
// ambientEvent('amb_h_tetsuya', 'turn', pan)           往復の端ごと
// ambientEvent('amb_h_barn', 'sync_on' | 'sync_off', pan)  ふしぎ08
// ambientEvent('amb_h_house', 'deep_breath' | 'calm')  ふしぎ07
// ambientEvent('amb_h_wind', 'ine' | 'susuki' | 'sugi' | 'hill' | 'none')  区域の葉ずれ
```

- `setMusicParam('h_stage', n)` は `stage` とは別の値として持つ（6.1）。
- `sfx(id, { level })` は `se_h_boar`（0〜2）、`se_h_tiller`（0〜5）、`se_h_ressha`（0／1）で使う。`sfx('se_h_tenko', { note })` は `'D6' | 'A5' | 'F5'`。`sfx('se_h_tomato_glow', { grade: 'kukkiri' })` は最終局面の長い版、`se_h_otsukare` も `grade` を読む。
- 未登録のIDは第1章と同じく開発中だけ `console.warn`。

### 14.2 シーケンサ

- **h_stage の飛び**：`bgm_hoshi_night` の `onParam('h_stage', 1, 0)` で `jumpNext('A1')`（第1章のボスの `jumpNext('AA1')` と同じ仕組み）。
- **段階2の 5/4**：C8 の最後の拍をくり返す処理は、40 5.4 の `bgm_town_s2` の B4・C4 と同じ関数を使う（`h_stage === 2` のときだけ）。
- **呼び声のパート**：書いた小節だけの mml（第1章の `chimeQuote` と同じ読み方。音形の検査はしない）。
- **ボスの点呼の層**：`hits()` で、`b.p.tenko` と `b.p.boss_phase` を読んで鳴らす（5.3 の表）。音程は曲の転調の外（`transpose` をかけない）。
- **ボスの明るさ**：`melody({ when })` と `partGain`。`h_light` の 0→1 は次の拍の頭（`BarCtx` の拍で待つ）、1→0 は次の小節。
- **ラッパのこだま**：曲の `onSfx(sp, 'se_part_break')` で数えて、旋律のパートのディレイのフィードバックを下げる。数は曲を鳴らしはじめたときに 0。
- **ボスの最終局面**：`onParam('boss_phase', 3)` で全パートを `partGain(id, 0, 1.0)`、`haltAt`。環境音のダッキング（`ambDuck`）を 1.0秒で 1 に戻す。第1章の `finalPhase` のドローンは作らない。
- **朝の夜明け**：`route` で、`h_stage < 3` のあいだ MD2 の次を MD1 に戻す。鳴らしはじめで `h_stage === 3` なら MI1 から。

### 14.3 セーブとロード

- 音の状態はセーブしない（第1章と同じ）。ロードしたら、ワールドが `h_stage`（`flag_ch2_stage`、第2章でなければ −1）、`setPaMode`、`setSpace`、4.2 の表の曲と環境音を呼びなおす。
- トマトの灯りの有無（`flag_ch2_got_tomato`）は `h_stage ≥ 1` と同じなので、音のために別に見る必要はない。

### 14.4 パフォーマンス

- いちばん重いのはボス戦（旋律＋こだま、オルガン、灯り、点呼、パッド、ベース、ドラム、キレ）。第1章のボスの目安（ノートPCの CPU 5%以内。40 15.3）で計る。オルガンは1音に BP 2本なので、和音の同時発音は4音まで。
- `amb_h_barn` の反すう6声と換気扇3台、`amb_h_insects` の虫は、`Every` の予約（既存）でまとめて鳴らす。発音が終わったノードは `onended` で外す。
- `bus_pa` は1本のまま（山の型は設定の切り替え）。こだまのタップが長くなるので、`PaChain` の「6秒使わなければ眠る」は **8秒**に延ばす。

### 14.5 サウンドテスト（開発用）

- 第1章のジュークボックス（40 15.4）に、第2章の曲・SE・環境音・ボイスを「第2章」のタブで足す。`h_stage`、`h_light`、`tenko`、`h_rest`、`bgm_hoshi_night` の `variant`、放送の型と距離 d のつまみも付ける。
