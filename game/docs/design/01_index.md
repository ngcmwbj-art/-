## 1. 全体の要約

### 1.1 作品

- **タイトル**：『しゅんの夕暮れあぜ道戦記』（*SHUN'S TWILIGHT CHRONICLE*。2026-09-26 に『あぜ道の夕焼け』から改題。その前は2026-09-25 に『はなまる夕焼け』〈*HANAMARU SUNSET*〉から改題。00 1章）。現代日本の郊外を舞台にした、ユーモアRPGのバーティカルスライス。
- **ログライン**：夏休みの最後の日、五時のチャイムが4つ目の音で止まった。チャイムが鳴り終わらないと、焼きそば屋の焼きそばは焼きはじまらない。小5のしゅんは、元担任の駄菓子屋のおばあから採点ハンコを託され、中の人がいないゆるキャラ「カネナリくん」を連れて、だれにも見てもらえなくなったモノたちに「みました」を押して回る。
- **プレイ時間**：初見・寄り道ありで約10分、必須だけで約7分（4章）。
- **3本柱**：①「みました」＝見てもらえなかったモノを認める（テーマ・能力・敵・ボス・決着が一本）②ボケとツッコミ＝敵の行動はすべてボケ、プレイヤーはツッコミとハンコ押しで返す ③止まった夕方が少しずつ壊れる町＝同じ町が段階0→1→2→夜と変わる。
- **トーン**：笑い7：切なさ3。恐怖演出なし。泣かせるのはエンディングの最後の30秒だけ。

### 1.2 世界のルール

- だれかに見てもらえたモノは、そのモノのままでいられる。見てもらえなくなったモノは自分が何だったかを忘れて妙なことを始める（＝敵）。倒すと元の姿を**思いだして**ポトンと落ちる（撃破演出「思いだす」）。
- 閉店したモールの迷子センターに取り残された忘れ物たちの想い「オムカエマチ」が、チャイムを4音目で止めている。
- 町ごとに違う時刻で止まっている。隣町の星見台はずっと「夜」（続編の予告）。

### 1.3 舞台

- **外マップ** `map_town` 64×44：A ひぐらし坂（自宅・空き地・坂・地蔵）／B 夕鳴銀座（北の列の店・アーケード・川べり通りに向いた南の列）／C 夕鳴公園／D モール駐車場／踏切（東端、下りたまま）／川べり通り・用水路・対岸。
- **屋内**：自宅2F・1F、焼きそばのたかし、駄菓子ひのや、コインランドリー、交番。**ダンジョン**：閉店モール「ショッピングプラザ・ユウナリ」M1〜M5（M5 がボス部屋）。
- **段階**（`flag_stage`）：0「ふつう」（開始、16:52→16:58）→ 1「停止」（焼きそば屋とひのやの両方に行って銀座に出た瞬間の17:00。チャイムが4音目で途切れる）→ 2「忘却」（公園の放送「迷子のお知らせ」。影がすべてモールを指す）→ 3「夜」（ボス撃破。17:01）。空のパレット、影、NPCの台詞、小物、BGM、敵シンボルを一括で差し替える。

### 1.4 仲間

- **しゅん**（11歳）：緑の大きすぎるTシャツ、背中の虫とりアミ、赤いビーサン。フィールドでは話さない。能力は**ハンコ術**（MP＝朱肉）。
- **カネナリくん**：鐘の頭のゆるキャラ（引退済み、中の人なし）。フリップで話す。能力は**PR活動**（クールタイム制）。エンディングで一度だけ声が出る。

### 1.5 戦闘の要点

- シンボルエンカウント。背後から触れると先制、背後を取られると不意打ち。格下は「照れて固まる」（逃げない、自動勝利しない）。
- 入力は3つ：**たたく／タックル**＝縮む輪に合わせて「いい音」／**ハンコ**＝長押しして離す（くっきり・ふつう・かすれ）／**ツッコミ**＝敵の「！」に合わせて決定（被ダメ半減、ボケ負け、キレ+1。ジャストでキレ+2）。
- キレ3で**ノリツッコミ**（2人の合体技、敵全体）。撃破は「思いだす」演出（ヒットストップ14f→白→縮む→ポトン→みました判→一言）。
- 成長：Lv上限5、累計経験値 10／40／90／150。レベルアップは「通知表」の演出。
- 必須の戦闘5つ（ハト係長、カネナリくん、おじぎ自販機、ソウジロウ1体、オムカエマチ）＋任意8つ（セミ×2、コーン2体組、ワスレガサ×2、ソウジロウ、モミスギ）。必須だけでボス前 Lv3、全部で Lv5。

## 3. 実装優先度

「上の段が動かないと下の段の手触りが確かめられない」順。各段の終わりで通しプレイと Visual QA を回す。

### P0 通しプレイが最後まで成立する骨組み

1. **ワールド**：`map_town`（段階0〜2の通行の制限：バリケード、2本のチェーン、踏切）と屋内6マップ、モール5区画、`door_*` 全部、カメラ（固定／追従）、隊列、NPCへの話しかけとカウンター越しの会話（30 3.9）、調べる。
2. **進行**：本筋のフラグ（2.8）と必須イベント（evt_opening〜evt_ending）、`flag_stage` での一括差し替えの仕組み、HUD の時計、おつかいメモ。
3. **戦闘の核**：コマンド、たたくの輪、ハンコの長押し、ツッコミの「！」と判定、ダメージ式、撃破、勝利・全滅（evt_gameover）、経験値とレベルアップ（通知表の簡易版）。必須の5戦（ハト係長、カネナリくん、おじぎ自販機、ソウジロウ、オムカエマチ：部位・チャイム・最終局面）。
4. **会話UI**：夏休みのノートの窓、名札、選択肢、フリップ、`{w}` `{spd}` `{shake}` `{wave}` `{c}`。
5. **セーブ**：お地蔵さんと M4 のベンチ、つづきから。
6. **音**：`bgm_town_s0/s1/s2`、`bgm_battle`、`bgm_boss`、チャイム（`playChimeMotif`、`se_chime_cut`）、戦闘の基本SE（`se_warn` `se_bishi` `se_hit_*` `se_stamp*`）。

### 4.5 しるしと、手前の物のすかし（改善会議 2026-10-20 の 1・2・4。docs/kaizen/2026-10-20.md）

- **きらり**（src/world/marks.ts）：まだ調べていない「調べられる物」に小さな黄色い「！」。主人公から3マス以内・近い順に3つまで。光らせるのは、もらっていない隠し品・お金（reward）、押せるふしぎ、そのときだけ置かれる物（cond に flag・notFlag・taken・notTaken・when がある物）だけ。いつもある飾り・人・閉まった扉は光らせない。調べた記録は `flag_seen_look_<obj id>`。
- **行き先のしるし**（src/events/kn_hint.ts の DEST）：グソっ君に〔次、どうする？〕を聞いたあと、その行き先の人・扉・物の上に、きらりと同じ「！」。ヒントの文が変わったら（段階が進んだら）消える。別の地図のときは、その地図へじかに行ける扉に出す。行き先の決まらない段階（数で変わる文など）は出さない。最初に1回だけ「迷ったら、わいに 聞いてや。」（第1章 迷子のお知らせのあと／第2章 星見台に着いたあと／第3章 子どもたちのあと、どれか最初の1回。`flag_kn_hint_told`）。
- **寄り道の しるし**（src/world/marks.ts の `addMarkSource`、2026-10-23）：短い あいだだけ 遊べる 寄り道の 人の 上に、同じ「！」（遠くからでも 見える）。今は 第3章 段階2（S13〜S14）の 防波堤の ツリノ（やっと、魚の 昼。済んだら 消える）。
- **せってい「しるし：あり／なし」**：きらりと行き先をまとめて消せる（はじめは「あり」）。
- **手前の物をすかす**（HD-2D、src/hd2d/seethru.ts）：主人公・仲間・話せる人が建物・木の葉・ひさし・切り抜きの物のうしろに入って隠れたときだけ、その手前の物をすかす（主人公と仲間の前の切り抜きは前からの 0.25、それ以外は半分）。12%隠れたら始め、6%を切ってから0.35秒待って0.3秒でもどす（チカチカしない）。

### 4.6 タッチの操作説明・店・会話の窓・重なりの点検（改善会議 2026-10-21 の 1・3・4・5。docs/kaizen/2026-10-21.md）

- **操作説明**（src/events/stage.ts keyGuide）：タッチで遊んでいるときは、キーの名前を画面のボタンの名前で出す（Z→けってい、X→もどる、C／X と C→メニュー、Shift→ダッシュ、4方向の矢印→十字キー。1〜2方向の矢印は向きを言うので矢印のまま）。PC はキーのまま。最初の説明（移動）は1マス歩くまで、ダッシュ・メニューの説明はダッシュかメニューを使うまで（最長40秒）、そのほか（遊びの説明）は出ている操作をするまで（最長20秒）消さない。会話の窓が出ている間は隠れて待つ。ツガオの部屋の「X：とばす」はタッチで「もどる：とばす」。
