## 4. 計算式の追加

20 4章・51 4章の式はそのまま。ここに書くものだけ足す。

### 4.1 ダメージの式に足すもの

```
ちから実効（敵） = ちから × (1 + 0.25 × ちから段階)
                × (1 − 0.08 × 鉄板の熱)          // 第3章：field_teppan（0〜3）。敵ぜんぶ（「手が ゆるむ」）
まもり実効（敵） = まもり × (1 + 0.25 × まもり段階)
                × (みられている ? みました係数 : 1)
                × (値段が 決まらない ? 1.5 : 1)   // 第3章：status_c3_mayoi（ネフダマヨイ）
```

- 鉄板の熱は**敵のちからだけ**を下げる（熱3で×0.76）。味方のちからは変えない（鉄板は「みんなを あたためる」もので、強くするものではない）。
- 値段が 決まらない、はツッコミかみましたで解ける（9.1）。ポコシャのちぢこまりは式ではなく「届かない」（13.5）。
- 行動順（20 4.8）の同点は **しゅん → グソっ君 → ヤキソバン**。

### 4.2 固定ダメージ・回復（第3章で足すもの。乱数0.9〜1.1だけ掛ける）

| もの | 値 |
|---|---|
| ノリツッコミ（3人版） | (しゅん＋グソっ君＋ヤキソバンのちから) × **2.0**。敵全体（属性 笑）。2人のときは第1章のまま ×2.5 |
| 鉄板のあたたまり | ラウンドの終わりに、行動できる味方ぜんいんの HP ＋ **3 × 鉄板の熱**（乱数なし。へばっている人は起こさない） |
| 大盛り | 味方1人の HP ＋ (40 ＋ ヤキソバンのまもり ＋ **12 × 鉄板の熱**)。使うと熱が0に戻る（5.6） |
| いただきます | 味方ぜんいんの HP ＋ (20 ＋ しゅんのちから) × 判定倍率（くっきり1.5／ふつう1.0／かすれ0.7）（6.1） |
| はなまるの おすそわけ（Lv9） | となりの味方に、はなまるの回復量 × 0.4（乱数は掛けなおさない） |

### 4.3 「まだ」のゲージ（人が相手のとき：ヒロスケ・ツガオ決戦）

- 人が相手の戦闘では、HP を**「まだ」のゲージ**と呼んで見せる（黒い横長のゲージ。16.6。みましたを押さなくても見える）。ふつうの攻撃・ハンコ・ノリツッコミは 20 4.1 の式どおりにゲージを減らすが、**ダメージの数字は出さず**、黒い小さな「まだ」の字が減った分だけ散る（17.13）。
- ゲージは**錠**（ロック）の所で止まる：ヒロスケは 30%（13.3）、ツガオ決戦は 50%（14.2）。錠が外れるまで、ゲージは錠の値より下がらない（はみ出した分は捨てる）。
- ゲージが錠に着いても、だれも倒れない。決着はハンコ（ヒロスケ＝ごちそうさま、ツガオ＝みんなの はなまる）で、ゲージは決着の演出で割れて落ちる（17.14）。
- ツガオ初戦はゲージを出さない（何も効かない。12章）。ポコシャもゲージを出さない（係長の声を3つほどく。13.5）。

### 4.4 状態異常の成否（第3章の技）

20 4.4 と同じ（`基本確率 × (1 − 対象のうん / 100)`、ツッコミ成功なら0%）。例外は `status_c3_mada`：ツガオ決戦の『まだ』の**ツッコミに失敗したら必ず**かかる（51 の `status_henji` と同じ考え方）。

### 4.5 逃走

- 第3章の通常の敵は 20 4.6 の式。中ボス・ボス・イベント戦はすべて不可（専用の文。60 6章）。
- 決戦では「にげる」の位置に「よぶ」が出る（14.3）。
