## 1. 音の方向性

### 1.1 合言葉

**「夕方5時の町内放送が、ほんの少しだけ調子っぱずれ」**

- 耳なじみのいい、やさしいチップチューン。そこに**1か所だけ**、和音や拍子や音程の「ずれ」を仕込む。聞き流せば心地よく、気づくと妙に引っかかる。これが「一見ふつうの町が少しずつおかしくなる」の音の版。
- 笑い7：切なさ3。基本は軽快でとぼけた音。切なさは、和音の色（借用和音、宙吊りの音）で出して、メロディで泣かせない。泣かせてよいのはエンディングの最後の30秒だけ。
- 恐怖の音（不協和音の叩きつけ、悲鳴、急な大音量）は使わない。不気味さは「止まる」「半音下がる」「1拍戻る」「音が抜ける」で出す。

### 1.2 3本柱

1. **チップ＋モダン**
   - 主役は、矩形波（50%、25%、12.5%）、三角波、ノイズ、2オペレータのFM。1曲あたりの同時発音は8声までを目安にして、チップらしい「限られた声」の感触を残す。
   - そのうえで、現代的な質感を足す：デチューンしたパッド、ステレオの広がり、リバーブ、テープの揺れ（ワウ・フラッター）、ディレイ、サイドチェインのような押し込み、フィルタの動き。
   - 古いゲーム機の制約の再現が目的ではない。「チップの音色で作った、今の曲」にする。
2. **「ちょっとおかしい」和声とリズム**（各曲の規則）
   - 旋律はヨナ抜き長音階（ド・レ・ミ・ソ・ラ）が基本。1フレーズに1音だけ、音階の外の音（半音の「はみ出し」）を置いてよい。
   - 和声は、1ループに1〜2か所、借用和音か遠い和音を入れる：♭VImaj7、♭IImaj7、III7、♭VII9、iv6（同主短調の4度）、トライトーンの置き換え。
   - リズムは、1曲に1種類だけ、拍子のずれた小節を入れてよい（2/4、7/8、5/4）。ずれには「店主のせっかち」「おじぎ」「秒針が戻る」「CDが飛ぶ」など、必ず物語の理由を持たせる。
   - 段階が進むと、音程が半音下がる、テンポが落ちる、メロディの音が抜ける（5.4、7.1）。
3. **チャイム動機が全体を貫く**（1.3）

### 1.3 夕鳴町の五時チャイム ★

**音列**（ヨナ抜き長音階、ハ長調。コンセプト14.1のとおり）

```
前半（問いかけ）：G4  A4  C5  E5
後半（こたえ）  ：D5  C5  A4  C5（最後をのばす）
```

**使いかたの規則 ★**

| 規則 | 内容 |
|---|---|
| 前半4音は自由に使ってよい | タイトル、町テーマのAメロの頭、ボス戦のカウント、スズメ、カネナリくんのノリツッコミ（歌うボケ）など。**4音目のE5で止まる**のが「問いかけ」 |
| **後半4音は封印する** | `D C A C` の並び（どの調に移しても、この音程の形 −2・−3・+3 半音）は、**エンディングまでどの曲にもSEにも出さない**。町テーマの2小節目も「こたえ」を言わずに、別の音へ逃げる |
| 封印を解く場所 | ①`evt_ending` の防災スピーカー（8音すべて）②`bgm_ending` の2小節目 ③クリア後の `bgm_title_clear`。この3か所だけ |
| 理由 | プレイヤーが10分間ずっと「こたえ」を聞かないので、エンディングで初めて8音が鳴ったときに、耳で「鳴り終わった」がわかる |

- 実在の時報やチャイム（「夕焼け小焼け」「家路」「ウェストミンスターの鐘」など）には似せない。上の音列はそのどれとも音の並びが違うことを確認済み。

### 1.4 音色パレット（使ってよい素材）

| 分類 | 使ってよい | 使わない |
|---|---|---|
| 波形 | sine、triangle、sawtooth、square（50/25/12.5%）、ホワイトノイズ、2オペFM、フォルマントフィルタ | サンプル、録音、既製の音源ファイル、ボーカル合成（言葉として聞こえる声） |
| エフェクト | バイクアッド（LP/HP/BP）、ディレイ、コンボリューションリバーブ（ノイズで作ったIR）、ウェーブシェイパー（軽い歪み）、パン、トレモロ、ピッチLFO | 重いビットクラッシュ、極端な歪み |
| 声 | 文字送りのブリップ（音程と母音の色だけ） | 意味のある言葉に聞こえる合成音声（「……おいしい。」も、母音の色が付いたハミングにとどめる） |

### 1.5 禁止リスト ★（レビュー時にチェック）

- **MOTHER2の引用・模倣**：旋律、和声進行の特徴的な引用、音色の再現（戦闘開始の渦巻き音、レベルアップ音、電話のベル、HPドラムの回転音、特定の敵やキャラの声の再現）をしない。既存のポップスを切り貼りしたような作り（サンプリングのコラージュ）もしない。
- **「〇〇のばしょ」型のメロディ収集**：8音のチャイムは「町の1つの鐘」であり、集めて回るものにしない。
- **実在の曲**：既存曲のメロディ、有名なCMソング、時報、学校のチャイム（ウェストミンスター）、駅の発車メロディ、防災無線の実在の曲（「夕焼け小焼け」「家路」「赤とんぼ」など）に似せない。
- **HPのローリング（ドラム式）カウンターの音**：HPの数字が回る音は作らない。HPバーの減り始めに1回だけ小さく鳴らす（`se_hp_tick`）。
- **恐怖演出の音**：ジャンプスケアの大音量、悲鳴、グロテスクな音。

### 1.6 目標にする品質

- 市販のインディーRPGと並べて聞いて、次の4点で見劣りしないこと。
  1. **ループの自然さ**：ループの継ぎ目がわからない。2周目で飽きない（町は60秒以上のループ）。
  2. **場面の変化が音でわかる**：同じ町でも段階0・1・2の違いが、目を閉じても聞き分けられる。
  3. **押したことへの返事**：決定、ツッコミ、ハンコ、たたくの1つ1つに、はっきりした手触りの音がある。同じ音が連続しても耳につかない（ランダム化、11.5）。
  4. **ミックスの整理**：SEがBGMに埋もれない。BGMがSEで途切れて聞こえない。会話の音がうるさくない。

## 2. 記法

### 2.1 旋律と和音（`mml` のコードブロック）

```
@song <曲ID> part=<パート名> ins=<楽器ID> meter=<拍子>
<小節ラベル>  <和音>            | <音符 音符 …> |
```

| 書き方 | 意味 |
|---|---|
| `G4:4` | 音名＋オクターブ：長さ。長さは **16分音符＝1** の整数（1＝16分、2＝8分、3＝付点8分、4＝4分、6＝付点4分、8＝2分、12＝付点2分、16＝全音符） |
| `-:4` | 休符 |
| `C5:4^` | タイ。次の音符（同じ音高）とつなげ、次の頭で発音し直さない |
| `[C4 E4 G4]:8` | 和音 |
| `#` `b` | 臨時記号。調号は使わず、すべて実音で書く |
| `[7/8]` | その小節だけ拍子が違う。ない場合は見出しの `meter` |
| 小節の合計 | 4/4＝16、2/4＝8、3/4＝12、5/4＝20、6/8＝12、7/8＝14。**全ブロックを検算済み**（16.1） |
| 和音欄の `・` | 小節の真ん中（4/4なら9ステップ目）で和音が変わる |
| 和音の構成音 | 各曲の和音表に書く。ボイシングの規則は3.4 |

### 2.2 ベースの型

ベースは型（パターン）と和音のルートで書く。

| 記号 | 意味 |
|---|---|
| `R` | 和音のルート（分数和音 `D7/F#` なら分母の F#）。音域は **A1〜G#2** に置く（A→A1、B♭→B♭1、C→C2 … G#→G#2） |
| `R'` | R の1オクターブ上 |
| `5` | 和音の5度（分数和音でも**和音の**5度。`C6/E` なら G）。R より上の最も近い音 |
| `3` | 和音の3度（長3度か短3度は和音どおり） |
| `-` | 休符 |

例：`R:6 5:2 R':4 5:4` ＝ ルートを付点4分、5度を8分、オクターブ上を4分、5度を4分。和音が小節の途中で変わるとき（`・`）は、型の前半8ステップを各和音に1回ずつ当てる。

### 2.3 ドラムの型

1文字＝16分音符1つ。4/4なら16文字、6/8なら12文字（付点4分＝6文字）、7/8なら14文字、2/4なら8文字。ジングルは全体のステップ数。

| 文字 | 意味 |
|---|---|
| `X` | アクセント（ベロシティ1.0） |
| `x` | 通常（0.7） |
| `g` | ゴースト（0.35） |
| `.` | 休み |

- `swing16=0.56`：16分の裏（奇数ステップ）を、2つ組の56%の位置まで後ろにずらす。
- `swing8=0.64`：8分の裏（ステップ2、6、10、14）を、拍の64%の位置へずらす（シャッフル）。

## 3. 音源とバス

### 3.1 エンジンに足す機能（`engine.ts` の拡張）

現在の `voice()` に次を足す。どれも数十行で書ける。

| 機能 | 仕様 |
|---|---|
| **FM** | `fm: { ratio, index, indexEnd?, indexTime?, ratio2?, index2?, index2End?, index2Time? }`。変調器 sine（周波数＝搬送波×ratio）→ Gain（index×変調器周波数）→ 搬送波の frequency。index は時間で指数的に indexEnd へ |
| **AM（トレモロ）** | `am: { rate, depth, rateEnd?, time? }`。LFO→エンベロープ後段の Gain。depth 1.0 で音量が 0〜1 を往復 |
| **パンの移動** | `pan` に加えて `panEnd`（dur で直線移動） |
| **フィルタの二段** | `filter2`（BPを2本並べる母音用。10章） |
| **ウェーブシェイパー** | `drive`（0〜3）。tanh 曲線の軽い歪み |
| **音楽のピッチ・バス** | `musicDetune`：ConstantSourceNode（単位セント）。**音楽のすべての発振器（FMの変調器も含む）の detune に接続**する。段階1の半音下げ、テープの揺れ、テープストップ、おじぎの音程下げを、ここ1か所で動かす |
| **音楽のフィルタ** | `musicFilter`：音楽バスの出口の LP（通常は 20kHz で素通し）。メニューのこもり、モールの音切れ、段階2の「遠いラジオ」に使う |
| **発音ハンドル** | `voice()` が `{ stop(fade), detune: AudioParam, gain: AudioParam }` を返せるようにする（`se_chime_cut`、`sfxLoop` に使う） |

### 3.4 和音のボイシング規則

- パッドとコードの楽器は、和音の構成音から**4音**を選ぶ（ルートは、ベースが鳴っているときは省いてよい）。
- 最高音は E5 以下、最低音は G3 以上。
- 直前の和音から各声部の動きが最小になる転回形を選ぶ（共通音は残す）。
- 和音表の構成音はすべて書いてあるので、7th と 9th を優先して残し、5度を先に省く。

### 3.6 バスと空間

```
[曲の各声] ──(detune ← musicDetune)──> musicBus(0.55) → musicDuck → musicFilter(LP) ─┐
[SE] ─────────────────────────────────> sfxBus(0.80) ─────────────────────────────────┤
[チャイム・放送] → bus_pa（歪み→BP→エコー3タップ→専用リバーブ→paCut）→ sfxBus         │
[文字送り] ───────────────────────────> voiceBus(0.70) → sfxBus                        │
[環境音] ─────────────────────────────> ambBus(0.60) → ambDuck ─────────────────────────┤
各バスから → reverbSend →（空間ごとのIR）→ master                                      │
                                                  master(0.8) → compressor → limiter → 出力
```

| バス | 中身 | 備考 |
|---|---|---|
| `musicBus` | BGMとジングル | ユーザー設定「BGM」の音量がかかる |
| `sfxBus` | SE、`bus_pa`、`voiceBus` | ユーザー設定「効果音」の音量がかかる |
| `ambBus` | 環境音 | 「効果音」の音量に従う |
| **`bus_pa`** | 防災スピーカーの声とチャイム | ウェーブシェイパー（drive 1.6）→ HP380Hz Q0.7 → LP3800Hz Q0.9 → エコー3タップ（140ms −9dB パン−0.3／310ms −14dB パン+0.4／620ms −20dB パン−0.1）→ **専用のリバーブ（屋外1.8秒）** → `paCut`（Gain）。リバーブまで含めて `paCut` の手前にあるので、`se_chime_cut` で残響ごと断ち切れる |
| `reverbSend` | 共用のリバーブ | 空間ごとにIRを切り替える（11.4）。切り替えは0.3秒のクロスフェード（IRを2つ持つ） |
| limiter | DynamicsCompressor（threshold −2dB、ratio 20、attack 1ms、release 60ms） | 既存のコンプレッサの後ろに足す。クリップ防止 |

### 5.8 `bgm_midboss`（中ボス：おじぎ自販機）

### 5.9 `bgm_boss`（ボス：オムカエマチ）

- **テンポ** 140／**拍子** 4/4／**キー** 第1段階 イ短調 → 第2段階 ホ短調（+7半音） → 最終局面 パッドのみ

## 6. ジングル

### 6.1 共通ルール

- ジングルは `playBgm('bgm_jingle_*')` で鳴らす（他チームの台本どおり）。オーディオ側が `bgm_jingle_` で始まるIDを見分けて、次のように扱う。

| ID | 鳴らす前 | 鳴り終わったら |
|---|---|---|
| `bgm_jingle_victory` | いまのBGM（戦闘曲）を **30msで切る**（置きかえ） | 余韻のループ（6.2）へ続く。次の `playBgm` か `stopBgm` まで鳴る |
| `bgm_jingle_levelup` `bgm_jingle_item` `bgm_jingle_join` | いまのBGMを**一時停止**する（`musicDuck` を 40ms で0。曲の時計は進めたまま） | 0.4秒でフェードインして、いまのBGMを戻す |
| `bgm_jingle_gameover` | いまのBGMを 0.8秒でフェードアウト | 無音のまま |

- 一時停止中にさらにジングルが来たら、先のジングルが終わってから次を鳴らす（キュー。最大2つ）。
- ジングルは `musicBus` に流す（BGMの音量設定に従う）。
- ジングルの最後の和音は、次に戻る曲と調がぶつからないよう、長くても0.8秒で切る。

### 6.2 `bgm_jingle_victory`（勝利 1.5秒＋余韻）

- **テンポ** 150（16分＝0.1秒）、15ステップ＝1.5秒。
- **ステップ0に判の音を内蔵**（`se_stamp_heavy` の本体と同じレシピ、v 0.8倍）。戦闘側は勝利の大判「みました」に合わせてこのジングルを鳴らし、判のSEを別に鳴らさない。
- 最後の和音は**チャイムの主和音**（ハ長調の C・E・G）。

```mml

@song bgm_jingle_victory part=brass ins=ins_fm_brass meter=free
V1  C              | [E4 G4 C5]:2 -:4 [F4 A4 D5]:1 [E4 G4 C5 E5]:8 |
@song bgm_jingle_victory part=bass ins=ins_fm_slap meter=free
```

**余韻のループ**（ジングルの最後から0.3秒後に始め、1.0秒でフェードイン、−6dB）

### 6.3 `bgm_jingle_levelup`（通知表 2.0秒）

- **テンポ** 125（16分＝**0.12秒**。通知表の判を押す間隔と同じ）。17ステップ＝2.04秒。

## 7. 音楽パラメータ

`setMusicParam(name, value)`。値が変わったときだけ処理する。曲の中の切り替えはすべて**次の小節の頭**か、下に書いた時間で行う。

### 7.1 `stage`（0／1／2／3）

| 値 | 意味 | 効く曲 | 切り替え方 |
|---|---|---|---|
| 0 | ふつう | `bgm_home` `bgm_shop` | ― |
| 1 | 停止 | 同上 | 5.4 の「段階1」の変換 |
| 2 | 忘却 | 同上 | 5.4 の「段階2」の変換 |
| 3 | 夜 | ― | 屋内の曲の変換を解除（エンディングでは屋内の曲を鳴らさない） |

- `playBgm('bgm_town_s0'|'s1'|'s2')` を呼ぶと、`stage` も自動で 0／1／2 になる。
- ワールド側は、**段階が変わったとき**と**ロードしたとき**に `setMusicParam('stage', n)` を呼ぶ（17章）。
- 屋内の曲が鳴っている最中に値が変わったら、`musicDetune` を0.6秒かけて移し（ピッチベンドのように）、テンポとパートの変更は次の小節から。

### 7.2 `kire`（0〜3）

- 戦闘の3曲（`bgm_battle` `bgm_midboss` `bgm_boss`）で、5.7 のレイヤーを出し入れする。
- 上がるとき：**次の拍の頭**で足す（小節を待たない。キレの手応えをすぐ返すため）。
- 下がるとき（ノリツッコミで0に戻る）：ノリツッコミの着弾の直後、**次の小節の頭**で外す。
- `ノリツッコミ` の演出中は、戦闘側の指示（13.3）で `muteMusic` と `duckMusic` を使う。

### 7.3 `boss_phase`（1／2／3）

- `bgm_boss` だけに効く。5.9 のとおり。1 は既定値。
- 2 に変わる前に、戦闘側は「1拍だけ無音」を `muteMusic(0.43)`（140BPMの1拍）で作る（20_systems_battle 13.6）。

### 7.4 `muffle`（0〜1）

- メニューを開いている間など、音楽を少し遠ざける。
- 1 のとき：`musicFilter` LP 1.8kHz、音量 −3dB（どちらも150ms）。0 に戻すときは200ms。
- UI側は、フィールドでメニューを開いたら 1、閉じたら 0 を送る。戦闘中のコマンド窓では使わない。

## 9. 効果音（`se_*`）

### 9.0 レシピの書き方

```
se_id   用途（聞こえ方）   全体の長さ
  L1 <波形> f=<周波数>[→<終わりの周波数>/<ms>] env=<A>/<D>/<S>/<R> dur=<ゲートms> v=<音量> [オプション…]
  L2 …（レイヤーを重ねる。at= で開始をずらす）
```

| 項目 | 書き方 | 意味 |
|---|---|---|
| 波形 | `sine` `tri` `saw` `sq`（50%）`p25` `p12` `noise` `fm` | `fm` は搬送波 sine。`fm=` で変調を書く |
| `f=` | `880` または音名 `C6` | `→` は指数グライド。`/ms` はグライドの時間（省略時は dur） |
| `env=` | `A/D/S/R` | A・D・R は ms、S は 0〜1 |
| `dur=` | ms | ゲートの長さ（A+D より短ければ A+D） |
| `v=` | 線形 | エンジンの vol と同じ尺度（11.2 の目安） |
| `flt=` | `LP1200` `HP3000` `BP2400q1.5` `BP2200→180q6` | `→` は dur のあいだにフィルタを動かす |
| `fm=` | `r4:i3→0/40` | 変調比4、index 3→0 を40msで |
| `am=` | `36/.9` `95→60/600` | トレモロ：速さHz／深さ（→でレートを動かす） |
| `vib=` | `6/15` | ビブラート：速さHz／深さセント |
| `pan=` | `.3` `.6→-.6` | → は dur のあいだに移動 |
| `at=` | ms | 開始の遅れ |
| `rev=` | 0〜1 | リバーブへの送り |
| `drive=` | 0〜3 | 軽い歪み |
| `rep=` | `3x90` | 同じレイヤーを90ms間隔で3回 |
| `rnd=` | `3%` | 呼ぶたびに f と v をこの幅でランダムにずらす（11.5） |

- 呼び出しのオプション `pitch`（すべての f に掛ける）、`vol`（すべての v に掛ける）、`pan`（上書き）は全SEに効く。`grade` `note` `hold` `dur` `level` は、そのSEの説明にあるときだけ効く。
- 「〜と同じ」は、そのSEのレシピをまるごと呼ぶ（ネストしてよい）。

### 9.3 足音・扉

**足音のルール**
- ミナトは**赤いビーサン**。外と店の中では、足が着く音の35ms後に、かかとをたたく小さな「ぺた」（下の「ビーサン層」）を必ず重ねる。これがミナトの足音の個性。
- **家の中ははだし**（`se_step_wood_bare` `se_step_tatami`）。ビーサン層なし。
- 歩きのアニメの接地フレーム（4フレームのうち0と2）で鳴らす。ダッシュは v×1.3、pitch×1.06。
- すべての足音に rnd=4%（音程）と v の ±12%。左右の足で pan を ±0.05 交互に。
- カネナリくんの足音は v×0.7、ミナトの足音と重ならないよう半拍（歩きの周期の1/4）ずらす。
- 地面の種類は、`30_level_art.md` 3.2 と4章の凡例のタイルから決める。下の表が正（30 の「足音（案）」はそのまま採用）。

### 9.6 チャイム・鐘・放送

**`se_chime_note`**（防災スピーカーのチャイム1音）

- 呼び方：`sfx('se_chime_note', { note: 'G4', hold?: 秒 })`。note を省くと G4。hold を省くと 0.45秒。
- 音：`ins_chime`（`ins_fm_vibes` を `bus_pa` に通す）。v 0.12。hold のあいだは S0.35 で伸ばし、hold のあと R600ms。
- `bus_pa` のエコー3タップと専用リバーブで、「町の建物に反射して遠くまで届く」感じを出す。

**`se_chime_cut`**（4音目で途切れる）

- 鳴っているチャイムの発音すべて（エコーと残響を含む）に対して：`bus_pa` の detune を −100セントへ 80ms で下げ、同時に `paCut` を 0 へ 80ms。テープが止まるように消える。
- 200ms 後に `paCut` と detune を元に戻す（次のチャイムのため）。

**`playChimeMotif(opts)`**（ヘルパー。イベントはこれを使うと楽）

| オプション | 既定 | 意味 |
|---|---|---|
| `notes` | 4 | 4＝前半だけ、8＝8音すべて |
| `gap` | 0.45 | 1音の間隔（秒） |
| `cut` | false | true なら4音目（E5）を伸ばし続け、**1音目の頭から `cutAt` 秒**で `se_chime_cut` を鳴らす |
| `cutAt` | 1.9 | 既定の1.9秒は、17:00 の台本（t=1.3 で1音目、t=3.2 で途切れる）に合わせた値。4音目の頭（t=2.65）から0.55秒で途切れる |
| `lastHold` | 2.0 | 8音のときの最後の C5 の長さ |
| `onNote(i)` | ― | 各音の発音時のコールバック（HUDや演出の同期用） |
| 戻り値 | Promise | 最後の音が消えたら解決 |

**`se_bell_kanenari`**（カネナリくんの鐘が鳴る。4秒）

- 真鍮の鐘の、倍音が少しずつずれた「ゴーン」。低くて、長くて、温かい。

## 10. ボイス（文字送りの音）

### 11.2 カテゴリごとの目安

エンジンの v の範囲と、リミッター手前でのピークの目安。**ヘッドホンと、ノートPCのスピーカーの両方で確認する**。

| カテゴリ | v の範囲 | ピークの目安 | 例 |
|---|---|---|---|
| 重い一撃 | 0.40〜0.60 | −3dBFS | `se_stamp_heavy` `se_don` `se_ojigi_press` `se_encounter` |
| 攻撃・被弾 | 0.12〜0.25 | −6dBFS | `se_hit_*` `se_bishi` `se_damage` |
| 能力・ジングル的なSE | 0.05〜0.10 | −10dBFS | `se_hanamaru` `se_kiran` `se_heal` |
| UI | 0.05〜0.16 | −16dBFS | `se_cursor` `se_confirm` |
| 文字送り | 0.02〜0.09 | −20dBFS | ボイス |
| 足音 | 0.02〜0.05 | −24dBFS | `se_step_*` |
| 環境音 | 0.002〜0.03 | −30〜−36dBFS | `amb_*` |
| BGM | 各曲の中で 8声の合計 | 戦闘 −12dBFS、町 −15dBFS、家・店 −16dBFS、タイトル −18dBFS、夜 −20dBFS | |

- **BGM どうしの音量差**：戦闘曲を基準（0dB）に、町 −3dB、家と店 −4dB、モール −4dB、タイトル −6dB、エンディング −5dB、夜 −8dB。曲の中の v はこの差を守るように合わせる（曲の最後にマスター Gain を1つ持つ）。

### 11.3 ダッキング

| きっかけ | 対象 | 量 | アタック／ホールド／リリース |
|---|---|---|---|
| 重い一撃（`se_stamp_heavy` `se_don` `se_ojigi_press` `se_crit` `se_thud_low`） | BGM | −4dB | 5ms／80ms／250ms（サイドチェインのような押し込み。手応えの一部） |
| ツッコミ成功 `se_bishi`、ジャスト `se_kiran` | BGM | −3dB | 5ms／60ms／200ms |
| フィールドの会話（文字が出ている間） | BGM | −2dB | 150ms／―／400ms（戦闘中はしない） |
| ジングル（`levelup` `item` `join`） | BGM | 一時停止（6.1） | |
| 17:00 のチャイム | BGM | −12dB | 13.1 |
| 放送（`broadcast` のボイスと `se_pa_chime`） | BGM −9dB、環境音 −6dB | | 300ms／―／800ms |
| `se_bell_kanenari` | ほかのSE −6dB | | 鐘の4秒間 |
| メニュー（`muffle`） | BGM | LP1.8kHz＋−3dB | 7.4 |

- ダッキングは `musicDuck` の Gain で行う。重なったら、いちばん深いものを採る（掛け算しない）。
- `duckMusic(amount, seconds)` は既存の関数を使ってよい（amount は線形。−4dB＝0.63、−12dB＝0.25）。

### 11.4 空間（リバーブ）

`setSpace(id)`。ワールドがマップに入ったとき、戦闘が始まったときに呼ぶ。IR はノイズを指数減衰させて作る（既存の方式）。

| id | 使う場所 | 長さ | 減衰の指数 | HP | 送りの既定 | 聞こえ方 |
|---|---|---|---|---|---|---|
| `outdoor` | 町の屋外 | 0.8秒 | 4.0 | 300Hz | 0.25 | 乾いた夕方の空気 |
| `room` | 家、店 | 0.45秒 | 5.0 | 350Hz | 0.20 | 小さな部屋 |
| `hall` | モール M1〜M4 | 2.6秒 | 2.4 | 250Hz | 0.45 | がらんとした吹き抜け。足音が遠くまで響く |
| `maigo` | 迷子センター M5 | 1.2秒 | 3.0 | 250Hz | 0.35 | 閉じた小部屋。ボスの登場の静けさ |
| `battle` | 戦闘 | 1.1秒 | 3.2 | 300Hz | 0.25 | |
| `night` | エンディングの夜 | 1.8秒 | 3.0 | 250Hz | 0.35 | |

- 既存の `reverbSend.gain`（0.35）を「送りの既定」で置きかえる。切り替えは0.3秒のクロスフェード。

### 11.5 同時発音とランダム化

| 規則 | 内容 |
|---|---|
| 同じSEの同時発音 | 足音2、`se_coin` 6、`se_count` 1（45ms以内はまとめる）、`se_hit_*` 3、そのほか 4。超えたら一番古いものを 10ms で止める |
| 全体の上限 | SE 24声、BGM 40声（FMの変調器は数えない）。超えたら v の小さい順に切る |
| ランダム化 | 連続しやすい音（足音、ヒット、判、コイン、カーソル、ブリップ）は、呼ぶたびに音程 ±3〜5%、v ±10%。**`se_warn` と `se_ring` はランダムにしない**（タイミングの基準なので） |
| 定位 | 戦闘の敵のSEは、敵のx座標で pan＝(x−192)/192×0.3。フィールドの物のSEは、画面中央からの横位置で pan＝±0.5 まで、距離で v を下げる（8タイルで −12dB） |
| ヒットストップ中 | SEは止めない（打撃の音はヒットストップの頭で鳴る）。BGMも止めない |

### 11.6 音量の設定

- 「せってい」に **BGM** と **効果音** の2本（0〜10、既定 BGM 7、効果音 8）。
- Gain＝(値/10)²。0 は完全に無音。
- 変更は 60ms で追従。効果音のつまみを動かしたら、確認に `se_confirm` を鳴らす。
- 保存は設定（UIチーム）で、起動時に `setVolume('bgm', n)` `setVolume('se', n)` を呼ぶ。

## 12. 切り替え演出

### 12.1 フィールド → 戦闘（20_systems_battle 16.1 の 500ms に合わせる）

| 時間 | 音 |
|---|---|
| 0ms（接触） | フィールドのBGMに**テープブレーキ**：`musicDetune` を −500セントへ 120ms、`musicFilter` を 8kHz→300Hz へ 150ms、音量を 150ms で 0。いまの再生位置を覚えておく（12.3）。環境音は 200ms で −12dB |
| 100ms | `se_encounter`（朱の丸判がペタン） |
| 100〜500ms | `se_encounter` のにじみが鳴っている |
| 500ms | `setSpace('battle')`。`musicDetune`・`musicFilter` を元に戻し、戦闘曲を**導入の小節から**頭出し。導入の刻みと敵の登場（500〜800ms）が重なる |
| 敵の登場 | `se_enemy_appear`（1体ごと） |
| 先制・不意打ち | `se_initiative`／`se_ambush` |

- **ボス戦**：0ms のテープブレーキはしない（迷子センターはもともとBGMなし）。`evt_boss_intro` の最後に `se_chime_note`（E5）→ 切り替え。戦闘曲 `bgm_boss` は導入 BO1 から。
- **イベント戦（カネナリくん、ハト係長）**：同じ手順。
- **中ボス**：`evt_ojigi` の「ドスン」（`se_ojigi_press`、vol .6）のあとに切り替え。

### 12.2 マップの出入りと「続きから」

| 場面 | 音 |
|---|---|
| 同じBGMのマップへ移る（例：モールの M1→M2） | BGM はそのまま。環境音と空間だけ切り替える |
| 違うBGMのマップへ移る（例：町→肉屋） | 扉のSE → 画面のフェードアウト（300ms）と同時に今のBGMを 0.3秒でフェードアウト → フェードインと同時に次のBGM（0.3秒） |
| 町に戻る | 町のBGMを**続きから**：`playBgm(id, { resume: true })`。最後に止めた小節の頭から、0.6秒でフェードイン |
| 続きからの有効期限 | 止めてから90秒以内。それより長いと頭から（ただし導入の小節は飛ばす） |

### 12.3 戦闘 → フィールド

| 場面 | 音 |
|---|---|
| 勝利 | 最後の撃破の演出中（ヒットストップ、白フラッシュ、縮む）は戦闘曲を −12dB。勝利の大判で `bgm_jingle_victory`（戦闘曲を置きかえる）→ 余韻のループ → 結果 → 戻りの切り替え（450ms）の頭で `stopBgm(0.3)` → 300ms 後に、**接触した時点で鳴っていたBGM**を続きから 0.8秒でフェードイン |
| にげる成功 | `se_flee` と同時に、戦闘曲にテープブレーキ（−300セント、200ms。ずっこけた感じ）→ 戻りの切り替えでフィールドのBGMを続きから |
| 接触した時点でBGMがなかった | 戻っても無音（例：17:00 の直後のハト係長。13.1） |
| 空間 | 戻りの切り替えで、フィールドの空間へ |

### 12.4 段階の切り替え

- 段階0→1、1→2 は通常のフェードではなく、13章のキューシートの演出で行う。
- 段階の切り替えで屋外の環境音も替わる（4.2）。

### 12.5 全滅

| 時間 | 音 |
|---|---|
| 0ms | 最後の味方がへばる：`se_ko` |
| 500ms | 戦闘曲を 0.8秒でフェードアウト。環境音も止める |
| 「きょうは ここまで。」の表示 | `bgm_jingle_gameover` |
| 選択肢 | `se_cursor` `se_confirm`。やりなおすときは、フィールドに戻ってから通常どおり |

### 12.6 ポーズとタブの切り替え

- ブラウザのタブが隠れたら `AudioContext.suspend()`、戻ったら `resume()`（シーケンサは時計を ctx.currentTime で持つので、ずれない）。
- 起動直後は無音。最初のキー入力かタップで `unlockAudio()`（既存）。タイトルの「ボタンを押してください」で必ず解錠される。

## 14. API（実装者向け）

既存の `src/audio/index.ts` の関数名（`sfx` `playBgm` `stopBgm` `duckMusic` `textBlip` `unlockAudio` `registerSfx` `registerBgm`）はそのまま使い、引数を増やす。他チームはこの一覧の関数だけを呼ぶ。

```ts
// ---- 効果音 ----
export interface SfxOpts {
  pitch?: number;   // すべての周波数に掛ける（既定1）
  pan?: number;     // −1〜1。レシピの pan を上書き
  vol?: number;     // すべての v に掛ける（既定1）
  at?: number;      // ctx.currentTime 基準の開始時刻（省略で即時）
  note?: string;    // se_chime_note など音程を取るSE（'G4'）
  hold?: number;    // 秒。se_chime_note の伸ばし
  grade?: 'kukkiri' | 'futsu' | 'kasure'; // se_hanamaru, se_mimashita, se_rewind
  dur?: number;     // ms。se_ring の長さ
  level?: number;   // se_kire_up の 1〜3
}
export function sfx(id: string, opts?: SfxOpts): void;

export interface LoopHandle {
  set(param: string, value: number): void; // se_hanko_charge: 'amount' 0〜1, 'zone' 0/1
  stop(fade?: number): void;               // 秒
}
export function sfxLoop(id: string, opts?: SfxOpts): LoopHandle; // se_hanko_charge, se_roulette

// ---- BGM・ジングル ----
export function playBgm(id: string, opts?: { fade?: number; resume?: boolean }): void;
export function stopBgm(fade?: number): void;
export function currentBgmId(): string | null;
export function bgmTapeStop(seconds: number, semitones: number): void; // 音程を下げながら止める（17:00）
export function duckMusic(amount: number, seconds: number): void;      // 既存
export function muteMusic(seconds: number): void;                        // 無音の間（かねを鳴らす、ボスの1拍）
export function setMusicParam(name: 'stage' | 'kire' | 'boss_phase' | 'muffle', value: number): void;

// ---- チャイム ----
export function playChimeMotif(opts?: {
  notes?: 4 | 8; gap?: number; cut?: boolean; cutAt?: number; lastHold?: number; onNote?: (i: number) => void;
}): Promise<void>;

// ---- 環境音・空間 ----
export function playAmbient(id: string, opts?: { vol?: number; fade?: number; lp?: number }): void; // lp: 壁・窓ごしのこもり（Hz）
export function stopAmbient(id: string, fade?: number): void;
export function stopAllAmbient(fade?: number): void;
export function setAmbientVol(id: string, v: number, ramp?: number): void;
export function ambientEvent(id: string, name: string, pan?: number): void; // 'flicker' など
export function setSpace(id: 'outdoor' | 'room' | 'hall' | 'maigo' | 'battle' | 'night'): void;

// ---- 文字送り・設定 ----
export function textBlip(voiceId: string, ch: string): void;             // 既存
export function setVolume(kind: 'bgm' | 'se', value0to10: number): void;
export function unlockAudio(): void;                                     // 既存
```

### 15.2 シーケンサ

- 25ms ごとのタイマーで、120ms 先までの音符を `ctx.currentTime` 基準で予約する（先読み方式）。`requestAnimationFrame` には頼らない（タブが隠れても曲がずれない）。
- 曲のデータ：`{ bpm, meter, swing, sections: { name, bars }[], order, loopFrom, parts: { id, ins, bars: string[] }[], transforms }`。
- 小節ごとに拍子を持つ（`[7/8]` など）。ステップの長さ＝60/bpm/4 秒。スウィングは奇数ステップ（swing16）または8分裏（swing8）の開始時刻だけをずらす。
- 段階の変換（5.4）とキレのレイヤー（5.7）は、パートごとの `when: (params) => boolean` と、音符ごとのフィルタ（例：「ステップ8〜11で始まる音を鳴らさない」）で書く。
- `musicDetune` は ConstantSourceNode 1つ。曲の各発振器の `detune` に `connect` する。テープの揺れは、このノードの offset に LFO（OscillatorNode→Gain）を足し込む。
- 続きから：止めたときの「小節番号」を保存し、`resume` ではその小節の頭から予約を始める。
- ジングルの一時停止：`musicDuck` を 0 にし、シーケンサの予約は続ける（再開のとき拍がずれない）。

### 15.3 パフォーマンス

- ノイズのバッファは1つを使い回す（既存）。PeriodicWave（矩形波25%・12.5%）はキャッシュ（既存）。
- 音符ごとにLFOを作らない。ビブラートとトレモロは、パートごとに1つのLFOを作って共有する。
- 発音が終わったノードは `onended` で `disconnect` する。
- 同時発音の上限（11.5）を守る。ノートPCのCPU 5%以内を目安に、ボス戦（いちばん声が多い）で計る。

### 15.4 サウンドテスト（開発用）

- 開発ビルドだけ、`?sound=1` で全BGM・SE・環境音・ボイスを鳴らせるジュークボックスを出す（`src/debug.ts` から）。キレ、段階、ボス段階のつまみも付ける。**製品ビルドには入れない**。
