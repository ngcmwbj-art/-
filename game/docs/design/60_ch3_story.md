## 0.1 第3章をひとことで

正午で止まった「海ぞいの町」に、しゅんとグソっ君は、いつものツガオ便の軽トラの荷台で着く。町の3つの「まだ」（市場・食堂・海水浴場）をほどき、ハンコ「いただきます」で、引退するサイレン「ナリオサメ」を最後まで鳴らしきる。そのあと同じ軽トラで、まだまだ団の事務所（旧水族館）へ。ツガオに一度負けて捕らわれ、助けに来たたかし＝**ヤキソバン**と3人で、ヒロスケとポコシャの「まだ」をほどく。ヒロスケの運転するツガオ便が、しゅんが話しかけてきた町と村の人たちを拾ってくる。最後はコマンド「よぶ」で、みんなが自分の手で描いたはなまるが黒い回覧板をうめ、ツガオに「おつかれさま」。決着のあと、グソっ君は自分の生まれ（ツガオが捨てた、戦闘の実験用のペット）を知り、それでも「しゅんが 見つけてくれた グソっ君」として、たかしの店で生きていく。

### 1.2 世界のルール（第3章で足すもの）

- 第1章・第2章のルールはそのまま生きている（「見てもらえたモノは、そのモノのままでいられる」「町ごとに違う時刻で止まっている」「止まっている町で過ごした時間は、ほかの町では数えない」）。
- **海ぞいの町は 8月31日の 12:00 で止まっている**（夏休みの最後の日の正午）。HUD の時計は「12:00」でコロンが点滅しない。第2章のテレビ「海ぞいの 町では、朝から ずっと『正午』です」、第2章のカット7の壁の時計「海ぞいの町」12時、ツガオの止まった腕時計（12時）と同じ。
- **止まった理由**：町に正午を知らせてきたサイレンが、8月31日の正午の1回で引退する（9月1日からは、ふつうのチャイムの放送に替わる）。サイレン番のミナトが最後のボタンを押した瞬間、サイレンの「まだ 鳴り終わりたくない」に、ツガオが黒い判「まだ」を押した。サイレンは鳴りはじめの最初の音のまま止まり、町は「正午になったところ」から先へ進まない。
- **ごちそうさまが言えない**：正午は「いただきます」の時間。町の人はお昼ごはんを食べるが、食べ終わって「ごちそう……」と言いかけると、サイレンの最初の音がもう一度鳴り（`se_c3_siren_head`）、また「いただきます」の前にもどる。だから、お昼ごはんを何回も食べている（第2章の母「お昼ごはん、何回 食べるのかしら」の回収）。おなかはいっぱいにならない（ふしぎの町なので）。
- **町の3つの「まだ」**：サイレンのほかにも、今日で終わるものの「まだ」に黒い判が押されている。①市場のセリ（ゲンの声が「ひゃくえん」の途中で止まる）②食堂かもめ（ナミエが今日で店をたたむ。「ごちそうさま」を聞いたら終わってしまう）③海水浴場（今年最後の海。監視員のカイトが遊泳旗を下ろせない、ウミが海に入れない）。3つをほどくと、ハンコ「いただきます」の部品（お箸・合掌・声）が1つずつ集まる。
- **旧水族館は、ナリオサメのあとも 12:00**：町はずれの閉館した水族館（『ふしぎな 深海生物展』の元の会場）は、まだまだ団の事務所。入口の貼り紙『本日 休館』に黒い判「まだ」があって、町の時計が 12:01 になっても、館の中だけ正午のまま。
- **ツガオの「まだ」**：40年、毎朝5時の集荷を1日しか休まなかった。休んだ1日（白紙の日＝第1章でグソっ君が公園で見つかった前の晩）を思い出さないために、自分に「まだ 休めない」を押している（S30 で明かす）。止めた時間を「休みの貯金」としてためるのは、本当は**自分では休めない人の、休み方の練習**だった（S27・S30）。
- **よぶ**（決戦だけ）：しゅんが話しかけてきた人たちは、自分の手で描いたはなまるを持って来る。ハンコは押したらそれきりだが、人が手で描いたしるしは、また別の人が描き写す（第2章カット7のツガオの言葉の、本当の形）。
- **第3章で「平和」という言葉は使わない**（第2章カット7の1回だけ。2.1）。

### 3.4 来る人（第1章・第2章で、しゅんが話しかけた人だけ）

> 決定（2026-10-08・2回目）：**来る人は、第1章・第2章でしゅんが話しかけた人だけ**。話しかけていない人は来ない。寄り道を済ませた人には、その寄り道の続きの台詞や絵がつく。決定（2026-10-10）：**みんなを連れてくるのはヒロスケのツガオ便**。

**判定**

- `flag_talked_<npc_id>`（3.0）。第1章・第2章のセーブには無いので、第3章の始まり（evt_ch3_prologue の最初）に、次のどれかがあれば1にする：`flag_seen_<npc_id>_*`（会話のキーの記録。`pickTalk`）、その人の寄り道のフラグ（下の表の「寄り道」列）、その人の本筋のイベントのフラグ。**本筋で必ず話す人**（おばあ、くま吉、ペロ、マサル、まつ先生、ハモ区長）は、第1章・第2章を遊んだ人なら必ず1。「第3章から」の標準データでも1。

## 12. ほかの担当への申し送り

### 12.1 全体・実装（events・ui）

1. **名前は仮**：町の人の表示名は1つの表（`C3_NAMES`。`npc_c3_*` → 表示名）から。台詞の中の名前（「ナミエおばちゃん」「ゲンじい」「ミナトさん」など）も、その表から差しこむ。名前が変わったら、文字数の検査（`textcheck2`・`wrapCheck`）をやりなおす。
2. **話しかけた記録**：`flag_talked_<npc_id>` を、会話の入口（`src/world/interact.ts` の話しかけ）で全員に立てる。第1章・第2章のセーブからは、evt_ch3_prologue の最初に `flag_seen_<npc_id>_*` と寄り道のフラグ（3.4 の表）から作る。`pickTalk` の `direct` キー（`s1-2` など）は `flag_seen_` を残さないので、第1章・第2章で `direct` キーしかない人の一覧を作り、取りこぼす人がいれば、その人の寄り道や本筋のフラグで代わりに判定する（実装の担当に確かめてほしい）。
3. **会話のキーの接頭字 `c`**：`flag_ch3_stage` を見て `c1_1` などを選ぶ（第2章の `h` と同じしくみ。02 6.2）。
4. **かっこの使い方**：この本の msg ブロックでは、地の文と台詞に（）を使っていない（10 1.2）。演出メモ（`>`）に書いたかっこは表示しない。
5. **2D でも最後まで**：HD-2D の見せ場（サイレン塔からの見下ろし、深海の展示室の暗さと光、大水槽の光、集合写真）は、2D では同じ構図の絵か、ふつうの見下ろしで。台詞・時間・音は同じ。
6. **来る人の列**：S25 の自動歩行で、来た人が多いとき（最大 24＋町の人）は、2D・HD-2D とも先頭の6人だけ列で歩かせ、ほかはホールに先に立っている形でよい（62・61 と決める）。
