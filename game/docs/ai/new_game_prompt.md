# 新しいゲームを作るときのプロンプト（ひな形）

『しゅんの夕暮れあぜ道戦記』の作り方をもとにした、ほかのゲームでも使える依頼文です。
【 】の所を書きかえて、新しいセッションの最初に貼りつけて使います。
いらない行は消してかまいません。

---

## ここから下を貼りつける

ブラウザで遊べる【ジャンル：例 2D RPG／パズル／アクション】を作ってください。

### 1. どんなゲームか
- 題材・雰囲気：【例：田舎の夏休み、日常の中の少しふしぎなこと】
- 参考にしたいゲーム：【例：○○の「現代の日常×奇妙さ」】。参考にするのは遊びの作りだけ。名前・キャラ・絵・曲・セリフのまねはしない。似すぎている所は、先に洗い出して消す。
- 主人公と相棒：【決まっていれば書く。なければ案を3つ出して選ばせて】
- 長さ：まず【5〜10分】で遊べる最初の1章（体験版）を作る。あとから章を足す。
- 遊ぶ端末：PC・iPad・スマホのブラウザ。キーボードとタッチの両方で遊べること。私は主に【iPad】で確かめる。
- 品質：お店で売っているインディーゲームの体験版と並べても見劣りしないこと。仮の四角や絵文字での代用、押しても何も起きないボタン、「あとで作る」の書き置きはなし。

### 2. 作り方の決まり
- 絵はプログラムで描くドット絵、音は WebAudio で作る。画像・音声ファイルや外部ライブラリを足すときは、先に私に聞く。
- 画面に出る文はすべて日本語。1ページ【3】行まで。
- 私は【職業：例 F1 肥育の農家】です。【牛・田んぼ・野菜】が出てくるときは、その道の人が見て正しく書く。自信のない事実は調べてから書く。
- 作業はこのブランチで行い、直すたびにコミットとプッシュをする（コミットメッセージは日本語）。
- 返事は日本語で、専門用語は少なめに。

### 3. 進め方
1. **設計書を先に作る**：コンセプト（ねらい・あらすじ・主な人物・遊びのしくみ・参考作との違い）を docs/design/ に書き、私に見せる。大事な決定は、私が選べる形で聞く。
2. **土台を作る**：画面・入力・会話・セーブなどのしくみを先に作り、作りの説明（docs/ARCHITECTURE.md）を書く。
3. **手分けして作る**：絵・マップ・戦闘・音などは、サブエージェントに担当を分けて同時に作ってよい。それぞれに指示書（docs/briefs/）を渡し、担当外のファイルは触らせない。まとめ役のあなたが確かめてからコミットする。
4. **目で確かめる**：作った画面は写真に撮って実際に見る。「撮る→見る→直す」を最低3回くり返す。
5. **自動で通しテスト**：機械がゲームを最初から最後まで遊ぶテストを早めに作る。直すたびに流して、止まる所・エラー・進めなくなる所がないか確かめる。章が増えたら章ごとに足す。前の章をクリアしたデータから次の章へ進む道も、テストに入れる。
6. **文の点検**：文字のはみ出し・1ページの行数・同じギャグのくり返しを数える道具を作って使う。
7. **公開して見せる**：ひと区切りごとに、私だけが見られる公開ページ（Artifact）を更新して、URL と「見てほしい所」を伝える。

### 4. 記録
- 決めたことは docs/design/ に、守るルールは AGENTS.md（と CLAUDE.md）に短く書いて、毎回守る。
- 不具合は docs/game/bugs.md に「症状・再現手順・原因・直し方」を書く。
- 長い作業の途中経過は tasks/active.md と tasks/handoff.md に書く（会話が長くなって要約されても続けられるように）。
- 私の最初の依頼文（このプロンプト）は docs/ai/request.md にそのまま保存しておく。

### 5. 報告のしかた
- 何を変えたか、どう確かめたか（成功・失敗・未確認を分けて）、私に見てほしい所を、短く伝える。
- 確かめていないことを「確認済み」と書かない。

### 6. してほしくないこと
- 私に聞かずに：公開・投稿・購入・外部サービスへの登録・ファイルの大量削除や大きな作り直し。
- `git reset --hard`、`git clean`、履歴の書きかえ。
- 秘密の情報（APIキー・.env・パスワード）を開く・表示する。

まずは、コンセプトの案を3つ出して、それぞれの面白さと、参考作に似すぎていないかの点検を見せてください。

## 使うときのコツ
- 最初のプロンプトは、のちのち見返せるように docs/ai/request.md へ保存させる（今回のゲームでは原文が残らなかった）。
- 毎朝の「げむきか（追加案）」「改善会議」がほしくなったら、あとから「毎朝○時に追加案を5つ出す定期実行を作って」と頼めば足せる。
- 遊んで気になった所は、「どこで・何をしたら・どうなった」を書いて送ると、早く直せる（例：「２章をクリアした後にそのまま3章を始めて、お母さんと話し終えたらしゅんが動かなくなった」）。
