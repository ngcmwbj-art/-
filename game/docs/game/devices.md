# 対応端末と入力

## 端末と画面
| 端末 | 入力 | QA で使ってきた画面サイズ（CSS px） | 確認の状態 |
|---|---|---|---|
| PC | キーボード・ゲームパッド | 1280×720 | Chromium（Playwright）で自動確認 |
| iPad 横（全画面の重ね置き） | タッチ | 1210×654（iPad Pro 11 の Claude アプリ）、1000×540、1024×600 | Chromium のタッチ再現で確認。実機は依頼主が確認 |
| iPad 縦 | タッチ | 820×1100 | Chromium で確認 |
| スマホ横 ／ 縦 | タッチ | 844×390 ／ 390×844 | Chromium で確認 |

- 実機の Safari（iPad・iPhone）は、自動の確認ができない。依頼主の報告で確かめる（未確認の項目はそう書く）。

## 気をつけること
- タッチ：iPad 横ではボタンは下の角に固定。中身がボタンをよける（src/engine/safezones.ts の `buttonZones()`・`freeSpan()`。スマホと PC では null）。
- 画面サイズの変更と縦横の回転：レイアウトが組み直される。回転のあとも文字がはみ出さないか `__game.cmd.wrapCheck()` で見る。
- 音の自動再生の制限：音は最初の操作のあとに鳴り始める（README.md）。
- 発熱：第2章でスマホが熱くなった件は、描画と音を軽くして対応した（docs/design/02_ch2_index.md の変更の記録 #62）。
