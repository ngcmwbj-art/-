# ゲームの概要（入口）

本体の設計は docs/design/ にあります。このファイルは入口の要約だけです。食い違ったら docs/design/ が正です。

## 概要
- 『しゅんの夕暮れあぜ道戦記』：夏休みの最後の日、夕方5時のチャイムが4つ目の音で止まった町を、小学5年生の小林しゅんが歩く2D RPG。
- だれも倒されない「戦記」。争いをツッコミとハンコで終わらせる（docs/design/00_concept.md）。
- 第1章 夕鳴町（17:00 で止まる）／第2章 星見台（4:59 で止まる）／第3章は構想（03_ch3_memo.md。第1・2章でばらさない）。

## 操作（README.md の「遊び方」が正）
- 移動：矢印キー／WASD、十字キー。決定：Z／Enter／スペース。キャンセル：X／Esc。メニュー：C／Tab。ダッシュ：Shift。
- スマホ・タブレット：画面上の十字キーと「けってい」「ダッシュ」「メニュー」ボタン。ゲーム画面のタップも「けってい」。

## 勝ち負け
- 戦闘は敵を倒さず、ツッコミ・たたく・ハンコで「みました」の判を押して終わる（docs/design/20_systems_battle.md、第2章は 51_ch2_battle.md）。
- 勝利・敗北・レベルアップの流れ：20_systems_battle.md の 16.12 と 18 章。負けられる戦闘（canLose）の扱いもそこを見る。

## 画面構成
- 内部解像度 384×216 を整数倍に拡大して描く。会話の窓は1ページ3行まで。
- iPad 横の全画面ではボタンを下の角に固定し、会話・戦闘・メニュー・店の中身がボタンをよける（docs/ARCHITECTURE.md の touch の項、src/engine/safezones.ts）。
