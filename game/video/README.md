# video/ の使い方

工程の順：企画 → 台本 → 素材 → ナレーション・BGM → 編集 → 字幕 → サムネイル → 書き出し → 公開準備

| フォルダ | 置く物 |
|---|---|
| 01_plan/ | 企画・構成のメモ |
| 02_script/ | 台本・字幕の文 |
| 03_assets/ | 素材（images・audio・bgm・voice）と sources.md（出所一覧） |
| 04_edit/ | 編集の中間ファイル、字幕ファイル（.srt など）、処理のスクリプト |
| 05_export/ | 書き出した動画（Git 管理外） |
| 06_publish/ | タイトル・説明文・タグ・サムネイル案の下書き（投稿はしない） |

書き出しの仕様は docs/video/specs.md。
