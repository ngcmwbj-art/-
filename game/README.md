# がんばれマサトくん！

迫り来る台風から、**量子力学**と**ギター**でキャベツを守り抜く、オープンワールド・タワーディフェンスのブラウザ版プロトタイプです。

- 詳しい仕様：[DESIGN.md](DESIGN.md)
- 動作環境：PC のブラウザ（Chrome / Edge / Firefox / Safari の最新版）、マウス推奨、音が出ます

## 遊び方（ローカル）

ES モジュールを使うため、ファイルを直接開くのではなく簡易サーバー経由で開いてください。

```sh
# リポジトリのルートで
npx http-server -c-1 .
# → http://localhost:8080/game/ を開く
```

three.js は CDN（jsDelivr）から読み込むので、初回はネット接続が必要です。

## 基本操作

| 操作 | キー |
|---|---|
| 移動 / ダッシュ / ジャンプ | WASD / Shift / Space |
| ギター（拍に合わせると JUST） | 左クリック |
| 観測パルス | F / 右クリック |
| 量子テレポート / 量子ギターソロ | R / Q |
| タワー選択 → 建設 | 1・2・3 → E |
| 台風を迎え撃つ / 操作説明 | Enter / H |

動作が重いときは、タイトル画面の「画質」を下げてください。
