# はなまる夕焼け（HANAMARU SUNSET）

夏休みの最後の日、夕方5時のチャイムが4つ目の音で止まった町を歩く、オリジナルの2D RPG の体験版です（約10分）。
MOTHER2 のような「現代の日常と、少しずつおかしくなる世界」を参考にしたゲームデザインで、キャラクター・マップ・敵・物語・UI・音楽はすべてオリジナルです。

## 遊び方

| 操作 | キーボード | ゲームパッド |
|---|---|---|
| 移動 | 矢印キー / WASD | 十字キー・左スティック |
| 決定・調べる・話す | Z / Enter / スペース | A |
| キャンセル・メニュー | X / Esc | B |
| メニュー | C / Tab | X / Y |
| ダッシュ | Shift（押しながら） | RB / RT |

スマートフォンでは画面に触れると仮想パッドが出ます。音は最初の操作のあとに鳴り始めます。

**戦闘のコツ**
- 敵の攻撃の直前に「！」が出たら決定ボタン。ツッコミが決まるとダメージが半分になり、キレゲージがたまります。
- 「たたく」は縮む輪が照準に重なった瞬間に押すと「いい音」。
- 「ハンコ」は決定を長押しして、朱肉のリングが満ちたところで離すと「くっきり」。

## 開発

```
npm install
npm run dev        # http://127.0.0.1:5173/
npm run build      # フォントのサブセット化 → 型チェック → dist/
npm run artifact   # dist を1枚のHTML（dist-artifact/hanamaru-sunset.html）にまとめる
```

- エンジン：TypeScript + Vite + 自作の Canvas2D エンジン（384×216 を整数倍拡大）。
- 画像ファイル・音声ファイルは使っていません。ドット絵はすべてコードで描き、音楽と効果音は WebAudio のシンセで生成しています。
- フォント：DotGothic16（SIL Open Font License 1.1）。`tools/font/` を参照。
- 設計書：`docs/design/`（コンセプト、シナリオ、戦闘、レベルとアート、サウンド）。
- 構成とチームの分担：`docs/ARCHITECTURE.md`、各チームの指示書は `docs/briefs/`。
- QA 用：`node tools/shot.mjs`（スクリーンショット）、`node tools/playthrough.mjs`（通しプレイの自動テスト）、ブラウザの `__game.cmd.*`（デバッグコマンド）。
