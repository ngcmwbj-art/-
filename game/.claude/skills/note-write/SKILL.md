# note-write

テーマ：$ARGUMENTS

.claude/rules/note.md と docs/note/style.md に従う。原稿は note/drafts/<日付>_<題>.md（1記事1ファイル）。

1. **想定読者と目的の確認**：だれに、読んで何が分かる・何をしてほしい記事か。style.md で「要確認」の所（読者・有料部分）は依頼主に聞く。
2. **構成案**：見出し3〜5個と、各見出しで書くことを1行ずつ。確認ポイント：構成。
3. **本文**：導入、見出しごとの本文、まとめ。数字・出典・引用は確かめた物だけ。
4. **タイトル案**：3つ。
5. **ハッシュタグ案**：5個前後。
6. **見出し画像の案**：言葉で1〜2案（必要なら画像生成の指示文）。画像を置くなら note/images/。
7. **推敲チェック**：誇張・あいまいな言い方・確かめていない事実・長い引用がないか。直した所を一覧にする。

投稿はしない。依頼主が公開したあと、控えを note/published/ に移すかどうかは聞いてから。
