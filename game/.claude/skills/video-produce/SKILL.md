# video-produce

形式とテーマ：$ARGUMENTS

工程ごとに成果物を保存し、各工程の終わりに「確認ポイント」を示す（依頼主の返事が必要な所は止めて聞く）。.claude/rules/video.md と docs/video/specs.md に従う。

1. **企画** → video/01_plan/<日付>_<題>.md：目的、見る人、尺、構成表（秒・場面・文字）。確認ポイント：尺と構成。
2. **台本** → video/02_script/<同じ名前>.md：ナレーションと字幕の文（時刻つき）。確認ポイント：言い回し。
3. **素材リスト** → video/03_assets/sources.md に行を足す：使う素材と出所・ライセンス。出所が分からない物は使わない。
4. **ナレーション・BGM**：このゲームの音を使うなら video/04_edit/pr_2026-10/audio.mjs のやり方で書き出す。声を入れるかどうかは specs.md（無ければ確認）。
5. **編集**：ffmpeg の処理をスクリプトかコマンドとして video/04_edit/<題>/ に残す。ゲーム画面は video/04_edit/pr_2026-10/rec.mjs のやり方で録る。
6. **字幕**：台本と一致させる（.srt を作るなら 04_edit に置く）。
7. **サムネイル案**：案を文で2〜3個（画像を作るなら 04_edit に）。
8. **書き出し** → video/05_export/（Git 管理外）。仕様に合うか確かめる（解像度・fps・尺・音が割れない）。
9. **公開準備** → video/06_publish/<題>.md（_template.md を写す）：タイトル案3つ、説明文、タグ。
   - アップロード・投稿はしない。
