# 動画の作業をするとき

- 工程の順を守る：企画 → 台本 → 素材 → ナレーション・BGM → 編集 → 字幕 → サムネイル → 書き出し → 公開準備。
- 元の素材は上書きしない。加工した物は別の名前で保存する。
- ffmpeg などの処理は、使ったコマンドやスクリプトを video/04_edit/ に残し、あとで同じ物を作れるようにする。
- 素材を足したら video/03_assets/sources.md に出所とライセンスを書く。出所が分からない物は使わない。
- 解像度・フレームレート・尺・音量は docs/video/specs.md に従う。チャンネルの表現方針（実写を混ぜるか、声を入れるか など）は specs.md の記載に従い、記載が無ければ依頼主に確認する。
- 書き出した動画は video/05_export/（Git 管理外）。アップロード・投稿はしない。
