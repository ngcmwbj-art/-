# note の記事を書くとき

- 普通の日本語で具体的に書く。不要な比喩や大げさな宣伝文句を抑える。
- 数字・出典・引用は確かめた物だけ使う。他人の文を長く引用しない。
- 見出しの構成、導入、まとめ、タイトル案、ハッシュタグ案をそろえる（docs/note/style.md）。
- 日時・通貨・単位・税込／税別は指定を確かめる。確かめていない換算や税の計算はしない。
- 原稿は note/drafts/（1記事1ファイル、Markdown）。投稿はしない。公開済みの控えは、依頼主が公開したあとに note/published/ へ。
