# がんばれマサトくん！ ゲームデザイン仕様書

> 迫り来る台風などの天災から、**量子力学**と**ギター**を駆使してキャベツを守り抜け！
> ジャンル：オープンワールド × タワーディフェンス × リズムアクション

この文書は製品版の仕様と、`game/` に入っているブラウザ版プロトタイプ（縦切りの体験版）の実装範囲をまとめたものです。
プロトタイプで実装済みの項目には **【実装済】**、製品版で作る項目には **【製品版】** と付けています。

## 0. グラフィック目標について（最初に正直に）

「PS5 を超えるグラフィック」は、**ブラウザ上の WebGL では技術的に到達できません**。
GPU への命令の出し方・使えるメモリ・レイトレーシングの有無などが、PS5 世代のゲームエンジンとは根本的に違うためです。

そこで二段構えにしています。

| | ブラウザ版プロトタイプ（このリポジトリ） | 製品版（目標） |
|---|---|---|
| 目的 | ゲームの面白さ（量子ルール・リズム・防衛）を今すぐ遊んで検証する | PS5 / PS5 Pro / ハイエンド PC で最高峰の映像 |
| エンジン | Three.js（WebGL2） | Unreal Engine 5.x |
| ライティング | 物理ベース＋ACES トーンマップ＋ブルーム＋環境マップ | Lumen（リアルタイム GI）＋ハードウェアレイトレ反射・影 |
| ジオメトリ | 手続き生成のローポリ〜ミドルポリ | Nanite（数十億ポリゴン級）で畑のキャベツ1玉1玉まで実物スキャン |
| 天候 | 2D 雲レイヤー＋GPU 雨＋ゲルストナー波の海 | ボリュメトリッククラウド、Niagara 流体の雨・波しぶき、Water System |
| 物理 | 簡易な吹き飛び演出 | Chaos 物理で畑・ハウス・トタンが本当に壊れる |
| 解像度 | 画質設定（低〜ウルトラ）で可変 | 4K / 60fps（性能モード 120fps） |

プロトタイプで遊んで面白さを固め、その仕様をそのまま UE5 に移植する、という流れを想定しています。

## 1. コンセプト

### 1.1 ログライン
銚子の台地でキャベツを育てる青年・マサト。毎年のように襲ってくる台風から畑を守るため、彼が手に取ったのは**愛用のエレキギター**と、独学で身につけた**量子力学**だった。

### 1.2 体験の柱（ピラー）
1. **守る緊張感** ― 嵐が近づくにつれて空が暗くなり、風が強まり、畑に危機が迫る。
2. **観測する快感** ― 揺らいで見える「重ね合わせ状態」の竜巻を観測し、本物を一発で暴き出す。
3. **弾く気持ちよさ** ― BPM に合わせてパワーコードをかき鳴らすと、衝撃波が嵐を吹き飛ばす。
4. **自分で育てた畑への愛着** ― 生き残ったキャベツはそのまま収穫・出荷され、次のシーズンの力になる。

### 1.3 トーン
ポスター「銚子のスイカ侍」と同じく、**本気の映画ポスター調の熱さ**と、量子力学×ギター×キャベツという**バカバカしさ**を両立させる。演出は大真面目、題材はちょっとおかしい。

## 4. ゲームの流れ

### 4.1 シーズン構成
1 シーズン ＝ 台風 5 回。1 回の台風が「1 ウェーブ」。

```
[準備フェーズ] → [台風接近（防衛）] → [台風一過・評価] → 次の台風 … → [収穫・リザルト]
```

| フェーズ | 内容 | 時間（プロトタイプ） |
|---|---|---|
| 準備 | 晴れ。Qビットが少しずつ貯まる。量子デバイスを建て、地形を下見する。Enter で切り上げ可 | 初回 50 秒 / 以降 30 秒 |
| 台風接近 | 空が暗くなり、雨・風・雷。竜巻・飛来物・落雷が畑を襲う | 実体の竜巻をすべて倒すまで（最大 200 秒） |
| 台風一過 | 嵐が引き、生き残ったキャベツの割合に応じてボーナス | 8 秒 |
| 収穫 | 5 回の台風を越えたらリザルト | — |

**敗北条件：** キャベツが全体の 30% を下回る（畑の壊滅）。

### 4.2 台風一覧【実装済】

| 台風 | 階級 | 最大風速 | 竜巻（重ね合わせグループ数） | 1グループの分岐数 | 飛来物間隔 | 落雷間隔 |
|---|---|---|---|---|---|---|
| 1号 | 強い | 33 m/s | 2 | 2 | 3.6 秒 | 6.5 秒 |
| 2号 | 非常に強い | 44 m/s | 3 | 2 | 3.0 秒 | 5.2 秒 |
| 3号 | 非常に強い | 50 m/s | 4 | 3 | 2.4 秒 | 4.2 秒 |
| 4号 | 猛烈な | 58 m/s | 5 | 3 | 1.9 秒 | 3.4 秒 |
| 5号「量子嵐」 | 観測史上最大 | 72 m/s | 6 | 4 | 1.5 秒 | 2.6 秒 |

竜巻の体力は `110 + 45 × (台風番号-1)`、移動速度は `3.6 + 0.45 × (台風番号-1)` m/s。
台風は毎回ランダムな方角（海側＝東〜南）から来て、風向きもそれに合わせて変わる。

### 4.3 製品版の追加ループ
- **育成【製品版】**：晴れの日に苗を植え、水やり・追肥・防虫。品種（春系・寒玉・グリーンボール・紫キャベツ）ごとに強さと売値が違う。
- **出荷と経済【製品版】**：収穫したキャベツを JA・直売所・漁港の食堂に出荷して「円」を得る。円で資材・エフェクター・タワーの改良を買う。
- **年間カレンダー【製品版】**：春キャベツ → 夏の台風シーズン → 冬の寒玉。季節ごとに天災の種類が変わる。

## 5. 天災

### 5.1 竜巻（重ね合わせ状態）【実装済】
本作の主役の敵。**最初は必ず「重ね合わせ状態」で出現する。**

- 紫〜シアンに揺らぎ、明滅する竜巻が 2〜4 本同時に現れる。そのうち**実体は 1 本だけ**。どれが本物かは観測するまでわからない。
- 未観測の竜巻には**ギターもアンプも効かない**（「観測されていない存在には干渉できない」）。
- 分岐はそれぞれ別のキャベツを目指して進む。

**観測のルール（量子力学の測定をゲーム化）**

| 状況 | 結果 |
|---|---|
| 観測範囲に**実体**が含まれる | 波動関数が収束。実体だけが残り、茶色い実体の竜巻になる（体力バー表示・攻撃可能） |
| 観測範囲に**幻の分岐だけ**が含まれる | 「そこにはいなかった」という測定結果で、その分岐だけが消える。残りが 1 本になれば自動で実体確定 |
| マサトが分岐に**体当たり** | 位置の測定とみなす。幻なら消え、実体なら収束（ただし吹き飛ばされる） |
| 放置して実体がキャベツに触れる | **デコヒーレンス**（環境との相互作用）で自動的に実体化し、そのまま畑を荒らし始める |

→ プレイヤーは「どこで観測するか」を考えることになる。範囲が広すぎると Qビットを浪費し、狭すぎると幻だけを消して終わる。

**被害：** 実体の竜巻は半径 6.5m 以内のキャベツに毎秒 48 ダメージ（台風が進むごとに +8%）。倒れたキャベツは竜巻に巻き上げられて螺旋状に飛んでいく。

### 5.2 落雷【実装済】
- ランダムなキャベツの位置に、黄色い**予告円（半径 5m）**が出る。2.6 秒後に着弾。
- 着弾すると円内のキャベツは全滅、マサトがいれば感電して吹き飛ぶ。
- **対処1：** 予告円の中で拍に合わせて（JUST）ギターを鳴らすと、雷を空へ**弾き返す**（+10Q・ソロゲージ +18）。
- **対処2：** トンネル避雷塔の範囲内なら、雷は塔に吸い込まれて Qビットに変わる（+6Q）。

### 5.3 飛来物（トタン板）【実装済】
- 風上から、壊れた小屋のトタン板が回転しながら放物線を描いて飛んでくる。着弾地点のキャベツに 75 ダメージ。
- ギターの衝撃波・アンプのパルスで撃ち落とせる（+3Q）。

### 5.4 製品版で追加する天災
| 天災 | 挙動 | 主な対処 |
|---|---|---|
| 高潮・高波 | 海側の畑に水の壁が押し寄せる | 量子トンネル堤防、波の位相を打ち消す「干渉アンプ」 |
| 雹（ひょう） | 広範囲に小ダメージが降り続く | もつれバリアで畑を覆う |
| 塩害の潮風 | キャベツがじわじわ弱る（継続ダメージ） | アルペジオでの回復、防風林の植樹 |
| 線状降水帯 | 一定時間、畑が冠水して成長が止まる | 排水路の掘削、テレポートでの資材運搬 |
| 崖崩れ（屏風ヶ浦） | 断崖沿いの畑が崩落 | 不確定性フィールドで落下物の位置を固定 |
| ボス：台風の目 | 最終ウェーブ。巨大な「目」が実体と幻を高速で入れ替える | 全観測塔を量子もつれでリンクして同時観測 |

## 6. 量子力学システム

量子力学の概念を、**直感的なゲームルール**に置き換えている。

| 概念 | ゲームでの扱い | 実装 |
|---|---|---|
| 重ね合わせ | 竜巻が複数の分岐として同時に存在する | 【実装済】 |
| 観測・波動関数の収束 | 観測すると実体ひとつに確定する | 【実装済】 |
| 負の測定結果 | 観測範囲に実体がいなければ、その分岐だけが消える | 【実装済】 |
| デコヒーレンス | 環境（キャベツ）との相互作用で勝手に収束する | 【実装済】 |
| トンネル効果 | 竜巻が障壁をすり抜けて沖へ飛ばされる／マサトが短距離ワープ | 【実装済】 |
| 量子もつれ | 2 つのタワーをリンクし、片方の観測をもう片方に共有 | 【製品版】 |
| 不確定性原理 | 対象の位置を固定するほど速度が不定になる（スローフィールド） | 【製品版】 |
| 量子ゼノン効果 | 観測し続けると竜巻が成長できない（観測塔の上位版） | 【製品版】 |
| シュレディンガーの箱 | 箱に入れたキャベツは「無事」と「全滅」の重ね合わせ。嵐の後に開けると 50%でボーナス 2 倍 | 【製品版】 |

### 6.1 リソース：Qビット
- 初期 150Q。準備中は毎秒 +1.5、嵐の中は毎秒 +0.6。
- 竜巻を倒す +25 / 雷を弾く +10 / 雷を吸収 +6 / トタンを撃墜 +3 / 台風一過ボーナス 30〜80。
- 消費：観測パルス 8Q、タワー建設 40〜60Q。

## 7. ギターシステム

### 7.1 リズム
- 曲は **BPM 120**、E5 → C5 → D5 → A5 のロック進行。ドラム・ベースはリアルタイム合成で、嵐の強さに応じて手数が増える。
- 画面下の**拍インジケーター**が縮んで重なる瞬間が拍。前後 **±110ms** 以内に弾けば **JUST**。
- 鳴らすコードは、その小節の進行に合わせて自動で変わる（どこで弾いても曲になる）。

### 7.2 アクション【実装済】
| 操作 | 名前 | 効果 |
|---|---|---|
| 左クリック | パワーコード | 周囲 9m と前方の扇形 17m に衝撃波。22 ダメージ |
| 左クリック（JUST） | ジャストコード | 前方の扇形が 21m に伸び **46 ダメージ**、周囲のキャベツを少し回復、雷を弾き返す、ソロゲージ上昇 |
| Q（ゲージ満タン） | 量子ギターソロ | 4.5 秒間、時間がゆがんで天災が 35% の速さに。半径 90m を一斉観測し、0.12 秒ごとに半径 42m へ連続攻撃 |

### 7.3 エフェクター（装備）【製品版】
足元のエフェクターボードに最大 4 個。組み合わせでビルドを作る。

| エフェクター | 効果 |
|---|---|
| ディストーション | 衝撃波のダメージ +30%、範囲 -10% |
| ディレイ | 0.75 拍後に衝撃波がもう一度出る（威力 50%） |
| コーラス | 衝撃波が 2 つに分かれ、左右に広がる |
| ワウ | 長押しで衝撃波の向きを振れる |
| ファズ（量子） | JUST 時に観測パルスが同時に出る |
| ルーパー | 4 小節分の演奏を録音し、アンプタワーに再生させる |

## 8. 量子デバイス（タワー）

### 8.1 プロトタイプのタワー【実装済】
| キー | 名前 | コスト | 範囲 | 効果 |
|---|---|---|---|---|
| 1 | 観測塔 | 40Q | 34m | 範囲内を常時観測。実体なら収束、幻なら消滅 |
| 2 | 量子アンプ | 60Q | 22m | 2 拍ごとに衝撃波（16 ダメージ）。収束済みの竜巻とトタンに有効 |
| 3 | トンネル避雷塔 | 50Q | 30m | 範囲の落雷を吸収して Qビットに変換。13m 以内に来た竜巻を 85m 沖へトンネル（塔ごとに 7 秒のクールダウン） |

建設：数字キーで選ぶ → マサトの 7m 前方に緑の半透明プレビュー（置けない場所は赤）→ E で建設。畑の上・水辺・他のタワーの 5m 以内には置けない。

### 8.2 強化・追加【製品版】
- 各タワー 3 段階強化（範囲 / 頻度 / 特殊効果）。
- **もつれリンク**：2 つのタワーを線でつなぐと、範囲と効果を共有。
- **干渉アンプ**：波の逆位相を出して高潮を打ち消す。
- **シュレディンガー倉庫**：収穫済みキャベツを一時的に重ね合わせ状態で保護。
- タワーは嵐の中で損傷する（竜巻の直撃で耐久減少）。準備フェーズで修理。

## 12. 映像演出
- **【実装済】** 嵐の進行に連動して：空の濁り・雲量と色・台風の渦を巻く雲・霧の濃さ・太陽光の強さ・海の波高と白波・雨の量と角度・草のなびき・灯台のビームの強さ・母屋の窓明かり・画面のカラーグレーディング（晴れ＝暖色、嵐＝寒色で彩度低め）。

## 14. プロトタイプの技術構成

```
game/
├── index.html        画面構成（タイトル・HUD・操作説明・リザルト）、three.js の読み込み
├── css/game.css      UI のスタイル
├── DESIGN.md         この仕様書
└── js/
    ├── main.js       ゲーム進行（フェーズ・ウェーブ）、入力、アクション、ポストプロセス
    ├── world.js      地形（手続き生成）、畑、草、防風林、母屋、ハウス、灯台、海
    ├── weather.js    空、雲、雨、霧、光源、環境マップ、稲妻
    ├── cabbages.js   キャベツ（インスタンス描画、体力、吹き飛び）
    ├── masato.js     マサトのモデルとアニメーション
    ├── player.js     操作と三人称カメラ
    ├── threats.js    竜巻（重ね合わせ・観測・デコヒーレンス）、落雷、飛来物
    ├── towers.js     量子デバイス 3 種
    ├── fx.js         衝撃波・観測球・光柱・パーティクル
    ├── audio.js      WebAudio によるリアルタイム合成
    ├── hud.js        HUD とミニマップ
    └── util.js       ノイズ・乱数などの共通処理
```

- 描画：Three.js r160、PBR、PCF ソフトシャドウ、ACES トーンマップ、UnrealBloom、カラーグレーディング／色収差／ビネット／フィルムグレインの自作パス、MSAA。
- 外部アセットは使わず、地形・モデル・テクスチャ・音はすべてコードで生成。
- 画質設定：低（影・草なし）／中／高／ウルトラ（影 4096、草 9 万株）。
