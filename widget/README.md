# Claude Code 進捗ウィジェット（iPhone）

iPhone のホーム画面に、Claude Code がこのリポジトリでどれだけ作業を進めたかを出すウィジェットです。
無料アプリ [Scriptable](https://apps.apple.com/jp/app/scriptable/id1405459188) の上で動きます。

## 出るもの

- 今日のコミット数と、今週の合計
- この7日間の日ごとの棒グラフ（今日だけオレンジ）
- さいきんの作業（コミットの1行目・どのブランチか・何時間前か）
- 公開中のゲームの本数（`portal/games.json` から）
- 「使用状況を開く」ボタン（claude.ai の使用状況の画面が開く）

大きさは 小・中・大 と、ロック画面用（横長）に対応しています。

## 使用状況（クレジット）について

**残りの使用量そのものは、ウィジェットに数字で出せません。**
Claude の月額プランの使用量（5時間の枠・週の枠・追加クレジット）を外から読む公式の方法が、
いまのところ用意されていないためです（2026年11月時点で確認）。

そのかわり、ウィジェットの「使用状況を開く」を押すと、claude.ai の使用状況の画面がすぐ開きます。
小サイズは、ウィジェットのどこを押してもその画面が開きます。

## 入れ方（最初の1回だけ）

1. App Store で **Scriptable** を入れる（無料）
2. iPhone の Safari で下のアドレスを開き、出てきた文字を **すべて選択してコピー** する
   `https://raw.githubusercontent.com/ngcmwbj-art/-/refs/heads/claude/cool-einstein-b2jskj/widget/loader.js`
3. Scriptable を開き、右上の **＋** を押して、コピーした文字を貼りつける。
   上の名前を押して「Claude進捗」などに変え、**Done** を押す
4. ホーム画面の何もないところを長押し →（左上の）**編集** → **ウィジェットを追加** → **Scriptable** を選び、
   好きな大きさで追加する
5. 置いたウィジェットを長押し → **ウィジェットを編集** → **Script** で、3 でつけた名前を選ぶ

貼りつけるのは「入口」（`loader.js`）だけです。本体（`claude-progress.js`）は GitHub から自動で取ってくるので、
あとで本体を直しても貼り直しは要りません。

## 知っておくこと

- 読むのは GitHub で公開されている情報だけです。パスワードやトークンは使いません
- 更新はおよそ30分おきです（いつ更新するかは iPhone が決めるので、もう少し空くこともあります）
- 通信できないときは前回の値を出し、右上の時刻が「前回 15:42」のようになります
- コミット数は、この1週間に動きのあった新しい順に4つまでのブランチを数えます
- 別のリポジトリを見たいときは、「ウィジェットを編集」の **Parameter** に `持ち主/リポジトリ名` と書きます
  （公開リポジトリのみ）

## 手元で確かめる

```sh
node widget/test/preview.mjs /tmp/preview
```

Scriptable の代わりをする最小限の部品で本体を動かし、実際の GitHub を読んで、
3サイズの見た目を HTML に書き出します。iPhone の描画そのものではないので、
文字の詰まり具合は実機と少し違います。
