# カード一覧

`data/cards.js` から `node tools/card_list.js` で自動生成しています（手で直さないでください）。

各農家タイプの欄には、そのタイプの報酬に出るカード（他のタイプと共有のものも含む）を載せています。「全員共通」のカードはどのタイプにも出ます。
