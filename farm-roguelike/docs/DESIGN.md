# のうか一年記（仮）— 設計メモ v0.1

デッキ構築ローグライク × 農業。春→夏→秋→冬の1年を乗り切り、冬のボスを倒せばクリア。
この文書は「実装前の確認用」です。ご確認いただいてから最小プレイ版に着手します。

---

## 1. 方針（技術）

| 項目 | 決めたこと | 理由 |
| --- | --- | --- |
| 置き場所 | リポジトリ直下に `farm-roguelike/` を新設 | 既存の `farm-puzzle/` や pOna のサイトと混ざらないように |
| ビルド | **なし**。素の HTML / CSS / JS（`<script>` を順に読む） | `farm-puzzle` と同じ作り。`index.html` を直接開いても動く |
| データ | JSON ではなく **JS ファイル**（`data/*.js`）に書く | JSON の `fetch` はダブルクリックで開くと失敗するため。書き方は JSON とほぼ同じ |
| 名前空間 | グローバルは `FR` 1つだけ（`FR.Cards`, `FR.Battle` …） | 読み込み順だけ気をつければよく、後から ES Modules / Vite にも移しやすい |
| 入力 | Pointer Events で **マウス・タッチを一本化** | タップで選択→もう一度タップ（または敵をタップ）で使用／上方向にドラッグして離しても使用 |
| 画面 | スマホ縦（360px幅）を基準に作り、iPad・PC は広げる | 縦持ちで片手でも遊べる配置を優先 |
| 絵 | 最初は絵文字＋CSS。表示はすべて `FR.Art.icon(id, emoji)` 経由 | `assets/img/<種類>/<id>.png` を置いて一覧に1行足せば画像に切り替わる |
| 乱数 | シード付き乱数（ラン開始時に決定） | セーブ→再開で同じマップ・同じ報酬になる（リロード稼ぎ防止） |
| セーブ | `localStorage`（キー `farm-roguelike-save`、`version` 付き） | マス移動のたび自動保存。戦闘中に閉じたら「その戦闘の最初から」再開 |

## 3. 画面遷移

```
タイトル ──(つづきから)────────────────┐
  │(はじめから)                          │
  ▼                                      ▼
農家タイプ選択 ──▶ 季節のマップ ◀──────────────┐
                    │ マスを選ぶ              │
     ┌──────┬──────┼──────┬──────┐            │
     ▼      ▼      ▼      ▼      ▼            │
   戦闘    市場   休憩  イベント  ボス         │
     │      │      │      │      │            │
     ▼      └──────┴──────┴──────┼────────────┤
   報酬 ─────────────────────────┼────────────┘
                                 ▼
                         季節の決算（次の季節へ）── 冬なら ──▶ 経営評価（クリア）
健康度が 0 になったら どこからでも ──▶ 経営評価（離農）
```

- **季節のマップ**：1季節 = 6段（5段＋ボス）。各段 2〜3マス、隣の段の近いマスとつながる（Slay the Spire 型）。
  - 1段目は必ず戦闘、5段目は休憩、6段目はボス。間は重み付きでランダム（戦闘45％・イベント25％・市場15％・休憩15％）
- **季節の決算**：その季節の収穫量・資金・被害を表示し、健康度を少し回復（季節の変わり目）。

## 4. 戦闘システム

### 基本（Slay the Spire 準拠）
- 毎ターン **5枚引く／エネルギー3**。使い切れなかった手札はターン終了で捨て札へ
- **健康度**（プレイヤーHP）＝農場の健康度。0 で離農（ゲームオーバー）
- **守り**（ブロック相当）：防鳥ネット・ビニールハウス・柵・畜舎など。ターン開始時に 0 に戻る
- 敵は頭上に **次の行動予告** を出す（🗡️6＝健康度へ6ダメージ、🥀＝弱らせる、🌱✖＝成長を止める など）

### 敵の倒し方は2種類
| 種類 | 例 | 勝ち方 |
| --- | --- | --- |
| 害獣・害虫・病害・雑草 | カラス、イノシシ、アブラムシ、いもち病、雑草 | **勢い**（敵HP）を 0 にすれば勝ち |
| 天候 | 干ばつ、台風、霜、大雪 | **勢いを0にする**か、**表示されたターン数を耐えきる**と過ぎ去る（耐えきった場合は報酬が少し減る） |

天候は「攻撃して倒す」が不自然なので、守って耐える遊び方もできるようにしています。

### 農業らしさの中心：「畑」と「畜舎」
戦闘画面の中央に **畑（3区画）** と **畜舎（2枠）** があります（数はレリックで増える）。

- **作物**：「種まき」「苗の植え付け」で区画に置く → 毎ターン終了時に1段育つ → 成長カード（水やり・肥料・日光）で早く育つ
  → 実ったら **収穫** カードで消費して **資金＋収穫量（スコア）＋戦闘効果**（例：トマト＝カードを引く、稲＝守り＋）
  - 稲は育つのに時間がかかるが収穫が大きい、葉物は早いが小さい…と作物ごとに個性
  - 果樹は「植えると実るたびに自動で少し資金」が入り続ける（収穫で消えない）
- **家畜**：「子牛導入」などで畜舎に入れる → **給餌** で育つ（自然には育ちにくい）→ **出荷** で大きな資金＋収穫量
  - 出荷時に **格付け（C〜A5）**：給餌・ワクチン・体調の積み重ねで上がる。高リスク高リターン
  - 敵の一部（鳥インフル・猛暑・イノシシ）は家畜や作物を **狙ってくる** ＝ 守らないと失う
- 畑と畜舎は **その戦闘の中だけ** のもの（戦闘が終わると、実っていた作物は自動で半額収穫）。
  ※ 果樹だけ「その季節の間は残る」にするか検討中（→ 7章の確認事項）

### 状態異常（例）
| 名前 | 効果 | StS の相当 |
| --- | --- | --- |
| 疲労 | 与える効果（除草など）が 25％減 | 脱力 |
| 荒れ地 | 受けるダメージが 50％増 | 弱体 |
| 乾燥 | 作物が育たない | （独自） |
| 地力 | 成長カードの効果＋1（溜まる） | 筋力 |

## 5. データ構造

### カード（`data/cards.js`）
```js
{
  id: 'weeding',            // 英数字（セーブで使うので後から変えない）
  name: '除草',
  emoji: '🌿',
  type: 'attack',           // attack 攻撃 / skill 防御・成長 / crop 作物 / livestock 畜産 / machine 機械
  cost: 1,
  rarity: 'basic',          // basic 初期 / common / uncommon / rare
  pool: ['common'],         // 出る農家タイプ（'common' は全員、'vegetable' など）
  target: 'enemy',          // enemy / self / plot（区画を選ぶ） / none
  text: '勢いに{damage}ダメージ',   // {名前} は effects の値で埋める
  effects: [{ op: 'damage', amount: 6 }],
  upgrade: { name: '除草+', effects: [{ op: 'damage', amount: 9 }] },
  exhaust: false            // 使うとこの戦闘から消える（廃棄）
}
```
**効果（`op`）を組み合わせてカードを作る** ので、新しいカードはほぼデータだけで足せます。
用意する op：`damage` `block` `draw` `energy` `heal` `gold` `status`（状態を付ける）
`plant`（作物を植える） `grow`（育てる） `harvest`（収穫） `addAnimal` `feed` `ship` `vaccinate` など。
どうしてもデータで書けない特殊カードだけ `custom: (ctx) => {…}` に関数を書けます。

### 作物・家畜（`data/cards.js` の中に一覧）
```js
CROPS:   { rice: { name:'稲', emoji:'🌾', stages:4, yield:30, onHarvest:[{op:'block',amount:8}] }, … }
ANIMALS: { wagyuF1: { name:'F1子牛', emoji:'🐂', stages:5, price:80 }, … }
```

### 敵（`data/enemies.js`）
```js
{
  id: 'crow', name: 'カラス', emoji: '🐦‍⬛', kind: 'pest',  // pest / disease / weed / weather / boss
  hp: [18, 22],                 // 勢い（範囲からランダム）
  turns: null,                  // 天候なら「耐えきるターン数」
  moves: {
    peck:  { intent: 'attack', damage: 6 },
    steal: { intent: 'special', text: '実った作物を1つ奪う', effects: [{ op: 'stealCrop' }] }
  },
  pattern: ['peck', 'peck', 'steal']   // 順番に繰り返す（ランダムや条件付きは ai 関数でも書ける）
}
```

### レリック（`data/relics.js`）
```js
{ id: 'strawHat', name: '麦わら帽子', emoji: '👒', rarity: 'basic',
  text: '戦闘開始時、守り4', hooks: { battleStart: [{ op: 'block', amount: 4 }] } }
```
発動タイミング（`hooks`）：`battleStart` `turnStart` `turnEnd` `cardPlayed` `harvest` `ship` `battleEnd` `restSite` など。

### 農家タイプ（`data/farmers.js`）
```js
{ id: 'vegetable', name: '野菜農家', emoji: '🥕', hp: 70,
  text: '回転が速い。カードを続けて使うと強くなる',
  deck: ['weeding','weeding','weeding','weeding','mulch','mulch','mulch','mulch','sowLettuce','harvest'],
  relic: 'basket',       // 初期レリック
  pool: 'vegetable',     // 報酬・市場に出やすいカード
  enabled: true }        // false にすると選択画面で「準備中」
```
**新しい農家タイプ＝この1件＋そのタイプ用のカード数枚＋初期レリック1つ** を足すだけで追加できます。

### ラン状態（セーブされる中身）
```js
{ version: 1, seed, farmerId, hp, maxHp, gold, deck: [{id, upgraded}], relics: [id],
  season: 0, map: {...}, position: {row, col},
  stats: { harvest: 0, shipped: 0, damageTaken: 0, battlesWon: 0 } }
```

## 6. 経営評価（スコア）

`スコア = 収穫量 ＋ 資金 × 0.5 ＋ 撃退数 × 10 − 受けた被害 × 0.5 ＋ クリアボーナス`
→ 「S：地域のモデル農家」〜「D：来年こそ」のランクと、内訳（収穫量・資金・被害）を表示。
最高スコアとクリア回数はラン外のデータとして保存します。

## 6.5 絵の方向性：「もののけ姫」のようなシリアスなタッチ

人の営み（農業）と、山・森・獣・天災とのせめぎ合いを、重く美しく描きます。
**作品のキャラクター・ロゴ・場面（神々や精霊のデザインなど）は使わず**、絵づくりの考え方だけを参考にします。

| 要素 | やること |
| --- | --- |
| 背景（`assets/img/bg/forest.svg`） | 夕方の重い空と、下のふちが金色に光る層雲。**稜線に針葉樹のぎざぎざがある山並みが何重にも重なり、山あいに霧**。手前左右に苔むした杉の巨木と垂れる枝葉、森を切り開いた畑。光の筋が霧を抜けて差しこむ。`tools/gen_bg_forest.py` で生成 |
| 獣・敵（`assets/img/art/`） | アニメ塗り（線＋平らな色＋影）だが **写実寄り**：白目なしの小さな光る目、剛毛・牙・筋肉の盛り上がり。かわいさより「野生の力」。`tools/gen_art.py` で生成 |
| 色 | 墨・苔・藍・朱・古い和紙。明るい原色は使わない。光は夕日と灯火の金色だけ |
| UI | 墨色の半透明パネル＋細い金茶の線、角はほぼ直角。行動予告は朱の札（「突進 12」）。アイコン絵文字は使わず漢字（銭・守り・道具） |
| カード | 古い和紙に墨の二重枠 |
| 文字 | 見出し・数字は明朝（しっぽり明朝 B1）、本文は角ゴシック（Zen Kaku Gothic New） |
| 敵の名前 | 「山の大猪」「群れ鴉」のように重みのある名前に |
| 動き（④以降） | 霧がゆっくり流れる、枝葉が揺れる、ボス戦は空が暗転し風が吹く。派手さより「間」 |
| 本物の絵に差し替えるとき | 背景は手描きの一枚絵（縦長 1200×2000 程度）、獣は透過PNG。`Art.icon()` に登録するだけで差し替わる |

※ 1つ前の明るい夏の里山版（`assets/img/bg/summer.svg`、`tools/gen_bg.py`）も残してあります。季節や場面で使い分けることもできます。

見本：`docs/mockup-battle.html`（戦闘画面の静的な見本。動きはありません）

## 8. 決まったこと

| 項目 | 決定 |
| --- | --- |
| 農家タイプ | **野菜農家・畜産農家・果樹農家の3種**。①は野菜農家で作り、⑤で畜産、⑥で果樹を追加（稲作は将来の候補） |

| 置き場所 | `farm-roguelike/` |
| 絵の方向性 | 「もののけ姫」のようなシリアスなタッチ（6.5章） |
