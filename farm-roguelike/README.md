# デッキ構築ローグライク × 農業（タイトル未定）

Slay the Spire のようなカード式ローグライクを、農業をテーマに作っています。
春→夏→秋→冬の1年を乗り切るのが最終形です。いまは **① 最小プレイ版** の段階です。

## いま遊べること

- 農家タイプ：**野菜農家・畜産農家・柑橘農家** の3種
- 敵：**10体**。1〜3体の顔ぶれで現れ、戦うたびに少しずつ強くなる（`data/enemies.js`・`data/encounters.js`。一覧は [docs/character-gallery.html](docs/character-gallery.html)）
  - 害獣・害虫：はぐれ鴉・群れ鴉・山の大猪・アブラムシの群れ
  - 雑草：はびこる雑草（勢いを回復しながら、乾燥や疲労にしてくる）
  - 病害・疫病：いもち病（使えない「病斑」カードを混ぜる）・鳥インフル（家畜を倒す。ワクチンで防げる）
  - 天候：遅霜・干ばつ・大型台風（**決まったターン数を耐えきると過ぎ去る**。勢いを0にしても勝ち）
- カード：**70種**（各タイプ 21〜26種＋全員共通5種）。一覧は [docs/cards.md](docs/cards.md)
- 流れ：戦闘 → 報酬（銭と、3枚から1枚選んでデッキへ）→ 次の戦闘 … 健康度が0になったら経営評価
- **市場**：3回追い払うごとに開く。5枚の中からカードを買える／デッキのカードを売って銭にできる（デッキは6枚まで減らせる。`js/market.js`）
- 戦闘中に自分の農家をタップすると、健康度・守り・エネルギー・かかっている状態・レリックなどを確認できる

### 3つの農家タイプ

| タイプ | 遊び方 | 初期レリック |
| --- | --- | --- |
| 野菜農家 | 区画3つ。種をまくとターンごとに育ち、実ったら収穫で銭と効果。回転が速く、続けてカードを使うほど強いカードが多い | 使い込んだ竹かご（収穫するたび守り3） |
| 畜産農家 | 畜舎3つ。子牛・子豚・ひよこを導入し、給餌で育てて出荷。家畜は自然には育たない。給餌・ブラッシングなどの **手入れ** が多いほど **格付け**（C2→B3→A3→A4→A5）が上がり、出荷の銭が最大2倍 | 古いカウベル（出荷するたび守り6） |
| 柑橘農家 | 区画3つ。苗木を植えると成木になり、その後は毎ターン実がなる。収穫しても木は残るので、守りながら摘み続ける | 先祖代々の石垣（戦闘開始時に守り8） |

### あそび方

- 戦闘画面は Slay the Spire のように横から見た舞台。左に自分の農家、右に敵が並ぶ。
  敵の頭上のアイコンが **次の行動の予告**（鎌＝攻撃と数字、爪＝作物や実を奪う、蹄＝畑を荒らす、矢印＝力を上げる）
- 下の左にエネルギーと山札、右にターン終了と捨て札（スマホ縦では手札の上に1列で並ぶ）
- 毎ターン5枚引き、エネルギー3でカードを使う
- **収穫ボタン**（畑の右）：実った作物・木の実・出荷できる家畜を、エネルギーを使わずに自分のターン中いつでも取れる。取れるものがあると光る
- エネルギーを増やすカード：早起き・農協の補助金・家族の手伝い（全員）、豊作の気配（野菜）、朝の見回り（畜産）、みかん山の朝（柑橘）
- 戦闘のテンポは `js/main.js` の `App.TEMPO` でまとめて変えられる（数を大きくするとゆっくり）
- **カードの使い方**：タップで選ぶ → もう一度タップで使う。上へドラッグして離しても使える
- 敵が2体以上いるとき、1体を狙うカード（除草など）は **敵をタップ**、または **敵の上までドラッグして離す** と、その敵に使う。
  「敵すべて」のカード（農薬散布・ドローン防除など）はそのまま使える
- 山の大猪や台風の「畑を荒らす」は、いちばん育った作物か木を消してしまう。霜や害虫の「しおれ」は作物の段を下げ、木の実を落とす
- 敵からかけられる悪い状態：**疲労**（敵に与える量が25%減）・**荒れ**（受ける被害が50%増）・**乾燥**（作物が自然に育たない）。ターンごとに1ずつ減る
- 鴉は「作物を狙う」と、いちばん育った野菜か、木の実を1つ奪う。「防鳥ネット」「袋かけ」などの覆いで防げる
- 畑と畜舎は戦闘ごとにリセット。勝ったときに実っていた作物・なっていた実・出荷できた家畜は半値で引き取り
- 右上「帳面」でデッキの確認・挑戦をあきらめる。区画や畜舎をタップすると説明（格付けの見込みなど）
- 自動で保存。途中で閉じても「つづきから」で再開（戦闘中だった場合はその戦闘の最初から。手札や敵は同じになる）

## 起動のしかた

ビルド不要です。`index.html` をブラウザで開くだけで遊べます。
iPad・スマホで遊ぶ場合は、かんたんなサーバーを立てるか GitHub Pages などに置いてください。

```sh
cd farm-roguelike
python3 -m http.server 8000
# PC：http://localhost:8000/   スマホ・iPad：http://<PCのIPアドレス>:8000/（同じ Wi-Fi）
```

## データの足し方

### カードを足す（`data/cards.js`）

```js
sickle: {
  name: '草刈り鎌', type: 'attack', cost: 1, rarity: 'common', pool: ['common'], art: 'weeding',
  text: '勢いに4を2回',
  effects: [{ op: 'damage', amount: 4 }, { op: 'damage', amount: 4 }],
  upgrade: { name: '草刈り鎌+', text: '勢いに5を2回', effects: [{ op: 'damage', amount: 5 }, { op: 'damage', amount: 5 }] }
}
```

使える効果（`op`）の主なもの：
`damage` 勢いを減らす / `block` 守り / `draw` 引く / `energy` / `heal` 健康度回復 / `gold` 銭 / `status` 状態をつける /
`plant` 植える / `grow` 作物と木を育てる / `harvest` 収穫 / `prune` 実の上限と実を増やす /
`addAnimal` 家畜を入れる / `feed` 家畜を育てて手入れ / `ship` 出荷 /
`damagePerPlayed`・`damagePerAnimal`・`blockPerFruit` など数に応じたもの。全部は `js/core/effects.js` の `OPS` にあります。

カードを足したら、`node tests/sim.js` でテスト（すべてのカードを実際に使って確かめる）、
`node tools/card_list.js` でカード一覧（docs/cards.md）を作り直してください。

### 敵・作物・レリック・農家タイプ

各ファイルの先頭に書き方の説明があります。農家タイプは `data/farmers.js` に1件足し、
`enabled: true` にして、専用カードの `pool` にタイプIDを入れれば選べるようになります。

### 絵について

- **カードの絵**（`assets/img/cards/<カードID>.jpg`、70枚）と **敵の絵**（`assets/img/enemies/<敵ID>.png`、背景透過、10体）は、
  いただいた絵から切り出したもの。カードを足すときは同じ名前で JPEG（3:2、360×240 程度）を置き、`js/ui/art.js` の `CARDS` に ID を足す
- 農家・作物・家畜・道具のアイコンと背景は、`tools/` のスクリプトで描いた SVG（`assets/img/art/`・`assets/img/bg/`）

### 絵を差し替える

`js/ui/art.js` の `FILES` に「名前 → ファイル」が並んでいます。手描きの PNG などに替えるときは
`assets/img/art/` にファイルを置き、ここのファイル名を書き換えるだけです。

## このあとの予定

| 段階 | 中身 |
| --- | --- |
| ② | 分岐マップ（1季節6段）・休憩（回復 or カード強化）・季節の決算 |
| ③ | 市場（購入・削除）・ランダムイベント・レリック10種ほど・敵を増やす |
| ④ | 4季節のボス（遅霜・大干ばつ・大型台風・家畜疫病／大雪）と季節ごとの背景。冬のボスでクリア |
| ⑤ | 畜産農家・柑橘農家の手ざわりの調整、家畜を狙う敵（イノシシ・鳥インフルなど）でワクチンや柵が活きるように |
