# デッキ構築ローグライク × 農業（タイトル未定）

Slay the Spire のようなカード式ローグライクを、農業をテーマに作っています。
春→夏→秋→冬の1年を乗り切るのが最終形です。いまは **① 最小プレイ版** の段階です。

## いま遊べること（① 最小プレイ版）

- 農家タイプ：**野菜農家**（畜産農家・果樹農家は「準備中」として表示）
- 敵：**群れ鴉** 1種。戦うたびに少しずつ強くなる
- カード：10種（初期4種＋報酬で手に入る6種）
- 流れ：戦闘 → 報酬（銭と、3枚から1枚選んでデッキへ）→ 次の戦闘 … 健康度が0になったら経営評価

### あそび方

- 毎ターン5枚引き、エネルギー3でカードを使う
- **カードの使い方**：タップで選ぶ → もう一度タップ（または敵をタップ）で使う。上へドラッグして離しても使える
- **畑**：「種まき」で小松菜を植える → ターン終了ごとに1段育つ（「水やり」「肥料」で早く育つ）→ 実ったら「収穫」で銭と効果
- 群れ鴉は「作物を狙う」と、いちばん育った作物を奪う。「防鳥ネット」で防げる
- 敵の頭上の朱の札が **次の行動の予告**
- 畑は戦闘ごとにリセット。勝ったときに実っていた作物は半値で自動収穫
- 右上「帳面」でデッキの確認・挑戦をあきらめる。区画をタップすると作物の説明
- 自動で保存。途中で閉じても「つづきから」で再開（戦闘中だった場合はその戦闘の最初から。手札や敵は同じになる）

## 起動のしかた

ビルド不要です。`index.html` をブラウザで開くだけで遊べます。
iPad・スマホで遊ぶ場合は、かんたんなサーバーを立てるか GitHub Pages などに置いてください。

```sh
cd farm-roguelike
python3 -m http.server 8000
# PC：http://localhost:8000/   スマホ・iPad：http://<PCのIPアドレス>:8000/（同じ Wi-Fi）
```

│  ├─ score.js           経営評価

## データの足し方

### カードを足す（`data/cards.js`）

```js
sickle: {
  name: '草刈り鎌', type: 'attack', cost: 1, rarity: 'common', pool: ['common'], art: 'weeding',
  text: '勢いに4を2回',
  effects: [{ op: 'damage', amount: 4 }, { op: 'damage', amount: 4 }],
  upgrade: { name: '草刈り鎌+', text: '勢いに5を2回', effects: [{ op: 'damage', amount: 5 }, { op: 'damage', amount: 5 }] }
}
```

使える効果（`op`）：`damage` 勢いを減らす / `block` 守り / `draw` 引く / `energy` / `heal` 健康度回復 / `gold` 銭 /
`plant`（`crop` に作物ID）/ `grow` 作物を育てる / `harvest` 実った作物をすべて収穫 / `status`（`id` と `amount`）。
新しい効果が必要なら `js/core/effects.js` の `OPS` に関数を1つ足します。

### 敵・作物・レリック・農家タイプ

各ファイルの先頭に書き方の説明があります。農家タイプは `data/farmers.js` に1件足し、
`enabled: true` にして、専用カードの `pool` にタイプIDを入れれば選べるようになります。

### 絵を差し替える

`js/ui/art.js` の `FILES` に「名前 → ファイル」が並んでいます。手描きの PNG などに替えるときは
`assets/img/art/` にファイルを置き、ここのファイル名を書き換えるだけです。

## このあとの予定

| 段階 | 中身 |
| --- | --- |
| ② | 分岐マップ（1季節6段）・休憩（回復 or カード強化）・季節の決算 |
| ③ | 市場（購入・削除）・ランダムイベント・レリック10種ほど・敵を増やす |
| ④ | 4季節のボス（遅霜・大干ばつ・大型台風・家畜疫病／大雪）と季節ごとの背景。冬のボスでクリア |
| ⑤ | 畜産農家（子牛導入・給餌・ワクチン・出荷・格付け） |
| ⑥ | 果樹農家 |
